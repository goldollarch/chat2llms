二、实体法分析：寻衅滋事罪构成要件逐项检验

网络”散布虚假信息型”寻衅滋事罪（《两高解释》第5条第2款）的构成要件可拆为四项。逐一审视（评价为 C 类推论，事实基础为 A/B 类）：

要件① 信息须为”编造的虚假信息”——认定存疑（法律适用问题）

  • 规范要点：该款用语是”编造的虚假信息”，其核心应是可证伪的事实性陈述。观点、评价、艺术表达、情绪宣泄在逻辑上不具”真假”属性，原则上不能成为刑法上的”虚假”。

  • 文书现状：一审/二审均未逐条列明哪一条内容、以何种证明路径被认定”虚假”，而是以”转发的内容经梳理均属于虚假信息”整体概括。

  • 核心风险点：文书实际采用的标准近似于”内容冒犯领导核心与体制 ⇒ 虚假”。把”不受欢迎的观点”转换为”虚假事实”，涉嫌范畴混淆。

  • 材料主张（B 类）：涉案贴文多为艺术漫画、纪念图、学术/时政评论、官方账号或官方媒体曾刊发内容，至今可检索、无有权机关辟谣。若属实，则”编造虚假”前提不成立。

要件② “散布”且属”起哄闹事”——行为类型匹配存疑

  • “起哄闹事”是本罪的行为本质，指借事生非、煽动制造事端。材料称被告人系”一键转发”、无增删、无组织指使他人散布。

  • 文书对”起哄闹事”要件未作专门论证，径直跳到结果要件。这是构成要件审查的实质性遗漏。

要件③ “造成公共秩序严重混乱”——结果要件近乎零证据（最薄弱环节）

  • 该罪属结果犯，须有现实秩序受严重冲击的可查证事实（如引发群体性事件、公共场所秩序混乱或其他严重后果）及因果关系。

  • 文书现状：起诉/一审/二审三级文书对此均只有一句结论性断言，无任何”何日、何地、何种秩序受冲击、规模、因果链”的事实描述，无舆情报告、无统计数据、无处置记录。

  • 材料对照数据（B 类·须谨慎采信）：账号 @_cenjoy 关注者约 92 人（不足百人、多为僵尸粉）；被控期间转发总量推算 50–70 次；单帖互动极低（转发 1–4、浏览 20–50）；刑满后涉案贴文仍存在、”零关注零传播”。

  • 真正决定性的不是这些数字精确与否，而是举证责任分配：结果要件由控方负证明责任，而控方对该要件举证为零。无论辩方数据是否精确，”该要件处于零证据状态”的结论都成立。

要件④ 主观”明知”——以学历推定故意，涉嫌主观归罪

  • 文书推定链：”完全刑事能力人 + 高学历 ⇒ 应辨别是非 ⇒ 明知 ⇒ 故意”。

  • 法律评价：刑事推定的基础事实与推定事实之间须有常态联系；”学历”与”特定信息是否系编造”之间不存在这种联系。以身份/学历特征推定心理状态，属客观归罪，与”主客观相统一””重证据不轻信口供”原则冲突。

  • 材料另指一处内在矛盾：判决一面以”应有判断力”归罪，一面（据 B 类自述）庭审中又打断被告人的专业陈述——若属实，说理难以自洽。

退路：《刑法》第13条但书

即便假定控方事实全部成立，鉴于”转发非原创、传播范围极小、无现实危害、来源多为公开渠道”，本案仍可能落入”情节显著轻微危害不大，不认为是犯罪”的但书空间。但书出罪比”全案无罪”在实践中更易被接受，是不否定控方事实主张前提下的现实路径。

实体小结：四要件中，①”编造虚假”认定缺依据、②”起哄闹事”未论证、③”严重混乱”零证据、④”明知”靠身份推定。就文书所载内容看，定罪论证链条存在多处断裂，更接近”事实不清、证据不足”的应判无罪情形。此结论受限于”未见卷宗”，如卷宗另有实质证据，须相应修正。

四、证据规则分析

  • 证据清单的”空心化”：起诉书列有”鉴定意见”，但判决书、裁定书的证据清单中实际并无鉴定意见支撑”虚假性”认定；核心依据实为侦查机关自制的《网络聊天平台梳理情况说明》。

  • “情况说明”的证据资格：其性质是办案机关就自身办案出具的陈述，不属于法定证据种类，通常只能解释取证过程，不能单独作为定案依据，更不能自我证明”所收集材料属虚假信息”。

  • “梳理”≠ 认定：”经梳理均属虚假信息”——“梳理”是办案操作，不是事实核查或鉴定方法。以办案人员判断替代真伪核实，是证据体系的根本缺陷。

  • 裁判文书说理：一审对证据认定仅一句”取证程序合法、内容客观真实、能相互印证，形成证据锁链，本院予以确认”，未对任何单项证据分别阐明采信理由，亦未说明证据如何指向”虚假性”与”严重混乱”两个核心待证事实——不符合裁判文书释法说理要求。（材料另指出判决书存在”刑其””完全刑事能力人”等多处文字瑕疵，反映文书审慎度不足。）

五、量刑评估

  • 法定刑档：第293条第一款为五年以下有期徒刑、拘役或管制；本案取一年八个月实刑。

  • 比例评价：结合材料所载极低传播规模、无组织性、无营利、无前科、无现实危害后果，即便假定罪名成立，科处实刑亦偏重；同类情节案件中，缓刑、拘役或免予刑事处罚是更常见的处理。

7.2 这一方法论的真实价值（C 类评价）

它做的不是”炫技”，而是完成了一次论证结构的位移，且位移方向对辩方有利：

  1. 从”结果有没有发生”转向”行为人有没有造成结果的因果能力”。这恰好对接客观归责理论的核心检验——行为是否创设了”法所不容许的风险”。在 m≪1 的亚临界条件下，风险创设环节即不成立。

  2. 把举证责任问题尖锐化为一项控方空白的待证事实。SOC 框架下，雪崩的必要条件是系统整体已处临界态。控方若要主张”蝴蝶效应”，就必须先证明案发时网络已积累足够势能（情绪极化、算法共振、枢纽联动）——这一清单上的每一项，卷宗均为空白。

  3. 为”相当因果关系”提供可复核的反证语言，与三级文书”造成公共秩序严重混乱”的结论性断言形成鲜明对比，直观暴露裁判说理的空洞。

  4. 反向支撑行为要件：平均每帖 1–2 次转发、几乎零回复的互动模式，与”寻求刺激、制造事端、呼告煽动”的”起哄闹事”行为特征不符。

7.3 必须诚实交代的效力边界（本章的关键）

材料自身的评估部分（第 99–100 页）其实已承认大部分局限，但这些承认在书中被夹在大量”科学上坚实、法理上无可辩驳”的褒扬语之间，容易被读者忽略。集中列出如下：

  1. 参数不是测出来的，是估出来的。模型中活跃比 0.15、转发概率 0.01 等取自行业经验值与推断，并非从本案真实数据测得。数学上的严格性只保证”若参数如所设，则级联必灭”，并不能保证参数本身为真。这决定了它是或然性论证而非证伪性论证。

  2. 类比不等于等价。社会系统的”秩序混乱”与热力学相变之间是同构类比；”公共场所秩序严重混乱”是规范性判断，其成立与否最终由法律标准而非物理模型决定。把物理定理作为裁判依据，在证据法上不可行。

  3. 这是一件双刃武器，材料未提示的风险：

    • SOC 论证隐含”若系统处于临界态，则边缘节点也可能触发大规模事件”。控方可反过来主张：被告人正是明知存在现实张力而仍加以传播，属于对风险的放任。

    • 无标度网络”对蓄意攻击极度脆弱”（精准移除枢纽可迅速碎裂网络）这一性质，若被反向引用，恰好支持”网络言论确有破坏秩序的能力”。

    • 模型一旦承认枢纽节点能够触发雪崩，就等于在一般层面承认网络言论具备危害能力，从而削弱”言论本质上不可能造成混乱”这一更强的主张。

  4. 哥德尔式”认知谦逊”抗辩存在被误读的风险。它有助于说明”我不知道内容真假”这一主观状态的真实可信，但刑法上的”明知”包含未必故意（放任）形态——“无力确定真假却仍然转发”，在控方叙述中可能被重构为对真伪的漠不关心与放任。因此这一抗辩宜作为对”身份推定明知”的反驳工具使用，不宜作为独立的正面主张铺得过开。

  5. 它不能替代另外两个要件的论证。科学框架只作用于”因果关系＋结果要件”。而”涉案内容是否属于编造的虚假信息””行为是否属于起哄闹事”这两个要件，必须靠法教义学与事实核查解决，与物理模型无关。把全书重心放在科学论证上，反而可能掩盖这两个更直接的出罪路径。

  6. 真正决定性的仍是举证责任，不是数字精度（材料第 96 页自陈）：无论辩方推算的转发量是否准确，控方对结果要件举证为零这一事实都成立。科学论证的正确功能是提高”合理怀疑”的强度，而不是自证无罪。

7.4 转化建议：如何让它进入法律程序而不被驳回

  1. 分层排序，顺序不可颠倒：第一层主张控方对结果要件零举证（举证责任）→ 第二层提交经公证的公开页面实测数据（关注者数、逐条互动量）作为量级反证 → 第三层才把科学模型作为解释性框架/专家辅助人意见（《刑诉法》第192条）呈现。本末倒置会让法庭以”与待证事实无关”整体驳回。

  2. 把估参换成实参——本案有一条被忽略的取证线索：一审判决第二项已明确”扣押在案的电脑、手机及硬盘”，其中恰恰保存着能直接测出平均分支数 m 与真实互动量的原始数据。申请法院调取该批扣押设备、委托司法鉴定出具传播量审计报告，是把”推断”升级为”实测”的最短路径；材料中”设备最高、账户中等、档案较低”的可行性排序支持这一选择。

  3. 术语必须法言法语化：”χ 有限、m≪1、q→1”应改写为”行为不足以引起危害结果，未创设法所不容许的风险，不具有刑法上的相当因果关系”。物理符号保留在附件推导中，正文只留结论。

  4. 以类案量级对比替代模型论证：材料第 62 页援引的最高法入库参考案例”尹某杰寻衅滋事案”（入库编号 2026-04-1-269-001）确立的入罪门槛是”大量转发评论＋人肉搜索、恶意骚扰等次生危害”。把本案与该案做逐项量级对照（相差至少一个数量级），在申诉材料中的说服力高于任何物理推导。

  5. 慎用其政治化延伸：材料把科学论证进一步推向”任何网民都可能因系统混沌而被犯罪”的制度性结论。这一推论在论证上有感染力，但在再审申请书中应压缩为一句”入罪标准缺乏可预测性，与罪刑法定原则的明确性要求相冲突”，以保持法律论证的克制与专业度。

8.3 心理学与物理学支柱的分工

两者并非重复：物理学处理”结果能否发生”（客观归责与因果能力），心理学处理”心态是否恶意”（主观要件）与”错误为何系统性地发生”（程序与制度成因）。前者针对要件②③，后者针对要件④，合起来正好覆盖本案两个完全无证的环节。心理学部分还额外承担一项物理部分不承担的功能——把办案人员的非理性从个人道德问题改写为制度激励问题，材料明确声明”并非为司法行为提供环境决定论开脱”，其用意在于说明这类错误可预期、可通过程序设计（录音录像全覆盖、二审开庭、文书逐项说理）加以抑制。

8.4 效力边界（本章的关键，且比物理篇更严）

  1. 心理画像不具备证据资格，且无法补强。全部人格剖面与”动力学诊断”都建立在当事人自己写的文本（血书、上诉书）之上，分析者从未接触当事人，无施测、无常模、无信效度检验。法律上它既不是《刑诉法》第 50 条的”鉴定意见”，也不构成对”专门性问题”的专家辅助人意见。这一点比物理篇的缺陷更硬：物理模型的参数可以通过调取扣押设备实测替换，人格剖面却没有任何取证路径能把推断变成证据。

  2. 存在严重的对称性问题——材料批评身份推定，却在使用同构的人格推定。判决书以”高学历”推”明知”；材料的心理学部分则给被告做”高开放性、高尽责性、自我功能高度整合”的正面画像，给办案人员做”低开放性、权威人格、死亡驱力（Thanatos）、邓宁-克鲁格效应”的负面画像，用的是同一套未经测量的临床语言。若承认这种画像具有证明力，控方完全可以反向使用”高开放性⇒易受境外思想影响⇒明知而乐于传播”。这是本章最重要的内在矛盾，材料自身未加警示。

  3. 病理化风险。健康心理学对 HPA 轴、皮质醇、急性应激障碍、PTSD 的推定，以及”人格与病理层面”（第 2857 页）等表述，虽逐节声明”不构成临床诊断”，却同时大量使用”动力学诊断”字样。写入申诉材料的现实风险是：被反向援引为”精神状态不稳定””偏执式坚持”，损害陈述可信度。

  4. 概念挪用削弱整章可信度。邓宁-克鲁格效应的原义是”低能力者高估自身能力”，材料用它批评法官”逻辑不如中学生”属于修辞挪用而非严格应用；Milgram 权威服从的实验情境亦与本案不完全对应。此类挪用一旦被对方或法官指出，会连带使其中真正可用的论证（道德推脱、隧道视野、认知闭合）一并失去分量。

  5. 推论层级过高，与个案要件脱节。文化心理学、进化心理学分支把结论推至”集体主义与个体主义文化冲突””社会 evolvability 下降””现代自我坚守的珍贵个案”，属宏观叙事，无法连接到任何一个构成要件的证明或反驳。

  6. 不可用于证明”恶意”的反面，只能用于证明”控方未证明”。心理学部分真正的法律功能不是证明陈博士动机纯良，而是说明：在缺乏客观认知证据的情况下，”恶意”这一待证事实无法由身份、学历、人格类型推出。它应当作为反驳工具而非积极主张使用。

8.5 转化建议：只保留两枝，其余降为附件

  1. 保留第一枝——对准法定动机要素。把”内在动机 / 学术探索”改写为规范论证：”本罪要求’寻求刺激、发泄情绪、逞强耍横、无事生非’的主观要素，而本案行为方式为长期、零星、无增删的内容收藏与转发，无任何制造事端、呼告动员、聚集联动的外部表征，与该法定动机类型不符。”——用 A 类文书事实（转发而非原创、无评论组织、无二次传播）支撑，不引用 Big Five 或 SDT。

  2. 保留第二枝——把认知偏差转成程序主张。不要主张”法官有偏见”（无法证明，且冒犯裁判者），而要主张为打破系统性确认偏误所必需的程序保障：一审违反公开审判（《刑诉法》第238条应发回情形）；二审对法定应当开庭情形不开庭，使书面审理成为单通道自我确认；文书须对每项证据分别说明采信理由。这三项是可核验的程序违法，心理学在此只作为”为什么这些程序保障不可省略”的说理背景，其功能相当于立法理由说明，而非证据。

  3. 删除全部对办案人员的人格与病理描述。改为可核验的行为描述：未核实即起诉、不开庭即终审、拒转控告材料、以”未提交新证据”倒置举证。心理学部分对司法非理性的解构，只有翻译成程序请求才具有实际效力。

  4. 确需心理学进入程序的唯一合法入口：依《刑诉法》第 192 条申请有专门知识的人出庭，就”网络低影响力账号的行为模式与犯罪动机之间的可检验关系”发表意见；不是为被告品格辩护，也不是为办案人员作诊断。同时应意识到，此类申请的实务价值低于传播量司法鉴定。

九、总体结论

  1. 就文书所载内容看，本案定罪在实体上（虚假信息认定、起哄闹事、严重混乱、主观明知四要件）与程序上（不公开审理、二审当开庭未开庭、举证责任倒置、证据空心化）均存在多处重大法律疑问，法律论点强度上”无罪主张”较强、”定罪论证”较弱。

  2. 这一结论的边界必须诚实交代：分析仅基于当事人整理的文书文本，完整卷宗未见。若卷宗另有经质证的实质证据（尤其能证明”明知系编造”与”造成现实秩序混乱”的证据），上述评价需相应下调。

  3. 时效是当前最紧迫的现实问题：常规申诉两年期已过，应立即转向”期限除外主张 + 检察审判监督 + 法院依职权再审”三条不受（或较弱受制于）该期限的渠道，并尽快固定公证类新证据。

  4. 本材料在方法上有两根支柱：物理学/网络科学与心理学（第七、八部分）。前者把争点从”结果有没有发生”推到”行为人有无造成结果的因果能力”，从而暴露控方对”系统处于临界态”这一前提的举证空白；后者把主观要件的攻击面精确对准法定动机要素”寻求刺激、发泄情绪、逞强耍横、无事生非”，并把司法错误从个人道德问题改写为可预期的制度激励问题。两者分工明确：物理管要件②③（客观归责与结果），心理管要件④（明知与恶意）。

  5. 但心理学支柱的证据法地位比物理篇更弱，须严格限制使用。全部人格画像建立在当事人自作文本之上，无施测、无常模，既非鉴定意见也难以作为专家意见；更关键的是它存在对称性悖论——批评判决”以学历推明知”，却用同一套未经测量的临床语言为被告作正面画像、为办案人员作负面诊断，控方可原样反向使用。可用的只有两枝：法定动机要素的不符（用文书事实支撑）、以及把认知偏差转写为程序请求（公开审判、二审开庭、逐项说理）。其余人格与病理描述写入申诉材料只会损害说服力。

1.1 统计物理学：涨落-耗散定理（FDT）

理论内容：平衡态附近，系统的自发涨落谱 S(ω) 与其对外微扰的响应函数 χ(ω) 由耗散强度联系（涨落的宏观响应 ΔM ≈ χ·δH）。远离相变点时 χ 为有限值，涨落被阻尼指数衰减 e^(-γt)；仅在临界点附近 χ 与关联长度 ξ 发散，微扰才可能被长程关联放大。

推论结构：控方指控隐含”任意转发可无衰减传导至宏观态”，即默认 χ→∞；而 χ 发散只在临界态成立，卷宗无任何临界参数记录（无热度峰值、无跨平台共振、无线下聚集）。故”微观涨落 → 宏观相变”的因果放大路径不成立。

评估：FDT 是一个受严格适用条件约束的定理（近平衡、线性响应、浴温度为热力学量）。它给出的是”微扰通常被阻尼”的倾向性直觉，不是”社会系统不可能被单条信息扰动”的定理。材料的正确用法是把它当作类比性举证框架：谁主张放大效应，谁证明系统处于放大态。材料的越界用法是”物理铁律””数学必然性划定因果红线”——这在 Daubert 第 5 项（方法之于本案事实的可靠适用）上失分。

1.2 相变与临界现象：范畴错误的指控

理论内容：相变的标志是序参量从零突变为非零、ξ→∞、χ→∞、自由能势垒消失；其必要条件是控制参数跨越临界值（T→T_c、渗流 p→p_c、分支过程 m→1）。涨落只是相变的触发媒介而非充分条件。

材料的法律转译（p2051–2072）：把”一次转发”直接等同于”秩序混乱”，在统计物理语境下正是将热力学涨落误认为宏观相变的典型范畴错误；在法理上则是把”潜在风险”等同于”现实危害”，违反结果犯要求的”行为通常足以导致结果”。

评估：这一节是整个客观支柱中法理收益最高、科学风险最低的部分，因为它不依赖任何本案参数——它只做概念区分（风险≠危害、能力≠结果）。对应中国刑法教义学中的”客观归责”检验：风险创设（不被法所容许）→ 风险在结果中实现 → 构成要件射程内。概念层面即可切断。

1.3 无标度网络拓扑：BA 模型与 Cohen 渗流阈值

理论内容

  • Barabási-Albert（1999）：幂律度分布 P(k)~k^(-γ)，2<γ≤3，由”优先连接 + 增长”生成；少数枢纽主导信息流。

  • Cohen, Erez, Ben-Avraham, Havlin（PRL 2000–2001）：用渗流理论定量刻画无标度网络的鲁棒性——随机失效的临界移除比例 f_c→1（需移除近乎全部节点才丧失巨连通分支）；但针对枢纽的蓄意攻击可在极低比例下使网络碎裂。

  • 小世界效应、长尾分布：海量低关注内容构成系统背景噪声。

材料的映射（p2139–2160）：被告人账号度数极低（关注者约 92 人）→ 属边缘节点 → 其”移除/扰动”不改变巨连通分支 → 社会秩序对个别转发具结构性鲁棒性 → 结果要件在拓扑上不具备被触发的条件。

评估（含一处材料未提示的反噬风险）

  1. 成立部分：拓扑性质论证不依赖本案互动数据的精度，只依赖”该节点度数处于分布左尾”这一定性事实，而这一事实可由公开页面公证固定，取证路径清晰。

  2. 类比强度有限：社交网络的信息传播并不满足渗流模型的独立失效假设；转发行为是”激活传播”（属于级联/扩散过程），不是”节点移除”（属于渗流鲁棒性）。把鲁棒性定理用于扩散问题，是跨过程借用，学理上并非严格同构。

  3. 反噬（重要）：同一文献的另一半结论——无标度网络对蓄意攻击极度脆弱——若被控方反向引用，恰可支持”网络言论具备破坏秩序的现实能力”。更严重的是，模型一旦承认枢纽节点能触发雪崩，就在一般层面承认了言论的危害能力，从而削弱”言论本质上不可能造成混乱”这一更强的主张。材料通篇未提示这一点。

1.5 分布式计算机科学：CAP 定理

理论内容：Brewer（2000）提出、Gilbert-Lynch（2002）证明——分布式系统无法同时满足一致性 C、可用性 A、分区容错 P。

材料的映射（p2102–2138）：现实社交网络为保障可用性与分区容错，必然牺牲一致性，即无法实现全局信息同步或”秩序统一”；因此社交网络本质上是高熵、非平衡、不可控的系统，”混乱”是结构性常态而非异常状态；把系统内禀无序归咎于个体行为，是归因谬误。材料引陈博士比喻：”我的转发，如同呼吸释放二氧化碳——不能因地球变暖，就判我终身监禁。”

评估

  1. 这是全部客观论证中科学挪用最重的一处。 CAP 的”一致性”是读写语义概念（所有副本在同一时刻看到同一数据值），与规范意义上的”公共秩序”（社会成员行为的预期稳定性与可协调性）不是同一类对象。CAP 不能推出”有序的网络在技术上不可能存在”——现实中分布式系统大量使用最终一致性、共识算法、CRDT，且 CAP 的三选二是在网络分区发生时的权衡，而非否定任何秩序形态。

  2. 该比喻的修辞价值高于证明价值。它在”制度批判/立法建议”层面有力（提醒规制者勿以个体归责替代系统治理），但在构成要件审查层面几乎不产生作用，因为它否定的是一种普遍性的治理幻想，而不是本案的结果要件事实。

  3. 建议在正式法律文书中删去 CAP。保留它的成本（被专业人士一眼识破类比失当）明显高于收益。

第二部分 主观支柱：对”明知”与”恶意”虚构性的解构

2.1 法定标准（材料 p869–872，规范引用最扎实）

《刑法》第14条：”明知自己的行为会发生危害社会的结果，并且希望或者放任这种结果发生”。《两高解释》第5条第2款要求”明知是编造的虚假信息”。材料据此归纳”明知”认定的三项底线：

  1. 认知对象特定——须明确知道所传播的具体信息系”编造的虚假事实”；

  2. 认知状态现实——行为时实际知晓或高度确信，而非”应当知道”或”可能知道”；

  3. 证明路径客观——必须通过客观外在事实（聊天记录、自认、内容明显违背常识、收到权威辟谣后仍转发等）逆向推证内心状态。

并援引：《刑诉法》第55条（排除合理怀疑）、第51条（公诉案件有罪举证责任在检察机关）、最高法刑诉法解释第140条（不得仅凭被告人身份、职业、学历等抽象特征推定主观故意）。

2013 年最高检《关于办理寻衅滋事刑事案件适用法律若干问题的解释》第一条把本罪主观要素界定为”寻求刺激、发泄情绪、逞强耍横等，无事生非”——这是心理学部分唯一直接命中法定要素的落点（材料 p810、p885、p2308）。

2.2 认知心理学：元认知与”应知/明知”的分离

理论内容：元认知是对自身认知状态与认知边界的觉知；双加工理论区分系统1（启发式、快速）与系统2（分析性、慢速）；认知闭合需求指个体对明确答案的渴求与对模糊的不容忍。

材料的映射

  • 对被告：上诉书自陈”我目前确实无力确定我所转发文章的真实性或虚假性”，材料解读为元认知成熟的表现（清醒认知边界），并与”邓宁-克鲁格效应”（能力欠缺者高估自身）构成对照——即：他不说”我懂得多所以我知道真假”，而说”我懂得多所以我知道我不能确定”。

  • 逻辑反转（材料 p2158，自评有效性”中/高”）：控方以”高学历”推”明知危害”；辩方反用同一前提——正因为我是这个领域的专家，我才明知我的转发在科学上绝无可能造成混乱。

  • 对司法：判决的”高学历⇒应辨别是非⇒明知⇒故意”是以”应有能力”替代”实际认知”，属系统1式启发式加工。

评估

  1. 概念区分本身是纯粹法教义学的胜利，不需要心理学也成立：应知≠明知是刑法常识；材料只是给它提供了认知科学的语言。

  2. “逻辑反转”有被反用的一面：专家身份同样可被用于推”更能识别内容真伪”，从而加强”明知”。反转动量依赖的是**”明知”的对象被置换**——从”内容真假”换成”传播后果”。因此正式主张时应精确表述为：控方未证明行为人对”信息系编造”这一特定对象的认知，而不是”专家所以无害”。

  3. 认知谦逊的边界（须警惕）：刑法上的”明知”包含未必故意（放任）。”无力确定真假却仍然转发”在控方叙述中可被重构为对真伪的漠不关心与放任。材料中”事实认识错误阻却故意”的论证（p932）对此回应不足——认识错误只阻却故意，若被评价为放任型未必故意，则该论证失效。这一抗辩宜作反驳工具，不宜作正面主张铺得过开。

第三部分 多伯特标准（Daubert）下的合规性评估

3.1 前提校正（材料自己已声明，但必须置顶）

多伯特案（Daubert v. Merrell Dow Pharmaceuticals, 509 U.S. 579 (1993)）确立的是美国《联邦证据规则》第702条下法官作为”看门人”审查专家证言可采性的框架，经 General Electric v. Joiner（1993，审查强度）与 Kumho Tire v. Carmichael（1999，扩展至技术与非科学专门知识）成形。它不直接适用于中国刑事诉讼。

材料 p7172 的表述是恰当的：”若将多伯特标准作为科学证据可靠性与因果关系论证的方法论标尺，可清晰检验控方指控与辩方抗辩在科学逻辑、可检验性、误差控制与同行共识层面的实质差异。”

中国法上的对应物（应据此实际主张）：《刑诉法》第50条（法定证据种类）、第55条（证据确实充分、排除合理怀疑）、第192条（有专门知识的人出庭）、刑诉法解释第101条（情况说明不得单独作为定案依据）、第140条（不得以身份/职业/学历推定主观故意）、以及电子数据取证规则对完整性校验值的要求。

换言之：Daubert 在本汇编中的价值是诊断工具，不是请求权基础。以下评估一律以”方法论标尺”进行。

3.2 评估的关键区分（本节最重要）

Daubert/Kumho 的真正审查对象不是理论本身的科学地位，而是”该方法是否被可靠地应用于本案待证事实”（relevance & fit；the alleged expertise must be properly applied to the facts in issue）。

3.5 综合对比：Daubert 标尺下的双向发现（材料未呈现的另一半）

分析哲学分析

哲学解构与科学解构的异同——以陈京元案汇编为样本

对象：汇编中的两条批判路径——科学解构（物理/网络科学/心理学，p557–988、p2027–3024、p7172–7220）与哲学解构（分析哲学/语言哲学/法哲学，p5230–5247、p6118–6230、p7442–8080） 出具日期：2026-11-12 说明：本文不重复要件结论，只比较两种解构方法本身；页码为原 PDF 页码

引言：两种”完美”不是同一种完美

两条路径在本案中都极具破坏力，但破坏的是不同层面的东西。先用一句话把它们的差别钉住：

科学解构说的是”世界不允许这件事发生”；哲学解构说的是”语言从未说出这件事”。 前者的弱点是它必须进入证据程序，后者的弱点是它必须进入解释程序。

由此立刻产生一个必须澄清的误解：材料常把两者并列称”科学上坚实、逻辑上无懈可击”，仿佛它们是可互换的同一类论证。不可互换，而且互换会同时损害两者——把物理模型写进法律理由会被以”与待证事实无关”驳回；把概念分析包装成证据会显得荒谬。

一、相同之处：四点真实的结构重合

1.1 攻击对象相同

两者都指向本案唯一两个零证据环节——客观危害要件（”造成公共秩序严重混乱”）与主观要件（”明知””恶意”）。两者都不碰”被告人确实转过帖”这一已被承认的事实。

1.2 论证层次相同：都在主张”必要条件缺失”，而非”证据不足”

  • 科学：若 m<1，则宏观级联在数学上不可达 → 因果能力这一必要条件不存在。

  • 哲学：若”严重混乱”无确定真值条件、”虚假信息”无清晰指称 → 命题得以成立的意义条件不存在。

两者都不是”你没证明”，而是”你无法证明，因为该项在你所用的框架内不成其为可证之事”。这比单纯质疑证据 stronger。

1.3 都不依赖完整卷宗

这是它们共同的吸引力来源：本案卷宗不公开，任何需要阅卷的论证都无法先行展开；而科学论证与哲学论证都可以只读裁判文书文本就完成。

1.4 终点都是同两个法条

科学论证最终服务于客观归责／相当因果关系；哲学论证最终服务于**《刑法》第3条罪刑法定的明确性要求**。二者只是从不同方向逼近这两个法律教义。

2.1 最重要的一条：否定性 vs 肯定性

这是两者在诉讼中命运不同的根源。

  • 科学解构要”立”——立一个模型、一组参数、一个概率界。凡”立”者皆可被攻击，且在中国刑事诉讼的印证结构下，辩方的模型主张不产生法定证据效力，除非它变成鉴定意见。

  • 哲学解构只”破”——它不主张任何关于世界的事实状态，因此永不与无罪推定和举证责任规则发生冲突。它不需要法庭相信它，只需要法庭无法指出它错在哪里。

结果：哲学解构更坚固，但对裁判者的实际约束力更弱（因为它不产生任何必须被采纳的东西）；科学解构更脆弱，但一旦转化成功就能撬动再审的法定事由。坚固性与无效性是同一枚硬币的两面。

2.2 反驳它们的成本，对控方来说极不对称

  • 反驳科学论证：控方只需提交任意一份案发期间的秩序受损实际记录（群体性事件接警记录、平台处置通报、舆情专报）。这在本案大概率不存在——所以科学论证事实上有效，但它的有效性来自控方空手，而不是来自模型正确。这一区分在评估时必须保留。

  • 反驳哲学论证：控方无法用数据反驳，只能做一件事——主张法律概念有自主定义权：”刑法上的’虚假信息’不由逻辑学决定，由立法与司法解释决定。”这是制度性的回答而非理性回答，但在实务上足以终结辩论。哲学解构的真正对手不是证据，而是定义权。

三、哲学能做而科学做不到的三件事

3.1 把”以言行事”的失败转成程序请求

奥斯汀的分析（p5243–5245）指出：宣判”有罪”要满足程序条件（允许辩护）、内容条件（行为确实该当罪状）、真诚条件。本案”禁止自辩严重违反程序条件””缺乏证据违反内容条件”，故该宣判”只是在以言施效（产生监禁后果），而缺乏正当的以言行事力量”。

这是任何物理模型都无法给出的论证：它直接说明为什么”不公开审理、剥夺辩护权”不只是瑕疵，而是使判决在构成意义上不成立——精准对应《刑诉法》第238条第(一)(三)项”应当裁定撤销原判、发回重审”的强制条款。哲学在这里比科学更有用，因为它批评的是言语行为的构成条件，而程序正当性正是这些条件在法律中的形态。

3.2 诊断”论证退化为宣告”

材料 p5247 的论证：一个完整的司法论证须包含正反论据与反驳；禁止自辩等于系统性排除所有可能证伪控方假设（H₀：有罪）的证据，使程序从”寻求真理的论证游戏”退化为”旨在压服的单方面宣告”。

这属于批判性讨论／论证理论（对话逻辑）层面的批评，与经验科学无关，却直接命中二审”不开庭、不逐项回应上诉理由”的病灶。科学的对象是世界，无法评价一个程序的论证品格。

3.3 把罪刑法定读成一项语言要求（本案最具原创性的哲学资源）

材料 p6143–6146、p6220–6222 用弗雷格”概念文字”（Begriffsschrift）解读罪刑法定：罪刑法定原则翻译成语言哲学，就是一项强制的”概念文字化”工程——立法必须把可罚行为写成外延确定、可由第三人机械复核的表达式；”越桥之处必须立法明示，法官不得私自架桥”。而本案的问题不是有人违反了罪刑法定，而是这次语言转换在”寻衅滋事”这个概念词上根本没有完成。

配合罗素的模糊性分析（p6351–6352）与哈特-魏斯曼的开放结构（p6143、p6146–6147），材料给出的定位很准确：”本案不在边缘案区域，它落在核心之外的空地上。” 这一句是纯粹概念性的，但它比任何物理推导都更接近《刑法》第3条的规范内核——明确性原则本身就是法律语言的质检标准，不需要从外部借用物理学来批评判决书说理不清。

四、科学能做而哲学做不到的一件事

科学（经转化后）可以产生新的证据，从而触发法定再审事由；哲学永远不能。

《刑诉法》第253条第(一)项”新的证据证明原判事实确有错误”，是唯一一个能迫使法院启动审查的入口。哲学论证无论多么严密，都只是”对原判的评价”，不增加任何案卷中的东西；而传播量审计报告、涉案贴文可检索性公证、逐条互动数据，都是可提交之物。

所以两者的实际关系是：

哲学论证决定申诉书”说什么”；科学证据决定申诉书”递什么”。 只有哲学，材料没有牙齿；只有科学，材料没有骨架。

五、各自的失效模式（含材料未自察的对称性问题）

5.1 科学侧（已详于《跨学科框架梳理与多伯特标准合规评估》，此处只列要点）

  1. 参数取自估计而非实测 → 或然性论证而非证伪性论证。

  2. 跨过程借用（渗流理论处理节点移除，转发属激活扩散）。

  3. 双刃反噬（承认临界态可被触发＝承认言论的一般危害能力）。

5.2 哲学侧（材料完全没有提示，且更棘手）

① 证实原则的自我反噬。 材料多处援引逻辑实证主义的可证实性／可证伪性标准（艾耶尔《语言、真理与逻辑》1936，p5237、p6143–6145、p7405–7411）来判”严重混乱”为伪命题。但证实原则自身不可被经验证实，这是它的著名死因；而奎因、后期维特根斯坦、戴维森已经系统瓦解了这个标准。用分析哲学已经抛弃的武器去批评一份判决，等于把自身最脆弱的部分暴露给对方。

安全做法：不使用”不可证实因而无意义”，改用**”该表述未给出可复核的判定标准，故不满足明确性要求”**——这是法教义学内部的标准，不依赖证实原则。

② 情感主义会反噬辩方自己的规范语词。 材料用艾耶尔的情绪主义（道德语句如”哼！””呸！”，无认知内容，p8387–8401）支持”艺术、情感表达不具真假值”。但同一把刀切下来，”罪刑法定””平等””人权””言论自由”这些辩方赖以立论的规范语句，按严格的情感主义同样无认知内容。材料引用了黑尔的规定主义（p8403–8417）作为补救，却没有意识到：既然承认道德/法律语言另有功能（规定、评价、表达），那就必须承认”虚假信息”在法律语言游戏里也可能另有功能，而不只是逻辑学意义上的真假——这恰恰是控方的立场。

安全做法：范畴区分只用在不涉规范属性的地方（漫画、纪念图、个人感慨确实不是事实陈述），而在”寻衅滋事””明知”等法律概念上，改走”法律解释的明确性与可复核性”路径，不主张”这些词没有意义”。

③ 开放结构反噬（材料 p6147 自己已标注这个词，但未展开）。 哈特-魏斯曼的 open texture 承认一切一般性法律概念必有边缘地带、法官在边缘案享有裁量——这同时是”口袋罪”扩张的法理温床。用开放结构批评判决”越界”，等于承认了裁量空间的本体论地位；控方只需说”这正是边缘案，法官有权裁量”即可抵消。

真正的武器不是开放结构，而是它对面的制度性回应：明确性原则（近似普通法的 void for vagueness）与罪刑法定的类推禁止。二者不是开放结构的推论，而是对它的限制。必须把这两者分清，否则等于借对方的武器批评对方。

④ 结论层级过高。 “伪命题集合””智识上的破产””语言与逻辑的全面溃败”这类判词在学术与档案写作中有力（这也是本汇编哲学部分最有价值的地方——它把一份个案判决当作语言滥用的标本进行诊断），但写进申诉材料会被读作对裁判者的整体贬斥，直接损害可受理性。

5.3 两侧的对称缺陷，其实是同一个

  • 科学侧：批评控方身份推定，却用未经测量的临床语言做反向画像（人格五因素、道德阶段）。

  • 哲学侧：批评控方概念混乱，却用已被抛弃的证实标准做概念批判。

两者都是用自己的弱点去攻击对方的同类弱点。这提醒一件方法论上的事：跨学科解构的说服力上限，取决于它是否比被批评对象更严格地遵守它自己提出的标准。

哲学：罪刑法定禁止以裁量填补构成要件（明确性要求），这是法律内部的原则

“危害后果无需精确，社会影响自有公论”

科学：那就请出示传播量、舆情、次生事件的实测数据——卷宗为零

“数据虽小但性质恶劣”

科学＋类案：入库参考案例”尹某杰案”（2026-04-1-269-001）确立的入罪样本是”大量转发评论＋人肉搜索、恶意骚扰等次生危害”，本案相差至少一个数量级

“两个要件都算过了”

夹逼：概念上不成其为可判定的命题，事实上没有任何可查证后果——两头都是空的

单独使用任一路，判决都能从另一侧的门走出去。

6.2 岗位纪律（三条硬规则）

  1. 概念区分可以入正文，模型必须先进鉴定。 可直接写入申诉书正文的只有三组区分：涨落≠相变（风险≠危害）、事实≠观点/艺术/情感、应知≠明知。它们不依赖任何数据，因此不会被反驳。而分支过程、渗流阈值、Monte Carlo 结果，在完成实测参数替换之前，只放附件。

  2. 哲学负责定性，科学负责定量，但都由法律语言收口。

    • 哲学产出：”该命题未提供可复核的判定标准”→ 收口于《刑法》第3条、《刑诉法》第176条。

    • 科学产出：”该要件的因果能力经实测不成立”→ 收口于《刑诉法》第55条、第253条第(一)(二)项。

    • 两句话都必须以法条结束，不以”物理铁律”或”分析哲学的基本信条”结束。

  3. 把”以言行事无效”用成”程序性无效”。 奥斯汀的恰当条件理论是本案对程序违法最有力、最不怕被反驳的学理支撑，因为它不指责任何人有偏见或无能，只陈述一个构成性事实：未满足程序条件的宣判不是一个错误的判决，而是未完成的法定的宣告行为。对应的落地请求就是第238条应当发回重审——这是哲学能给出而科学给不出的最强主张。

结语

科学解构与哲学解构在本案中是同一场批判的两个不相交的子集：科学攻击的是”转发→混乱”这条因果路径在世界中是否可达，哲学攻击的是这句话是否说出了任何具有确定真值的东西。它们共享对象、共享层次（必要条件）、共享法条终点，但在论证类型（后验／先天）、反驳方式（数据／定义权）、诉讼通道（证据／解释）和论证负担（承担／不承担）上完全不同。

最凝练的差别：科学解构必须主张什么，所以它脆弱而有力；哲学解构不必主张任何关于世界的事实，所以它坚固而无能。因此正确的用法不是择一，也不是混用，而是让哲学定义争点，让科学填补证据，让两者都在法条处收口——一个要求法庭去看数据，一个要求法庭听懂自己在说什么，而本案的致命之处在于：这两件事它都没有做。

二、欧陆解构的核心内容：按论证功能分组

按流派罗列只会复述目录。真正有分析价值的是这些框架各自攻击了判决的哪一个部位。本案欧陆论证可归为七组。

2.1 符号任意性：罪名是一个”空能指”

  • 索绪尔-巴特-列维-斯特劳斯线（p5314–5315、p5328）：”寻衅滋事”是空能指——所指可被任意填充；”意义不在事物本身，而在事物之间的关系”，故”高学历应明辨是非”是一种符号暴力；”证据锁链完整”是结构幻象（其”证据”不过是户籍证明、抓获经过等程序文书的相互指涉）。

  • 德里达线（p5434–5435、p5669–5687）：”中心”坍塌——罪名被当作可容纳一切异见的稳固中心，实则无中心；”高学历→明知”是一场延异游戏（意义在链条上滑动而不落定）；”证据锁链”的替补（supplément）本质——用替代品冒充在场。

  • 利奥塔线（p5416–5417）：”简化复杂性，是恐怖主义”；把异质语言游戏（艺术、学术、外交声明）强行纳入单一规则，是对语言游戏异质性的压制。

2.2 主体生产：判决不是在惩罚一个主体，而是在制造一个主体

这是欧陆部分最具特色、也最不受英美传统关注的一层。

  • 阿尔都塞”询唤”（interpellation，p5399）：法律不是用来”审判”陈京元，而是用来”询唤”他——把他构造成”罪犯主体”，并试图让他”自愿认同”该身份；”不认罪”因此是对询唤的拒绝。

  • 福柯线（p5417、p5453–5454）：权力/知识生产”真理”——司法不发现犯罪事实而是生产犯罪事实；”高学历”成为”科学依据”，用于将人”正常化”为罪犯；不公开审理是”反向全景敞视”——让你在黑暗中不知被谁审判、为何定罪；惩罚对象不是行为后果而是”潜在可能性”。

  • 萨特-海德格尔线（p5274–5275、p5531–5532、p5550）：司法以”本质强加”否定”存在先于本质”的自我定义；把主体贬为可被推定的物，”将他者物化，即是暴力”；”常人”（das Man）的闲言（”口袋罪””梳理””觉得”）消解本真性。

  • 巴迪乌线（p5861–5862）：接触境外信息与转发是一个事件，血书与上诉是主体化过程（介入→忠诚）；司法系统的目标是阻止主体化——禁止专业自辩即阻断”介入”；”寻衅滋事罪”是情势国家（state of the situation）对不可编码之物的暴力回收。

2.3 结构功能：替罪羊与净化仪式

  • 结构主义人类学线（p5314–5315）：陈京元被塑造成”污染”的承载者，通过”献祭”（判刑）完成一次净化仪式；”选择性执法”不是司法不公而是结构的精准打击——无业、无权、无依附的身份使其成为”结构中最理想的替罪羊”；”口袋罪”如巫术，不追求真实而追求象征平衡。

  • 这条线与心理学的”替罪羊投射机制”（p2532、p2774）构成呼应，但结构主义版本把它从心理机制升格为社会系统的功能需求。

2.4 理性类型批判：工具理性对交往理性的压制

  • 霍克海默-阿多诺-马尔库塞线（p5378–5379）：法官不关心内容的意义、语境或意图，只关心”是否敏感”——工具理性极致；”寻衅滋事罪”是意识形态装置，把政治忠诚（而非社会危害）作为实质标准；艺术、学术、政治评论本是否定性思维的实践，定罪即是对批判能力的剿灭，产出”单向度”的顺从者。

  • 哈贝马斯线（p5352、p5370、p5739–5740）：本案是交往理性被系统殖民的样本；血书是一次理想言说情境式的尝试——以科学、逻辑、证据邀请公共领域进行视域融合；司法则把公共领域私有化为”体制自留地”。

2.5 诠释学：视域融合的拒绝

  • 伽达默尔-利科线（p5338–5340、p5352）：法官的”高学历应明辨是非”不是开放的前见（Vorurteil），而是封闭的判决前提；司法拒绝进入被告人的视域（学术研究、信息存档、跨文化理解），强行把行为纳入”敌对意图”框架；”撑伞女孩”漫画、许章润文章属诠释敏感型文本，其意义依赖语境；国家垄断诠释权，把自己预设为”意义的最终裁决者”，被告人被剥夺诠释主体地位，沦为”意义的客体”——血书正是夺回诠释权的努力。

  • 操作落点（材料自列）：不追问”你为何转发？”——这一句在诉讼中可翻译为”未查明主观动机与行为语境”。

2.6 系统与符码：法律未使用自己的区分标准

这是大陆法理论线中最锋利的一处。

  • 卢曼（p8015）：本案是法律系统被政治系统殖民化的样本——法律系统并未运用自身符码（合法/不法），而是直接采纳了政治系统的符码（忠诚/异端、敌/我）。

  • 托伊纳（p8037、p8055）：功能分化的病理性越界——行为本属科学系统与公共领域的交叉实践，被司法强行全部转译为法律符码；且系统无法隐藏其悖论：控方无法证明”虚假信息”，悖论以封闭运作硬撑。

  • 施米特（p7615）：”上层领导特别指示办成铁案”即主权者决断；”寻衅滋事”定义模糊、边界不清，正是例外状态的法律工具；”我觉得是谣言””梳理即真实”都是决断而非规范适用。此处的结构是：形式上依法、实质上决断。

2.7 存在论与后人类：两类补充

  • 加缪-本真性线（p5274–5275）：”生命不息，战斗不止”被读作在荒谬中坚持真实、反抗异化；”最大的不道德不是作恶，而是放弃成为自己的责任”。

  • 拉图尔-巴拉德-新唯物主义线（p5496–5498、p6042–6043）：转发不是”高学历主体的自主选择”，而是人与贴文、平台、算法、历史语境共同编织的行动者网络；司法通过”梳理”操作暴力转译（translation）网络，把异质联结改写成”罪犯—权威—标签—条文—行政文件”的单一链条；”艺术→侮辱””观点→谣言”的切割不是发现事实，而是对物质现实的强制性重构；被抹除的非人类行动者包括贴文本身、平台架构、以及被刑讯的身体。

2.8 非实证主义法理论（最可直接使用的一层）

  • 富勒八项”法律的内在道德”（p7636–7641），材料逐条比对本案：①一般性（选择性执法，针对特定个人的”私人命令”）②公布（”高学历=明知”从未写入任何条文，是临时发明的口袋规则）③非溯及既往（定罪”规则”是 2023 年审判时才创造）④明确性（”严重混乱”无任何客观量化标准）⑤非矛盾性（一面认定其有高学历与判断力，一面喝令”闭嘴！回答是或不是！”禁止其运用该能力——材料称此使公民陷入”精神分裂”）⑥可能性（要求一个人对全部转发内容作真伪鉴定是”不可能的任务”）⑦稳定性（为个案”量身定制”的一次性规则）⑧官方行为与公布规则的一致性（口引第293条，实际标准却是”觉得是谣言”——材料称此为最严重违反，摧毁法律公信力）。结论：富勒意义上的**”法律的失败”**。

  • 阿列克西（p7545–7550）：①原则理论与权衡——“言论自由”对”公共秩序”，本案拒绝权衡，用”零证据的严重混乱”压倒”无限价值的言论自由”，材料称之为**”零比例的暴政”；②论证义务**（Begründungspflicht）——判决必须给出理性、可检验的论证，”梳理即真实”不是论证而是权力宣言；③正确性宣称（Richtigkeitsanspruch）——法律若丧失正确性宣称即不再是法律而只是暴力外衣；④法的双重性质——形式合规而实质不公者非”完整的法”。

  • CLS／Cover／佩雷尔曼（p7578、p7837–7838、p8183–8187）：任何司法判决都伴随痛苦的施加（”法律解释发生在暴力场域之中”），而主流法理学系统遮蔽这一事实，制造”判决是法律自身逻辑必然结果”的幻觉；佩雷尔曼新修辞学主张判决不是计算而是论证，须面向”普遍听众”，本案是”听众的缺席”——论证无视普遍道德直觉；CLS 主张法律推理内含基本矛盾，裁判结果实取决于意识形态偏好。

三、与英美分析哲学解构的相同之处：四点真实重合

3.1 同一诊断，三套词汇（最显著的重合）

把三条线并排看，会发现它们说的是同一件事：

传统

表述

分析哲学（弗雷格/罗素/哈特）

“虚假信息”外延不确定；”模糊谓词”；开放结构；本案不在边缘案区域，而在核心之外的空地上

结构主义／后结构

“寻衅滋事”是空能指；延异使意义不落定；替补冒充在场

系统论

法律未使用自身符码，采纳了政治符码

三者共同指向：**判决书的核心术语没有给出可复核的判定标准。**这一重合极为牢固，因为三个互不相干的传统独立得出同一结论，而它恰好是《刑法》第3条明确性要求的规范内核。

3.2 都把”证据锁链”读作符号结构而非事实链条

分析哲学指其循环论证（”梳理”即预设结论）；德里达指其替补本质；结构主义指其关系性自指。三条路都在说：所谓锁链是程序文书之间的相互指涉，不指向外部世界的事实。

3.3 都诊断”法律语言被政治修辞殖民”

分析哲学称之为语义污染（semantic contamination，p5239–5240：判决援引法律却依赖”领导核心””体制”等不在刑法语义场内的术语）；卢曼称之为符码替换；施米特路径称之为决断冒充规范；富勒称之为官方行为与公布规则的背离；CLS 称之为政治偏好冒充法律推理。这是本案两传统的第二交汇点，且比第一交汇点更具结构性。

3.4 都不依赖卷宗、都不承担举证责任

与分析哲学相同，欧陆解构批评的是判决的形式与条件，而非主张一个需要辩方证明的事实状态。两者都可以在只读文书文本的情况下展开。

低：几乎不可反驳——任何反例都可被重述为意识形态遮蔽或符号暴力

诉讼通道

解释与说理层；真值条件缺失可对接”事实不清、证据不足”

无通道：其结论是制度性诊断，不是个案裁判理由

4.1 核心差异：欧陆把”错判”重述为”正常运转”——由此产生一个致命悖论

这是本文最重要的判断，材料完全没有察觉。

分析哲学说：这是一个错误（概念误用、逻辑谬误、真值缺失），错误是可以纠正的，纠正机制（再审）预设了这种可能性。

欧陆说：这不完全是错误，而是结构的功能——替罪羊需要被献祭（p5314）、空能指必须被填充（p5314）、询唤必须产出一个罪犯主体（p5399）、例外状态必须由决断来填补（p7615）、法律系统必须转译异质网络（p6043）。

后果是论证自我取消：若本案是结构的正常运作，则：

  1. 冤案不依赖任何人的失误，因此没有可以被推翻的”事实认定错误”——而《刑诉法》第253条全部五项再审事由都以”认定或适用错误”为前提；

  2. 纠错机制本身也是该结构的一环，于是请求再审等于请求结构自我否定，欧陆框架越成立，救济在逻辑上越无望；

  3. 它把辩护从”这个判决不成其为判决”（富勒、阿列克西可支持）推向”这个体制不会自我纠正”（福柯、阿甘本可支持）——后一句在学术上更强，在法庭上却是自杀。

一句话：分析哲学解构与救济逻辑同构（可错→可纠），欧陆解构与制度批判同构（必然→不可纠）。二者解释力成反比地分配在”说服力”与”可用性”两端。

4.2 精确度差异：分析哲学能定位”错在哪一句”，欧陆只能说明”为何必然如此”

分析哲学逐句检验：P1 无证据、P2 循环、P3 不相干谬误、结论偷换概念——每一点都可独立反驳或成立。欧陆框架不做逐句检验，它做的是总体定性（工具理性、殖民化、例外状态）。前者是外科式的，后者是影像学的。在申诉状里，法官能执行的是”第3点不成立”，无法执行的是”你的系统被政治殖民了”。

4.3 主体地位差异（一个容易被忽略但后果严重）

分析哲学把被告人当作论证的对手方（其自辩被视为一套可检验的推理）。欧陆部分则把被告人当作哲学主体或象征人物——本真此在、向死而生者、真理的殉道者、事件的忠诚主体、否定性思维的践行者。

这产生一个策略性副作用：崇高化叙事把当事人写成”罕见的顶级心智”（材料 p930：”现代学术理性培育的顶级心智”），而罪刑法定与平等原则要保护的是不需要英雄叙事的普通公民。一旦辩护依赖”他是这样的学者”，就与判决依赖”他是这样的学者”（高学历=明知）形成同构——都在做身份论证。这与材料对判决的核心批评正面冲突。分析哲学路径没有这个问题，因为它只说”该命题无真值条件”，不涉及说这话的人是谁。

4.4 不可证伪性：波普尔式的反驳对欧陆框架无效

材料自身大量援引波普尔可证伪主义（p7069–7087），却未意识到：精神分析、马克思意识形态论、解构主义正是波普尔本人点名的不可证伪范式。用可证伪标准批评判决、同时采用一批不可证伪的框架来支持这一批评，是欧陆部分的方法论软肋。反例不可消化性具体表现为：若有人指出某转发者未被追诉，框架可答”这正是结构选择性打击的证明”——任何证据都被预先转化为对框架的确认。

五、欧陆独有而分析哲学没有的资源（四项，其中两项可用）

  1. ✅ 符码替换诊断（卢曼/托伊纳）——欧陆最有价值且可直接转化的贡献。 它指出：本案判决实际使用的区分标准不是”合法/不法”，而是”忠诚/冒犯”。这个论断的妙处在于它不是心理归因，而是对文本所用区分标准的客观描述——可直接从判决书用语举证（”对明知是侮辱、攻击国家领导核心以及我国现行政治体制的图片和文章进行转发”）。 转化写法（无需任何欧陆术语）：判决未适用第293条第(四)项的构成要件区分（是否起哄闹事、是否造成公共场所秩序严重混乱），而适用了该条文中并不存在的标准（是否冒犯领导核心与体制），故属适用法律确有错误（第253条第(三)项）。这是欧陆给出的、而分析哲学与科学都未给出的一个独立再审事由。

  2. ✅ 阿列克西的原则权衡与论证义务——可转为比例原则论证。 “言论自由 vs 公共秩序”的权衡框架，加上”目的正当性／适合性／必要性／均衡性”四步，是德国宪法实践的成熟工具，且中国法上有对应物（比例原则在行政法与宪法教义学中已被广泛接受）。本案的可执行版本：即便假定存在合法目的（维护网络秩序），以刑事手段处罚零传播的转发，也不满足必要性与均衡性；而材料所谓”零比例的暴政”，翻译成规范语言就是以近乎为零的证明强度压倒了宪法第35条的价值分量。

  3. ⚠️ 诠释学的”视域融合”→可降格使用。 其可用内核是一句朴素主张：法院未查明行为的意义与语境（为何转发、以何种态度转发），却径直作敌对意图归因——对应”主观要件事实未查清”。但”前见””视域””效果历史”术语必须全部删去，否则会读作文艺批评。

  4. ❌ Cover”判决即痛苦的施加”、齐泽克意识形态批判、巴迪乌事件论——只能用于学术写作。 Cover 的洞见（法律解释发生于暴力场域，主流法理学系统遮蔽之）在批判法学上是深刻的，但它否定的正是”判决可以通过说理自我约束”这一前提，而申诉状的全部功能恰恰建立在这个前提上。使用它等于拆掉自己脚下要踩的地板。

六、欧陆部分的失效模式（四条，均比分析哲学部分更硬）

  1. 外圈论证入状即策略性自伤。 “替罪羊/献祭/净化仪式/询唤/生命政治/例外状态/主权决断/资本逻辑”——任何一条写进申诉材料，都会被读作对司法制度整体的政治控诉，直接触发不予受理。材料 p508 其实已自察一处：把这类表述归为”不具备可立案性，仅属情绪性控告”。这个判断应当普遍化到整个外圈。

  2. 不可证伪性使它在交叉质询中毫无防御。 分析哲学的论证可以被逐句反驳；欧陆框架只能被整体接受或整体拒绝。法庭不会整体接受一个理论框架。因此欧陆部分在对抗性程序中注定失效，无论其解释力多高。

  3. 主体崇高化与平等保护互相削弱（见 4.3）。 最需要的主张恰恰相反：不必承认陈京元是罕见的理性主体，只需承认任何公民都不应因一次零传播的转发被定罪。建议在所有对外文本中把”独立学者／顶级心智”改为”普通网络用户／完全刑事责任能力人”——后者与判决用词一致，使反驳无余地。

  4. 概念误用的密度高于分析哲学部分，且更不易被读者察觉。 例如”延异”被用来指”能指滑动导致认定不确定”（德里达的 différance 不是这个用法）；”询唤”被用来指”给罪犯贴标签”（阿尔都塞指的是主体经由意识形态装置被构成，不是命名行为）；”空能指”被当作”定义模糊”的同义词（拉克劳意义上的 empty signifier 指无法被任何具体所指填满的结构性位置，而非语义不清）。这些挪用不影响修辞力量，但一旦遇到专业读者即整体失分——与分析哲学部分的证实原则反噬属同一类风险，只是暴露面积更大。

结语

汇编的欧陆部分在解释广度上远超分析哲学部分：后者只能说明这份判决在语言与逻辑上不成立，前者说明了这份判决为何可能——为何罪名必须模糊（空能指）、为何必须只办这一个人（结构功能）、为何不公开审理（反向可见性）、为何形式依法而实质决断（例外状态）、为何”高学历”同时是罪证又是禁言理由（符码冲突）。这是一份个案文书能被提升到何种理论位置的示范，也是本汇编在思想史与档案维度上最有分量的部分。

但两者在规范功能上并不互补，而是分工甚至对立：分析哲学解构预设”这是可以纠正的错误”，因而与再审制度同构；欧陆解构倾向于说明”这是结构的正常输出”，因而在逻辑上取消了纠正的必要性前提。欧陆部分的解释力越强，它作为诉讼武器的可用性就越低。

因此最终判断是：**欧陆哲学为这个案件提供了它应当被记住的理由，但没有提供它应当被改写的路径。**可改写的路径只有三条——分析哲学给出的”未形成可判定命题”、阿列克西与富勒给出的”未说理、未权衡、规则自相矛盾”、卢曼给出的”未适用自己的区分标准”；再配上科学支柱转化而来的实测证据。欧陆其余的部分，交给学术与档案，那是它真正的位置。

〇、地图与评级轴

罗素框架（《西方哲学史》1945 第一章）：确定知识属科学；超出最试探性表述之外的教条属神学；两者之间是无人之域——同时遭受科学、神学与形而上学三方攻击，这就是哲学。关键在常被略去的后半句：无人之域的居民必须只讲理由、不讲 certainty。

本案的映射约定：

  • 科学侧＝已确立的定理、定律、可测量数据；

  • 无人之域＝可给理由、可被反驳、不要求最终确定的论证（概念分析、规范论证、可错的经验概括）；

  • 神学侧（罗素意义上的”教条”）＝不可反驳、以权威或体认为根据的表述——包括天理/良知/道心式断言，也包括不可证伪的解释框架的教条化；

  • 判决书＝地图上的越境者：用”证据锁链””经梳理均属”的句式冒充科学侧确定性，用”领导核心不可冒犯””我觉得是谣言”的根据冒充神学侧不可错性，而它合法栖身所需遵守的无人之域规则（说理、举证、可复核）恰恰一条都未执行。

  • 第六支柱的地图位置需单列：它不在无人之域设防，也不从外部进攻神学侧，而是进入教义内部，取用其中残存的理性构件（实事求是、实践标准、制度根本性、法制统一、有错必纠、自我革命），用以审计该教义的执行人。故其效力条件不是”论据为真”，而是”承诺对执行者确有约束力”——一个政治前提，不是一个可证事实。

二、把总表读成一条防线：四种话术，四道边检

判决书任何一次自我辩护只会取四种形式，各自撞上一条边界——且第四条撞在不同的地点：

  1. “这是有证据支撑的事实断言”（”造成严重混乱”）→ 撞 Daubert 边防（中国对应：证据种类、完整性校验、鉴定程序、§55 排除合理怀疑）→ 科学支柱的实测证据包与概念区分拦截：无数据则连进入审查的门槛都未达到。拦截地：法庭。要求交出：数据。

  2. “这是不容置疑的价值真理”（”领导核心不可冒犯””法外之地论”）→ 撞 无人之域的规范责任（说理义务、权衡义务、明确性）→ 富勒八项＋阿列克西＋卢曼转化版拦截：价值断言不得冒充构成要件；未适用条文自身的区分标准即”适用法律确有错误”。拦截地：法庭。要求交出：理由。

  3. 两条都不走，径以权力宣告（”未提交新证据，驳回”）→ 这正是罗素所说无人之域遭受攻击的形态本身——撞程序刚性：§238 违反公开审判应当发回、§234 应开庭而不开庭、举证责任法定不得倒置。拦截地：法庭。要求交出：程序。

  4. “这是政治大局、维护核心、稳定所需”（第四种也是最后一种退路：不再谈事实、不再谈规范、不再谈程序，而谈政治站位）→ 前三道边检在此处都会松动，因为它们在法庭内部与政治话语没有共同语言。拦住它的只有 承诺边检：以该权威自己确立的公开承诺作尺——制度不因领导人看法与注意力而改变（反注意力式追诉）、实事求是与实践标准（反”我觉得是谣言”）、法制统一（反选择性追诉）、有错必纠与自我革命（反拒绝纠错）、”让人民群众在每一个司法案件中感受到公平正义”（反以稳定之名制造不义）。其结构是：不用外部价值反驳其政治理由，而用其政治理由的官方原文反驳其政治理由。 拦截地：不在法庭，在政治系统（政法委、纪检监察、人大、检察；并作为检察监督与依职权再审的递呈依据）。要求交出：一致性。

由此可得全案的元诊断：错判不是选错了答案，而是拒答了问题——它跳过的恰恰是无人之域的全部义务（定义、举证、说理、权衡、公开）。六类解构工具的互补性在于各自要求交出一样东西：科学要数据，分析哲学要理由，欧陆要制度说明，程序论要程序，诸子要名实相副，内部检验要言行一致——而六样它一样都没交。

四道边检的合成效果：前三道把判决逼回法庭内它唯一合法的位置（必须给理由的论证场），第四道把同一问题送到法庭之外的另一个机关（必须兑现承诺的政治系统）。这就是为什么本表既要有 A 级法条主张，也必须保留一条 A− 级政治通道——两者收件人不同，缺一则整案无出口。

三、诉讼装配线（按评级归堆后的唯一顺序）

第一步（A 级，入正文主干）——全部匿名化（不出现任何学者、定理、主义、领导人语录之名）：

  1. 结果要件零举证 → §55、§176：指控事实不清；

  2. “严重混乱”无可复核判定标准 → §3 明确性＋§253(三)；

  3. 范畴错位（观点/艺术≠可证伪事实）→ §253(三)；

  4. 应知≠明知、禁止身份推定 → 解释§140；

  5. 未适用构成要件标准而适用条文外标准（卢曼转化版）→ §253(三) 独立成由；

  6. 违反公开审判 → §238(一) 应当发回＋§253(四)；二审应开庭未开庭 → §234；

  7. 量刑不满足必要性与均衡性（阿列克西转化版）→ 畸重；

  8. 《刑法》§13 但书作退路主张。

第二步（B 级，须改造后进正文）：调取扣押设备→司法鉴定（传播量审计报告）→把分支过程从 C 升 A；页面公证＋无辟谣检索→”新证据”→ §253(一)；名家”名实相副”与法家”法莫如显/一断于法”内核以普通法言写入说理段（出处仅可留脚注，且建议不留）。

第三步（A− 级，第六支柱专用并行通道）——不替代第一、二步，另件另递：

  • 收件人：云南省/最高人民检察院（审判监督与检察建议）、省级以上监察机关（执法违法线索）、人大内司委与政法委（依职权再审的递呈）；

  • 内容：承诺-落差框架＋实事求是/实践标准＋法制统一＋有错必纠；

  • 写法要求：政治话语只作定性与动机说明，每一项落点仍须绑定一条 §253/§254 法定事由；

  • 两条装置必须照搬：①边界检验节（自列最强控方论证并驳倒）；②诚实声明节（依据材料范围、未经独立核验、”查明/认定”仅指文书记载）。这两项是本支柱对全部对外文书的形式贡献。

第四步（C 级，说理背景，限两句以内、零术语）：偏见机制→程序保障不可省略之理；视域融合→未查明语境；工具理性→以效率代审查；格物/梳理→未经核实即认定；两类矛盾→思想认识问题不宜以刑事强制解决（须同引防扩大化限定）。

第五步（D 级，一律不入件）：CAP、熵隐喻、未施测人格与道德阶段、对办案人员的一切病理/神学式诊断、欧陆外圈（询唤/献祭/例外状态/延异）、儒道释心性话语、领导人语录引文（转译后可用，引文本身不入）。

第六步（D 级，最高危，须物理分隔）：极左文体段落（发动群众、打倒司法黑帮、资产阶级法权、斗争先声，p1710/1788/1874/1924/1952）。此类段落即使单独成件也不递出；若为历史面貌保留，只入档案附件，与任何递交通道隔离。

第七步（D 级，但为全书所当留）：教门劝慰与《言骚》骈文、以及第六支柱的九套理论批量重述——它们是这部档案作为中文对一桩冤案的道德-历史定性与官方话语落差样本的不可替代部分；罗素地图上它们属神学侧与文学，本就不欠论证一个交代——它们回答的不是”此判决为何无效”，而是”此事为何不可忘、此类落差为何会在最细密的规范时代发生”。

结语：谱系的一句话总纲

按罗素地图重排后，这部 10194 页汇编的全部方法野心可以收成一句：

它发动了整张知识地图上的一切法院来审判一桩判决，最终发现只有法庭内的那个机关有管辖权——而它受理的从来不是”哪套理论为真”，只有两样东西：证据与程序。 科学解构的价值在于把自己转化为证据（鉴定），哲学解构的价值在于把自己翻译为程序请求（发回、开庭、说理），诸子解构的价值在于证明连最工具主义的传统都不认这份判决，而第六支解构的价值在于：它是唯一一支不引入任何外部标准、只把判决方的承诺原样递回其手中的——因此也是唯一能给整份材料换上一件在收件人面前最不易被拒收外衣的。 五者共同的伦理，仍是无人之域的那条古老戒律：只讲理由，不讲 certainty；要求别人如此，自己先如此。
