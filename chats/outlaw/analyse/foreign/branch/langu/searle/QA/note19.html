如何解释法律等“制度性事实”的建构过程

约翰·塞尔（John Searle）在其社会本体论（Social Ontology）中，致力于解答一个根本问题：“人类社会的制度现实（如货币、法律、国家、婚姻等）是如何通过心智与语言被建构出来的？”。他结合 “构成性规则”（Constitutive Rules）公式与 “集体意向性”（Collective Intentionality）理论，对这一建构过程给出了系统性的解释：

一、 奠基前提：粗糙事实与制度性事实的区分

塞尔将世界上的事实划分为两大类：

  1. 粗糙事实 / 无情性事实（Brute Facts）：独立于人类意识、语言与意向性而客观存在的物理现实（如山川的存在或客观物理运动）。

  2. 制度性事实（Institutional Facts）：依赖于人类共同体的同意、语言与社会规则才得以存在的社会现实（如货币、法律、产权、婚姻和国家领土等）。

制度性事实的建构解答了“一张纸为何能成为货币”或“一块土地为何能成为国家领土”的社会生成机制。

二、 核心公式：构成性规则“X 在情境 C 中算作 Y”

塞尔指出，制度性事实建构的核心机制在于构成性规则，其基本逻辑公式表达为 “X 在情境 C 中算作 Y”（X counts as Y in context C）：

  • X（基础实体或行为）：指基础的客观存在、物理实体或符号动作（如一张印有特定图案的纸片、一段物理土地或说出一句话）。

  • C（背景语境）：指特定的制度框架、背景情境或社会规则体系（如金融市场体系、国际秩序或法律制度）。

  • Y（地位与功能赋予）：指在语境 C 中被社会赋予 X 的全新地位、社会功能与道义权力（Deontic Powers）（如赋予相关主体权利、义务、责任与许可）。

三、 对货币、国家与法律的建构过程解释

塞尔运用这一公式，具体阐释了不同制度性事实的生成：

  1. 货币的建构：在金融市场或经济体系（C）中，一张特定材质和图案的纸片（X），被赋予了交易支付的功能与地位，从而“算作”法定货币（Y），并赋予持有者“购买”的道义权力。

  2. 国家与领土的建构：在国际秩序或政治制度框架（C）中，某块具体的物理土地（X），被赋予主权与行政管辖的地位功能，从而“算作”国家领土（Y）。

  3. 法律与规范的建构：在法律制度或司法裁决语境（C）中，特定的行为（X）在满足明确的法定条件时，被规范界定并“算作”犯罪或违法行为（Y），进而产生具体的法律后果与道义惩罚/合规义务。

四、 关键动力机制：集体意向性（Collective Intentionality）

构成性规则“X 算作 Y”之所以能够创造社会现实，并非取决于 X 自身的物理属性，而是取决于集体意向性（Collective Intentionality / We-intentionality）：

  • 集体接受与承认：制度性事实的存续完全依赖于社会共同体成员对构成性规则的共同接受、同意与承认。只有当群体共同认可某种物理实体或行为具备 Y 功能时，该制度性事实才具备客观的社会效力。

  • 共享共识：集体意向性使法律与制度成为“我们的规则”和共享共识，而非单方面强加的暴力命令。

五、 宣告式言语行为与制度合法性边界

塞尔进一步将语言哲学与社会本体论连接，指出制度性事实通常通过 宣告式言语行为（Declarative Speech Acts） 在社会现实层面被创设与宣告（如通过主婚人宣读或法官判决）。

然而，宣告性言语行为创设制度事实必须依赖集体意向性的支撑与适当的语境 C（如经验事实与法定条件）。如果权威机构强行垄断宣告权，在缺乏客观事实证据或背离社会共同体集体共识的情况下单方宣告“X 算作 Y”，就会脱离集体意向性，制造出虚假的制度性事实。这种脱离共识的单方宣告将引发制度信任崩塌，使制度性事实退化为单纯的“暴力事实”。
