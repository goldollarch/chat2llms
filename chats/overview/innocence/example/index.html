    • 二、附件目前最需要修正的几个地方
      • 1. “网络寻衅滋事罪是典型结果犯”表述宜更加严谨
      • 2. 不要说 Cohen 公式“证明边缘节点结构性隔离”
      • 3. Galton-Watson 的“100%灭绝”不能等于“绝不可能产生危害结果”
      • 4. FDT这一段建议删除或者降为附录
    • 三、真正应该强化的是“证据结构”
    • 四、还有一个非常重要的再审策略调整
    • 五、再审法律依据也应改得更准确
    • 六、我建议改成下面这个版本
      • 一、再审申请的核心理由
      • 二、本案首先必须回答的不是“申请人是否转发”，而是“法定危害结果究竟是什么”
      • 三、原判对“公共秩序严重混乱”的认定，应当接受严格的事实审查
      • 四、所谓“转发行为→严重混乱”的因果链不能以时间先后代替证明
      • 五、复杂网络科学可以作为因果审查的辅助工具，但不能替代证据
      • 六、关于无标度网络与Cohen临界阈值理论
      • 七、关于分支过程：其价值在于建立可检验的传播动力学假设
      • 八、“蝴蝶效应”不能替代具体因果证明
      • 九、对“明知”要件的审查：不能以“高学历”直接替代具体主观证据
      • 十、申请人的专业知识不应当成为“双重标准”的依据
      • 十一、涉案信息的性质也应当逐条审查
      • 十二、关于申请人刑满后对涉案信息传播状态的观察
      • 十三、真正的再审核心：即使不采纳任何复杂系统理论，原判仍应接受证据审查
      • 十四、再审理由与《刑事诉讼法》第二百五十三条的对应关系
      • 十五、结论
