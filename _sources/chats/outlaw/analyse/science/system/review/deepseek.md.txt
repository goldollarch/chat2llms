### 〇 分析基座

本卷讨论的全部科学论证，都围绕一个问题：**"转发行为造成公共秩序严重混乱"这个断言，由谁证明、证明到什么程度。**

#### 〇.1 举证责任的归属

| 主体                     | 义务                                                                                                             | 依据                     |
| ------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------ |
| **人民检察院**     | 承担被告人有罪的全部举证责任，包括**行为、后果、因果关系、主观明知**；须达到"证据确实、充分，排除合理怀疑" | 刑诉法第 51 条、第 55 条 |
| **被告人／辩护人** | **不负证明自己无罪的义务**；提出辩解、提出合理怀疑即为已足                                                 | 无罪推定（第 12 条）     |
| **人民法院**       | 证据不足、不能认定被告人有罪的，**应当**作出无罪判决                                                       | 刑诉法第 200 条第 3 项   |

#### 〇.2 这一归属对科学论证的意义

科学论证在本案中有三处可能的位置，法律地位完全不同：

| 位置                                 | 谁在用 | 法律功能           | 判断标准                               |
| ------------------------------------ | ------ | ------------------ | -------------------------------------- |
| **证明"严重混乱已经发生"**     | 控方   | 结果要件的证明     | 须达排除合理怀疑；须有数据与基线       |
| **证明"该结果由被告行为造成"** | 控方   | 因果关系的证明     | 须排除其他原因；须有传播路径与规模     |
| **提出"控方无法完成上述证明"** | 辩方   | 质疑；形成合理怀疑 | **只需使事实存疑，不负证明义务** |

**由此产生一条贯穿全篇的判断规则**：

> 凡本卷出现"数字""参数""模型推定"，先问是**控方用来证明要件**，还是**辩方用来演示控方缺少什么**。前者不足即为举证失败；后者不足只影响说服力，**不构成举证瑕疵**。

#### 〇.3 三条禁令

1. 不得因辩方参数是估算值，就认为因果关系成立。
2. 不得把"辩方无法证明后果未发生"当作"后果已发生"的依据。
3. 不得以侦查机关的"梳理""认定"这类判断性材料替代数据与鉴定。

### 一、总览：科学论证的四层结构

```
┌─ 第 0 层  本体论 ───────────────────────────────────┐
│  命题：混乱是系统的内禀属性，"严重混乱"不是可观察事件  │
│  工具：热力学第二定律、CAP 定理、无标度网络            │
│  法律功能：指出结果要件的对象不明                      │
└──────────────────┬─────────────────────────────────┘
                   ▼
┌─ 第 1 层  传导机制 ─────────────────────────────────┐
│  命题：即便有扰动，也必被耗散，跨不过尺度              │
│  工具：涨落-耗散定理、分支过程、自组织临界、渗流        │
│  法律功能：指出"行为→结果"的事实链缺乏环节            │
└──────────────────┬─────────────────────────────────┘
                   ▼
┌─ 第 2 层  归责结构 ─────────────────────────────────┐
│  命题：归责须跨三道门槛，本案三道全未跨                │
│  工具：临界门控、响应函数、尺度分离                    │
│  法律功能：把因果关系拆成**控方须证明的三件事**        │
└──────────────────┬─────────────────────────────────┘
                   ▼
┌─ 第 3 层  证明与证据 ───────────────────────────────┐
│  命题：概率→0 构成合理怀疑；举证责任在控方             │
│  工具：概率论、贝叶斯、相对熵、Daubert 五基准          │
│  法律功能：给出证据审查的判准                          │
└────────────────────────────────────────────────────┘
```

**这个结构最值得注意的地方在第 2 层**：它表面在讲物理，实际做的是把"因果关系"翻译成一张**控方的举证清单**。这是本卷最重要的贡献。

### 二、第 0 层：混乱是常态

#### 2.1 热力学第二定律 → 内禀涨落

**论证**：绝对零度不可达，因此在任何有限温度下微观自由度必然存在无规则热运动。这种"不一致"与"局部混乱"不是外部异己分子制造的病态结果，而是**系统维持运行的内禀属性与基线常态**。社会系统是"位于有序与混沌之间的复杂适应系统"，长尾效应与无标度性都是这种无序性的表征（p15–16）。

**法律功能**：刑法上的"损害"必须是可归因于行为的**增量**，而非系统本来就有的**基线状态**。这一步在追问一个控方必须回答的问题：**如果不转发，世界的混乱度是多少？**——而卷宗里没有任何基线测量。

#### 2.2 CAP 定理 → 有序网络不可达

**论证**：分布式系统不可能同时满足一致性、可用性、分区容错性，也不存在确定性算法在一般运行环境下达成共识（p15–16、p2102–2138）。

**法律功能**：把"秩序"从一个可测量的物理状态，改写成一个不可达的理想极限。若理想态不存在，"偏离理想态"也就无从测量。

**一处必须记录的自我限定**：Qwen 在 p2105 自认"CAP 定理原生于分布式数据库/计算机网络架构……将其直接等同于'社会秩序必然无序'属于**概念隐喻，非严格科学推论**"。

#### 2.3 无标度网络 → 极端异质与长尾

**论证**（引 Cohen 等）：无标度网络度分布为重尾。按渗流模型，阈值为 p_c = 1 − ⟨k⟩/(⟨k²⟩ − ⟨k⟩)；当度指数 γ ≤ 3 时 ⟨k²⟩ 发散，f_c → 1——**即"把所有边缘节点全部移除也不影响连通性"**（p2139–2160）。

**法律功能**：本案被告正是这样一个边缘节点（关注者约 92 人），在**结构上**不具备影响系统整体连通性的能力。

#### 2.4 这一层的边界

三件工具共同做一件事：**指出"公共秩序严重混乱"这个结果要件的对象不明确**。

但它不能证明"后果未发生"。法律上的"秩序混乱"从来不指"偏离热力学平衡态"，而指**可观察的社会功能紊乱**（交通中断、公共机构瘫痪、群体冲突、应急响应启动）。把"熵"等同于"秩序混乱"是一次概念替换。

**因此这一层的正确用法是提问，不是结论**：

> "控方所说的'严重混乱'，其操作化指标是什么？基线是什么？测量方式是什么？"

——这三个问题都属于控方的举证范围。

### 三、第 1 层：微扰为什么必然衰减

四件工具**串联**成一道闸门。

#### 3.1 涨落-耗散定理（FDT）

**数学形式**（文档写法）：ΔA = χ · δf，其中 δf 为微观涨落、χ 为响应函数/磁化率、ΔA 为宏观响应；并给出 χ(ω) ∝ S(ω)/(k_B T)（p2027–2028）。

> *技术注*：严格形式为 S(ω) = (2k_BT/ω)·Im χ(ω)（经典极限）。文档中的写法是略去频率因子与虚部的示意式，不影响论证方向，但正式文书应写严格式。

**物理含义**：在耗散主导的稳态系统中，涨落的宏观响应受限于 χ。若系统处亚临界区（χ 有限）且耗散率 γ ≫ 0，则扰动必指数衰减（δA(t) ∝ e^(−γt)）。

**三重映射**：

| 物理量      | 本案对应                                                     | 刑法要件                 |
| ----------- | ------------------------------------------------------------ | ------------------------ |
| 涨落 δf    | 零星转发（关注者 <100、互动≈0、总量 <100 次）               | 被指控的"行为"           |
| 耗散 γ     | 平台限流、注意力衰减、算法过滤、事实核查、法律阈值、认知疲劳 | 社会秩序的韧性           |
| 响应函数 χ | 信息放大系数、舆情敏感度                                     | "造成混乱"的因果能力     |
| 临界性      | 仅当控制参数越阈值、χ → ∞ 时才可触发相变                  | 结果犯的"现实危险性"前提 |

**由此提出"控方论证的三重断裂"**（p2028–2029）：

1. **响应函数误设**：控方隐含假设任意转发都能无衰减传导至宏观态，即默认 χ → ∞，而卷宗无任何临界参数记录（无热度峰值、无跨平台共振、无线下聚集）；
2. **耗散机制无视**：抹掉了社交网络内生的全部阻尼通道；
3. **尺度混淆**：以微观噪声替代宏观相变，转发量低于日活噪声量级，信噪比 SNR ≪ 1。

**法律功能**：这三重断裂与客观归责三阶层形式上同构，可用作**审查控方因果论证的清单**。

#### 3.2 分支过程（Galton-Watson）：级联必然灭绝

**数学**：把信息传播建模为分支过程，每个个体平均产生 m 个新个体（平均分支数）。灭绝概率 q 是概率生成函数 q = G(q) 的最小非负根。

**关键定理**：当 **m ≤ 1** 时 q = 1——级联以概率 1 灭绝。

**本案参数化**（p2185 附近）：

```
m = k × p_转发 × (1 − 衰减率)
  = 15（活跃关注者）× 0.01（转发率）× 0.8（留存）
  = 0.12
```

m = 0.12 ≪ 1，处**深度亚临界区**；据此得出引发雪崩的概率趋近于零，95% 分位数仅 3 次传播。

**这一步的性质**：它是全套论证中唯一的"数学定理"而非类比——m < 1 ⇒ 灭绝概率 = 1 是严格结论。但结论依赖于**输入**，而输入（15、0.01、0.8）是估算值。

**这一点如何看待，见第八章**（辩方材料的法律地位）。

#### 3.3 自组织临界性（SOC）：临界门控

**理论**（Bak、Tang、Wiesenfeld，1987）：复杂系统会自组织到临界态；临界态下微扰可引发任意规模的雪崩，规模服从幂律分布；此时响应函数发散（p2161–2184）。

**法律功能**：只有在系统已处临界态时，一个边缘节点的微扰才可能被放大为宏观事件。反过来，**控方若主张因果成立，必须先证明系统处于临界态**——这是一项具体的举证要求。

**最具原创性的一句**（p2067）：**"被放大 ≠ 被造成。"** 即便某次转发恰在雪崩起点，真正的原因是系统已处临界态。

#### 3.4 尺度分离与蝴蝶效应的适用边界

**一个主动的自我限制**（p16）：蝴蝶效应"只是一种简化理论模型，在现实世界中并不成立"。

并设定反驳条件：若控方主张"最后一根稻草"，**须同时证明**①系统已处超临界饱和 ②该行为是必要且不可替代的条件。而卷宗"两项硬核数据均完全空白"（p865）。

**这一步的法律意义最大**：它把举证负担明确地放回了控方一侧——不是"我证明我无关"，而是"你要主张稻草压垮骆驼，就得证明骆驼已经满载，且这一根不可替代"。

#### 3.5 第 1 层的逻辑结构

```
扰动是否进入临界区？ ──m<1（分支过程）──▶ 必灭绝
        │m≥1
        ▼
系统是否处于临界态？ ──χ有限（FDT）──▶ 必衰减
        │χ→∞
        ▼
因果是否可追踪？ ──尺度分离（渗流）──▶ 不可归因
        │可追踪
        ▼
      归责成立
```

任一环节不通，归责即不成立。本案三环全不通——而**证明三环皆通的责任在控方**。

### 四、第 2 层：三重门控 —— 本卷最实质的贡献

把第 1 层翻译成教义学语言，得到一张**控方举证清单**：

| 门槛                         | 科学表述                                            | 控方须证明什么                               | 本案卷宗                             |
| ---------------------------- | --------------------------------------------------- | -------------------------------------------- | ------------------------------------ |
| **门槛一：临界态**     | 须满足 m ≥ 1、高连通、情绪共振、算法强推、现实张力 | 行为创设了"法不容许的风险"，而非介入既有风险 | **无临界参数记录**             |
| **门槛二：响应发散**   | χ → ∞ 须有证据                                   | 结果发生的相当性或高度盖然性                 | **χ 处常规有限值，无测量**    |
| **门槛三：因果可追踪** | 须有传播拓扑、路径、规模数据                        | 排除其他原因；风险确实实现                   | **无拓扑、无路径、无排他分析** |

**这张表的价值在于它把"因果关系"从哲学争论降为三张数据表。** 控方要么提交，要么承认未举证——而依刑诉法第 51、55 条，未举证的后果是疑罪从无，不是"由辩方补正"。

**它的反向用法**：若坚持归责，则按同一标准，公权力机关的滥权行为才是真正的超临界扰动源（p2163、p2176）。这属于辩方的**质疑性论证**，不承担证明义务。

### 五、建模一节：辩方反证的地位

`models`（p2185–2234）把类比升级为可计算模型。

| 模型     | 参数与结论                                                                                                                                                                     | 页码        |
| -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------- |
| Qwen     | m = 15×0.01×0.8×1.0 = **0.12**；q = 1.000000；95% 分位 3 次；敏感性极端情景 m = **1.08**、q = **0.76**、爆发率 24%；附完整 Python（不动点迭代＋蒙特卡洛） | p2185–2198 |
| ChatGPT  | 最小 Galton-Watson 模型，λ ∈ [0.01, 0.05]                                                                                                                                    | p2199       |
| Copilot  | R₀ = 50 × 0.001 = 0.05；并把**诽谤罪**的"转发 500/浏览 5000"直接当寻衅滋事门槛（p2214）                                                                                | p2211       |
| DeepSeek | 断言概率 **< 10⁻¹⁰**                                                                                                                                                  | p2219       |
| Gemini   | 称雪崩为 "Forbidden Transition"，P ≈ **10⁻⁸**                                                                                                                         | p2226       |
| Grok     | 给 m = 0.001 → 1.5 的精确数值表                                                                                                                                               | p2230       |

#### 5.1 这些数字在法律上是什么

**它们不是"证据"，是"反证推演"。**

辩方不负举证义务。辩方提出"若平均分支数小于 1，则级联必然灭绝"，其法律功能是把一个问题摆到台面上：**要认定本案的因果关系，需要哪一类数据？** 而提供这类数据是控方的事。

因此：

- 参数是估算值 → **不构成辩方的举证瑕疵**；
- 参数不精确 → 只影响"这个演示是否直观"，不影响"控方是否完成举证"；
- 只要"若 m<1 则灭绝"这个定理成立，辩方就已经提出了一个控方必须回应的质疑。

#### 5.2 唯一值得提醒的是表述形式

若把"若参数如此，则概率趋零"写成"q = 1.000000"，是把**条件句**写成**陈述句**、把**假设**写成**测量**。这不会产生法律上的不利后果，但会产生一个实际风险：对方只需一句"参数从哪来"，就能把整段整体搁置，而不必回应其中的逻辑。

**更稳的写法**（也是更符合辩方地位的写法）：

> "若平均分支数小于 1，则级联必然灭绝；本案卷宗缺乏计算该参数所需的任何数据，故控方无法完成因果证明。"

这不是"承认我没证明"，而是**把举证责任归位**。

#### 5.3 一处法条误用

Copilot 把 2013 年《两高解释》**第 2 条诽谤罪**的"转发 500 次／浏览 5000 次"当作网络寻衅滋事的入罪门槛（p2214）。该数字针对的是诽谤罪的"情节严重"认定，不是本罪要件。这类误用在全书至少 6 处。

### 六、哥德尔一节：从客观要件转向主观

`Godel`（p2235–2263）攻击点不在后果，而在"明知"。

**论证链**：形式系统的不完备性 → 任何知识体系都存在不可判定命题 → 不存在"完备且确定"的真理状态 → 因而不存在"明知某表达为虚假"的确定心理状态 → 控方"高学历⇒应知⇒明知"不成立。

**六家对定理的陈述均准确**，但对推论的态度分裂：

| 模型                  | 态度                                                                                                                                                                                        |
| --------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Qwen、Copilot、Gemini | 基本接受推论                                                                                                                                                                                |
| DeepSeek              | 取中道                                                                                                                                                                                      |
| **ChatGPT**     | 正面反驳（p2245–2248）：适用范围被扩大；法律上的"明知"采**实践理性标准**；否则一切认知类犯罪都无法成立。结论："**哥德尔可以证明'人不可能绝对确定'，但不能证明'人不可能明知'**" |

**这一节是全书自我批评最集中的地方**：ChatGPT 的这段话，等于替控方给出了最强的回应。

**从举证角度看**：哥德尔一节的真正用途不是"证明被告不知道"，而是**指出控方的"明知"认定缺少任何外部指标**——它只有一个基础事实（学历）。这在辩方地位上完全成立。

### 七、证据科学部分（`analytic` 卷 p7001–7441）

这一部分不属于物理学，但它直接处理**控方证据的审查标准**，实践价值最高。

#### 7.1 Daubert 五基准（p7172–7219）

**五基准**：① 可检验 ② 已知错误率 ③ 同行评议 ④ 普遍接受 ⑤ 技术可靠。

**做法**：先自限（"不直接适用于中国刑事诉讼……仅作方法论标尺"，p7174），再给出控方五项全不通过、辩方五项全通过的矩阵（p7175–77）。

**最有价值的是与国内规范的对接**（p7176–77）：

| 对接点                  | 内容                                           |
| ----------------------- | ---------------------------------------------- |
| 刑诉法第 50 条          | 证据种类法定——"梳理情况说明"不属其中任何一种 |
| 刑诉法第 55 条          | 证据确实、充分，排除合理怀疑                   |
| 《刑诉法解释》第 101 条 | **"情况说明"不得单独作为定案依据**       |

**这三条对接是本卷唯一可以写进裁判文书的表述。**

#### 7.2 因果论（p7220–7260）

条件说 → 相当性（休谟恒常联结）→ 反事实（刘易斯）→ 客观归责（罗克辛三要件），配 Galton-Watson 与 **D_KL(P‖Q) ≈ 0**（相对熵趋零表示证据几乎不更新判断）。

**D_KL 那一步很巧妙**：它把"这批证据没有证明力"这个定性判断，变成"证据对假设置信分布的更新量趋零"这个可表述的量化描述。

#### 7.3 贝叶斯主义（p7260–7281）

三个病灶：**先验误置**（把"内容敏感"当作"虚假"的高先验）、**似然比扭曲**（把"学历"当作高似然比证据）、**拒绝更新**（辩方提出反证后后验未变）。

它不要求法院接受贝叶斯定理，只要求法院说明它的证据如何改变了判断——这是裁判说理的最低要求。

#### 7.4 科学实在论（p7424–7441）

"无奇迹论证"反向应用为"**反实在论司法**"：判决若不以"事实"为对象，而以"信念"为对象，则它是非实在论的。

结语：**"事实导向法治 → 信仰导向法治。"**

### 九、L2：辩方科学论证的法律地位

辩方不负举证义务。这一节只判断"其材料是否足以形成合理怀疑"。

| 辩方论证                | 法律功能                     | 是否足以形成怀疑                     |
| ----------------------- | ---------------------------- | ------------------------------------ |
| 四层结构与三重门控      | 指出控方须证明哪三件事       | **足以**（这是一个清单）       |
| 分支过程（m<1 ⇒ 灭绝） | 演示"级联不可能"的条件       | **足以**（定理成立，条件待查） |
| "被放大 ≠ 被造成"      | 区分触发与原因               | **足以**（这是归责结构的要害） |
| 蝴蝶效应的反驳条件      | 把"稻草论"的证明责任推回控方 | **足以**（举证责任归位）       |
| 贝叶斯三病灶            | 指出控方证据未更新判断       | **足以**                       |

#### 9.1 关于"参数是估算"的正确表述

辩方用估算参数**不构成举证瑕疵**。正确的表述是三层：

1. **法律层**：辩方不负举证义务，提出反证推演即为已足；
2. **证明责任层**：参数之所以是估算，是因为**控方从未提供任何平台数据**；缺数据的一方是控方。
3. **说服力层**：把假设写成确定值（"q = 1.000000"）会削弱说服力，建议改为条件式。

**只有第 3 层是对辩方的评价，而它不是"缺陷"，是"表述风险"。**

#### 9.2 关于"多理论得出同一结论"

辩方只需要合理怀疑，不需要"独立证据来源"。六个不同理论各自提出同一个怀疑，法律上完全成立——它们是**同一怀疑的多重表述**。

因此：

- 把它当作"交叉验证"（编者评注的做法）没有必要；
- 把它当作"缺乏独立性、不构成证据"（批评者的做法）则属于**把独立证据的要求套到辩方身上**，同样是举证责任倒置。

### 十、表述层面的三点提醒（L2，不是缺陷）

| ## | 表述                                                | 风险                                                       | 建议                                                 |
| -- | --------------------------------------------------- | ---------------------------------------------------------- | ---------------------------------------------------- |
| 1  | 把"概率→0"写成"不可能"                             | 后者是对否定性事实的断言，容易招来"请证明绝对不可能"的追问 | 写"概率趋近于零，已足以形成合理怀疑"                 |

### 十一、一句话总结

> 这一卷真正做成的，是把"因果关系"从一句断言变成一张清单：**要认定"转发造成严重混乱"，控方必须证明——系统处于临界态、该行为创设了风险、传播路径可追踪、结果可测量、其他原因可排除。**
>
> 卷宗在这五项上全部空白。而依刑诉法第 51、55、200 条，空白的一方承担后果。
>
> 至于辩方的估算参数、模型推演、概率表述，它们不是证据，也不需要是证据——它们的功能是**把这张清单摆到桌面上**。把"清单提出者"当作"举证义务人"，是举证责任的倒置。

### 〇 分析基座

#### 〇.1 举证责任的归属

| 主体                     | 义务                                                                                                 | 依据                     |
| ------------------------ | ---------------------------------------------------------------------------------------------------- | ------------------------ |
| **人民检察院**     | 承担被告人有罪的全部举证责任，包括**主观明知与犯罪动机**；须达到"证据确实、充分，排除合理怀疑" | 刑诉法第 51 条、第 55 条 |
| **被告人／辩护人** | **不负证明自己无罪的义务**；提出辩解、提出合理怀疑即为已足                                     | 无罪推定（第 12 条）     |
| **人民法院**       | 证据不足、不能认定被告人有罪的，**应当**作出无罪判决                                           | 刑诉法第 200 条第 3 项   |

#### 〇.2 心理学在本案中的三个可能位置

| 位置                         | 谁在用             | 法律功能             | 判断标准                                 |
| ---------------------------- | ------------------ | -------------------- | ---------------------------------------- |
| **证明"他明知且恶意"** | 控方               | 主观要件的证明       | 须有外部指标；须排除合理怀疑             |
| **解释"确信如何形成"** | 辩方               | 质疑；说明推定不可靠 | **只需使"明知"存疑，不负证明义务** |
| **给出人格评分与诊断** | 双方（主要是辩方） | 无证据地位           | 无量表、无访谈即无证明力                 |

**由此产生贯穿全篇的规则**：

> 凡本卷出现"人格评分""诊断""机制分析"，先问它是**控方用来证明明知**，还是**辩方用来解释确信**，还是**模型在无数据时的表现**。三者法律地位不同，不可混评。

#### 〇.3 三条禁令

1. 不得因辩方无法证明"他不可能明知"，就认定"他明知"。
2. 不得把"学历"这一基础事实直接当作"明知"的证明。
3. 不得以"专家可以做心理分析"为由，替代对主观要件的举证。

### 二、这套论证的总结构：两个方向

它不是"证明被告无罪"，而是一个**双向操作**：

```
        正向：指出"明知"缺少任何外部指标
   ┌──────────────────────────────────────────┐
   │ 心理状态不可观察 → 明知只能是推断 →      │
   │ 推断依赖启发式 → 启发式在个案中被污染    │
   └───────────────────┬──────────────────────┘
                       │
                       ▼
        「法官眼里的'明知'，是一台偏差机器的输出」
                       │
   ┌───────────────────┴──────────────────────┐
   │   反向：把"确信"解释为一个可描述的心理事件  │
   │ 确认偏误 → 动机性推理 → 决策疲劳 →      │
   │ 后见之明 → 程序正义崩塌 → 自我确信      │
   └──────────────────────────────────────────┘
```

**这个镜像结构是全部 114 节的骨架**。它不需要证明"被告不知道自己做了什么"——那会落入"辩方自证无罪"的陷阱；它只需指出**控方的"明知"认定没有任何外部指标**，从而在主观要件上形成合理怀疑。

按功能分五组：

| 组               | 攻击或建构对象     | 主要分支                             |
| ---------------- | ------------------ | ------------------------------------ |
| **A 前提** | "明知"的可观察性   | general、cognitive                   |
| **B 明知** | 被告的认知状态     | cognitive、general、personal         |
| **C 恶意** | 被告的动机结构     | dynamic、motivation、humanistic      |
| **D 确信** | 办案人员的判断过程 | **forensic**、social、cultural |
| **E 处境** | 被告的心理状态     | Develop、positive、health、emotion   |

### 三、A 组前提：心理状态不可观察

**论证**：一个人的心理状态不能被直接观察，只能通过三类外部指标推断——此前行为、被告知后的反应、事后复述的理由。本案**三类一样没有**，只有"学历"这一与具体认知内容无关的属性。

**这一点的法律意义很明确**：它指向的是**控方举证的空白**。依刑诉法第 51、55 条，控方须以证据证明"明知"；而卷内关于"明知"的全部内容，是判决书的一句话："具有很高的学历和知识水平……应辨别是非"。

**学历能证明什么**：认知能力。
**学历不能证明什么**：在某一特定时刻、对某一条特定内容、形成了"它是假的"这一具体判断。

用能力推定内容，是"应当知道"冒充"明知"。

#### 3.1 元认知与邓宁-克鲁格效应

**理论**：能力低者高估自身能力，且因缺乏元认知而无法察觉自己的错误。

**本案映射**（p2264、p25）：被告自述"正如柏拉图所言我也只是被囚禁在洞穴中的一个囚徒而已"，以"洞穴中的囚徒"自况显示元认知；判决书作者被指为邓宁-克鲁格效应的典型。

**评价**：这一条属于修辞。它能增强读者的印象，但不能作为论证——因为对裁判者作认知能力评价，本身就不在心理学可支持的范围之内。

#### 3.2 系统 1／系统 2 的错位

**理论**：卡尼曼的双系统理论——系统 1 快速、直觉、情绪化；系统 2 缓慢、审慎、逻辑化。

**本案映射**（p2341）：

> "他越是'理性'（系统 2），就越被系统视为'威胁'；司法者越是'非理性'（系统 1），就越被制度奖励为'高效'。"

**双向应用**：对被告，学者的系统 2 运作（核实、比较、存疑）被解读为"狡猾""诡辩"；对司法者，系统 1 的"敏感内容→可疑→有罪"捷径被制度奖励为"办案效率"。

**法律功能**：正当的司法判断应是系统 2 的产物（审慎、可复核、有说理）。判决书只有一句结论性表述而无推演，在形式上就是系统 1 的输出。这是一个关于**说理义务**的观察，落在程序而非心理。

#### 3.3 认知闭合需求与情绪启发式

**理论**：认知闭合需求——在不确定情境下急于获得确定答案；情绪启发式——以情绪反应替代事实核查。

**本案映射**（p2269）：

> "情绪启发式：对'敏感内容'的负面情绪直接输出定罪结论，跳过事实核查与逻辑推演。"

**法律功能**：这是对"以政治评价替代法益判断"的心理学描述。判决先说内容"侮辱、攻击领导核心"（情绪反应），随即跳到"经梳理均属于虚假信息"（事实结论），中间无核查环节——而这个核查环节，正是控方举证义务的内容。

### 四、C 组：恶意与动机

#### 4.1 本我—自我—超我的双向对照（dynamic，p2504–2532）

| 结构 | 办案人员                     | 被告                           |
| ---- | ---------------------------- | ------------------------------ |
| 本我 | 恐惧（怕追责、怕上级）       | 求知欲、表达欲                 |
| 自我 | 防御性运作（找理由、找依据） | 现实性运作（核实、评估风险）   |
| 超我 | 权威型（"上级""核心""体制"） | 开放型（学术共同体、普遍价值） |

结论（p2505–2506）：被告是**成熟型防御**（升华、理智化），司法方是**神经症型防御**（投射、合理化、否认）。

**评价**：这一节把"恶意"反转成"恐惧"——法官不是害人，而是在自保。修辞上极有穿透力。但精神分析不是可证伪的经验科学，其概念无法独立测量，因此**解释力强、证明力接近零**。它适合作为"动机的另一种可能解释"，不能作为"恶意不存在"的证明。

同样的意思用更朴素的话说得更清楚（p2301）：

> "司法人员可能更恐惧'追责不力'带来的职业风险，而非'错判一个无辜者'的道德风险。"

#### 4.2 动机结构：准确性动机 vs 方向性动机（motivation，p2998–3024）

**理论**：Kruglanski 的认知动机理论——准确性动机（求正确）与方向性动机（求特定结论）。

**本案映射**（p2999）：控方行为模式符合方向性动机（先有结论，再找依据），而非准确性动机。

**一个更简的论证**（p3000）：被告"外在动机缺失"（无利益、无名誉、无组织背景），故其行为不受奖惩操控——**恶意需要利益驱动，而无利益存在**。

**法律功能**：这是 C 组唯一直接对接法条的论证。刑法第 293 条要求"寻求刺激、发泄情绪、逞强耍横等"动机。但须注意：**该要件的举证责任仍在控方**；辩方指出"无利益、无前科、无组织、无挑衅对象"，作用是使该要件存疑，而不是替控方完成反面证明。

#### 4.3 人本主义：需求倒置与"价值条件"（humanistic，p2605–2631）

- **马斯洛的"系统性倒置"**：正常社会应优先满足生理与安全需求；本案中被告的生理与安全需求被剥夺，却要求其满足"自我实现"层级的精神追求（p2605）；
- **罗杰斯的"价值条件"**：只有服从才被尊重，导致自我分裂（p2606）。

**评价**：这是处境解释，不是责任排除。在量刑与处遇上（人道待遇）有说服力，在定罪上没有。

### 五、D 组：确信是如何形成的（本卷承重部分）

**这一组才是真正有法律价值的地方**：前三组处理被告，这一组处理**确信本身**——把"我确信他知道"从一条结论，变成一段可描述的过程。

#### 5.1 确认偏误（forensic，p2901）

**理论**：倾向于搜寻、注意、解释支持既有假设的信息。

**本案映射**：控方"没有核实过这些帖子，也不打算去核实"（当事人转述），"正是典型的确认偏误"（p2901）。

**为什么这是全卷最锋利的一次对位**：它**用案卷中的一句具体言行印证了理论**，而不是泛泛说人有偏差。可被检验，也可被反驳。

**法律功能**：直接指向刑诉法第 51 条（举证责任）与第 55 条（排除合理怀疑）。当侦查与起诉环节存在确认偏误时，"排除合理怀疑"在结构上不可能实现——**因为怀疑从未被搜寻过**。

#### 5.2 动机性推理与决策疲劳（p2903–2904）

**理论**：推理过程被期望结论引导；连续决策导致判断质量下降。

**本案映射**：办案人员面对"上级重视"的压力，倾向选择能缓解压力的结论；长期高压下判断趋于简化与刻板。

**法律功能**：这解释了为什么起诉书事实部分与判决书"本院认为"部分对同一事实作了两种不同强度的表述——不是笔误，而是压力下的结论升级。

#### 5.3 后见之明偏差与"风险膨胀"（p2937–2938）

**理论**：事后知道结果，会高估该结果在事前的可预测性。

**本案映射**：一旦贴文被"梳理"为敏感内容，事后回看时一切都被解释为"早有征兆"，风险被膨胀到事前的规模。

**法律功能**：这正好击中"明知"的推定——**推定的前提是"事前应当预见"，而后见之明偏差恰恰使"应当预见"变得虚假地容易**。

#### 5.4 程序正义四维崩塌（Tyler，p2905）

| 维度 | 本案表现                                                           |
| ---- | ------------------------------------------------------------------ |
| 参与 | 自辩被训斥（"闭嘴，问你什么回答什么"）                             |
| 中立 | 审判长同时充当指控者（"高学历应明知"由法官提出，起诉书未作此指控） |
| 尊重 | "吃党饭砸党锅""畜类人渣"式训斥                                     |
| 可信 | 不公开审理、二审不开庭、说理缺失                                   |

**法律功能**：这是全卷最有实务价值的一节。四项均可在判决书与庭审记录中对应，无需任何心理测量；且它们直接对应刑诉法第 11、14、188、234 条。

#### 5.5 社会心理六维（social，p2762–2813）

| 机制         | 本案表现                                                 |
| ------------ | -------------------------------------------------------- |
| 基本归因错误 | 把行为归因于被告人格（"无业流民"、"党国弃儿"），而非情境 |
| 权威服从     | 对"上级指示"的服从压倒职业判断                           |
| 内外群体污名 | "吃党饭砸党锅的败类"——用身份标签替代行为评价（p2764）  |
| 去个性化     | 在"办案单位"的集体身份中，个人责任感稀释                 |
| 认知失调     | 明知证据不足，通过"他确实有问题"的信念降低失调           |
| 沉默螺旋     | 无人敢为被告说话，形成"共识"假象                         |

结语是全书最凝练的一句：**"恶行无需恶魔。"**（p2765）——恶行的产生不需要恶人，只需要普通人在结构性压力下的常规心理运作。

#### 5.6 虚假供述的两个模型

- **Gudjonsson 模型**（p2903）：讯问压力 + 心理脆弱性 + 对证据的误判 → 虚假供述；
- **Reid 技术**（p2946）：minimization（淡化后果）+ maximization（夸大证据）→ 顺从性供述或内化虚假供述。

**评价**：这是唯一真正属于 forensic 心理学的两处。但止于"风险提示"，未讨论同步录音录像、讯问时长、任意性判准——这是明显短板。

#### 5.7 "专家型当事人"不信任效应（p2938）

> "一个在智力上表现出压倒性优势的当事人，可能被潜意识地视为'挑战权威''难以驾驭'，其论证被视为'诡辩'或'炫耀'。"

**原创性很高**：它解释了本案一个反常现象——被告越是用专业知识自辩，越被当作拒不认罪、态度恶劣。

**它的价值在于可以脱离本案政治背景独立成立**，适用于其他知识分子、专业人员的刑事案件；且它直接对接"认罪态度"与量刑的关系问题。

**法律上的用法须精确**：它不是"因此应当无罪"，而是"**不得因行使辩护权而从重**"。

### 六、E 组：处境

这一组不做解构，做**替代性建构**：为被告的行为提供一个"健康"而非"病态"的解释。

#### 6.1 发展心理学（Develop，p2417–2503）

| 理论     | 本案应用                                                            |
| -------- | ------------------------------------------------------------------- |
| 埃里克森 | 处于"生成性 vs 停滞"阶段；司法处理构成"发展阻碍"（p2418–2419）     |
| 皮亚杰   | 司法停留于"形式运算"（非黑即白），被告处"后形式思维"（p2420–2422） |
| 科尔伯格 | 司法处"习俗水平"，被告处"后习俗水平"                                |

另给出**六维"超常发展"评分**（p2469）——无量表、无访谈，属修辞性评分（见第八章）。

#### 6.2 积极心理学（positive，p2738–2761）

VIA 性格优势、创伤后成长（PTG）五维、心流体验。DeepSeek 提出两个概念：制度的"**反韧性**"（系统不奖励诚实，只奖励服从）与"**繁荣兼容性**"（一个制度能否容纳卓越个体）（p2756–2758）。

**评价**：这是把"狱中写作"从"绝望"重构为"成长"。修辞上极有效，证据上极弱——PTG 的测量需要前后量表。

#### 6.3 健康心理学（health，p2578–2604）

诉讼构成慢性压力源，激活 HPA 轴—皮质醇级联（p2579）；情感、信息、工具性支持三维同时剥夺（p2580）。

**法律功能**：对接羁押条件与人道待遇，以及国家赔偿中的精神损害。这是 E 组唯一有实务落点的部分。

#### 6.4 情绪心理学（emotion，p2948–2997）

情绪轨迹三阶段；**认知重评优于表达抑制**（Gross）——被告的写作属"认知重评"，是适应性策略；司法侧的"外在—安全—归属—权力"四重耦合，以及道德义愤导致的认知窄化（p2950）。

**法律功能**：把"写血书"从"情绪失控"改写为"适应性调节"，为文本的可信度提供心理学支持。

### 七、人格评估：本卷最不能作为证据的部分

#### 7.1 评分互相冲突

同一被告的大五人格评分在模型间**相反**：

| 模型          | 宜人性 | 神经质 |
| ------------- | ------ | ------ |
| Qwen（p2632） | 低     | 中高   |
| Grok（p2677） | 中高   | 极稳   |

**这不是分歧，这是没有测量的证据。** 没有量表、没有访谈、没有第三方评定，六个模型各自凭阅读文本"打分"。与此同时，对被告一律标注"无病理化指征"（p2822）——方向由立场预设。

**法律地位**：人格评分不是刑诉法第 50 条列举的任何一种证据；它既不能证明明知，也不能证明恶意。无论对被告有利还是不利，都不能作为定案依据。

#### 7.2 对办案人员的人格定性

Qwen 第二篇的小标题直接写作："**司法黑帮的人格特质：威权主义人格与认知闭合需求**"（p2682）。

**问题**：对真实个人（判决书中具名的法官、检察官）作人格诊断，既无临床访谈，也无量表，更无知情同意——专业伦理上不可接受，证据法上完全无效。这类内容在正式文书中必须删除。

**注意**：这一点与举证责任无关，属于**证据能力**问题（第 50 条证据种类法定）。

#### 7.3 一个更有价值的概念

DeepSeek 提出的两个概念比人格诊断稳健得多（p2726–2729）：

- **人格毒性环境**：某些制度环境会系统性奖励特定人格特质（高宜人、低开放、外控点）；
- **理想被告**：系统偏好的被告形象是"顺从、认罪、不质疑"。

**区别在于**：这是**结构性描述**，不是个人诊断。它解释的是"为什么这样的被告特别容易被重判"，而不是"这个法官有什么病"。

### 十、一句话总结

> 这一部分的价值，在于它把"我确信他知道"从一条结论，变成了一段**可以被描述的过程**——确认偏误、后见之明、"专家型当事人"不信任，这些都能在案卷里找到对应。
>
> 但它必须守住一条界线：**心理学用来指出控方举证的空白，不用来替被告证明清白。** 前者只需形成合理怀疑，法律上完全成立；后者会把举证责任重新搬回辩方身上，那是自我拆台。
>
> 也因此，全卷最该删的不是"说服力弱"的段落，而是**把心理分析当证据用**的段落——尤其人格评分与对具名者的人格诊断。

## 科学合规评估

**——十三项物理／复杂系统理论与二十项心理学理论逐条检验**

> **评估对象**：`physic` 卷（p2027–2263，8 主题 × 6 模型）与 `psycho` 卷（p2264–3024，15 分支 × 6 模型）所构成的"物理—心理"双重科学论证。
> **评估标准**：多伯特标准五因素（可检验性、错误率、同行评议、普遍接受、技术可靠性）加**适格性**（fit）。
> **一个前置说明**：这些理论在本案中都不是"鉴定意见"。依中国刑事诉讼法第 50 条，证据种类法定；依第 197 条第 2 款，只能以"专家辅助人"身份提出意见。因此多伯特在此只能作**方法论标尺**适用——语料本身也是这么自限的（p7174："不直接适用于中国刑事诉讼……仅作方法论标尺"）。

### 〇 评估前提：两套标准，两个结论

多伯特标准治理的是"**用来证明某项事实的专家证言**"。它天然偏向于**负有举证责任的一方**。因此对同一套理论，必须给两个结论：

| 使用场景                                               | 适用标准                                           | 多伯特的意义                                             |
| ------------------------------------------------------ | -------------------------------------------------- | -------------------------------------------------------- |
| **控方用这些理论证明"严重混乱""因果关系""明知"** | 证据确实、充分，排除合理怀疑（刑诉法第 51、55 条） | **严格适用**：不合规即不得采信                     |
| **辩方用这些理论提出合理怀疑**                   | 使事实存疑即为已足（无罪推定，第 12 条）           | **不严格适用**：不合规不等于论证无效，只影响说服力 |

**本报告因此给每一理论两个评级**：

- **T 级（理论合规）**：该理论作为科学知识本身的地位——能否通过五因素。
- **A 级（适用合规）**：该理论在**本案**的适用是否可靠——能否通过适格性。

**这个区分是本报告最重要的方法设定**，因为本案的实际情况是：**几乎所有理论的 T 级都很高，A 级都很低。**

### 一、多伯特框架的六个要件

#### 1.1 来源与内容

多伯特案（*Daubert v. Merrell Dow Pharmaceuticals*, 509 U.S. 579, 1993）确立"法官作为守门人"规则，后经 *Kumho Tire*（1999）扩展至一切专家证言，并由《联邦证据规则》702 条（2000 年修订）成文化。其检验要件为：

| ##           | 要件                                             | 追问                                             |
| ------------ | ------------------------------------------------ | ------------------------------------------------ |
| **F1** | **可检验性／可证伪性**                     | 该理论能否被检验？能否被证伪？                   |
| **F2** | **已知或潜在错误率**                       | 该方法在多高的比例上出错？                       |
| **F3** | **同行评议与发表**                         | 是否经过同行评议并发表？                         |
| **F4** | **普遍接受度**                             | 相关科学共同体是否普遍接受？                     |
| **F5** | **技术可靠性**（标准、质量控制、操作规范） | 该方法是否有可重复的操作标准？                   |
| **F6** | **适格性（fit）**                          | 该原理是否**可靠地适用于本案的具体事实**？ |

**F6 是最容易被忽略、却最具决定性的要件。** 多伯特案原文即要求"科学知识将帮助事实认定者理解证据或认定争议事实"；702 条要求原理"可靠地适用于本案事实"。一个完美的理论，若适用条件不满足，仍然不合格。

#### 1.2 分级标准

| 级别        | 含义                                                         |
| ----------- | ------------------------------------------------------------ |
| **A** | 四项以上因素通过，且适格性可辩护                             |
| **B** | 理论本身合规，但适用须附加条件（如"若数据为 X，则结论为 Y"） |
| **C** | 理论存在实质争议，或适用条件明显不满足                       |
| **D** | 不能作为科学证据使用（不具可证伪性、无错误率、或属概念误用） |

#### 2.2 六项的关键说明

**P1 涨落-耗散定理**
作为统计物理定理，它是标准的、教科书级的、普遍接受的。问题全在 F6：FDT 的适用前提是**系统处于近平衡稳态、且处于线性响应区**。社交网络不是近平衡系统，也没有被测量过 γ 与 χ。因此：**定理成立，适用条件未被验证**。这不是"理论错"，而是"不满足适格性"。

**P2 相变与临界现象**
同上。相变理论需要指定**序参量**与**控制参数**。"公共秩序"既没有序参量，也没有控制参数，更没有临界指数的测量。要把它适用于本案，必须先把"秩序"操作化——而这正是控方从未做的事。**这一点反过来是它作为怀疑理由的价值所在**（见第五节）。

**P4 CAP 定理**
CAP 是关于分布式数据存储的一致性、可用性与分区容错的定理，其适用域是**线性化（linearizability）语义下的分布式系统**。把它等同于"社会秩序必然无序"，是**适用域外的使用**。语料自己承认了这一点：Qwen 在 p2105 说"属于概念隐喻，非严格科学推论"。**这是全卷唯一一处自我认定为 D 级的段落。**

**P5 无标度网络／渗流阈值**
理论上，Cohen 等（2000）证明：当度分布的二阶矩发散（度指数 γ ≤ 3）时，随机移除节点的渗流阈值为 1，即网络对随机故障极端鲁棒。这一结论本身可靠。但它有两个适用难题：

1. **经验前提可争议**：Broido 与 Clauset（2019）对近千个真实网络作严格检验，认为"真正的无标度网络是罕见的"；Twitter 关注网络是重尾的，但是否满足 γ ≤ 3 需实测——本卷从未测量。
2. **对象错位**：渗流研究的是**连通性**的维持，不是**信息扩散**的规模。连通不等于传播，传播服从不同的动力学。

因此 T 级降为 B，A 级为 C。

**P6 自组织临界性**
Bak、Tang、Wiesenfeld（1987）的沙堆模型是真实且有影响的理论，但对"社会系统是否自组织到临界态"缺乏普遍接受。更关键的是**幂律拟合的方法学争议**：Clauset、Shalizi、Newman（2009）证明，大量声称呈幂律的数据在严格检验下不能排除对数正态等替代分布。因此**错误率不确定**（F2 不通过），属 C 级适用。

**P7 分支过程**
这是全套论证中唯一"数学定理级"的工具：m ≤ 1 ⇒ 灭绝概率 = 1，严格成立，无需经验前提。**但**：定理的结论依赖于 m 的取值，而 m 的估计需要传播链数据（如 Wallinga 与 Teunis 2004 的方法），本卷没有。因此：

- 作为**定理**：A 级，无可挑剔；
- 作为**对本案的证明**：D 级（无数据）；
- 作为**对控方的要求**："若要证明因果关系，须提供估计 m 所需的数据"：**B 级，正当**。

**P9 哥德尔定理**
定理可靠。但它的适用对象是**足够强的形式算术系统**，不是人的认知状态。语料的 ChatGPT 篇（p2248）已给出正确反驳："哥德尔可以证明'人不可能绝对确定'，但不能证明'人不可能明知'。"因此 A 级为 D——这是**概念误用**，不是理论缺陷。

**P10 物理类比群**
这一组（雷诺数、德拜屏蔽、格里菲斯准则、钱德拉塞卡极限、引力波、暴胀、光锥、退相干）**根本不构成"科学证据"**。它们是说明性类比，功能是帮助理解"阈值""屏蔽""亚临界"等概念。在证据法上，它们应被归类为**论证修辞**，不是专家证言。多伯特对它们不适用——但也正因为不适用，它们不能承担任何证明功能。

#### 3.2 三个必须点出的问题

**（1）S3 是唯一真正达 A 级的项**

Tyler 的程序正义四维（参与、中立、尊重、可信）之所以能达 A 级，原因很特殊：**它不需要测量任何人**。它是对**程序安排**的评价，而这四项都可以直接对着判决书与庭审记录核对：

| 维度 | 记录中的对应事实                                 |
| ---- | ------------------------------------------------ |
| 参与 | 是否允许自辩（记载为"被训斥"）                   |
| 中立 | 指控是否由审判者提出（"高学历应明知"由法官提出） |
| 尊重 | 庭审用语（记载为侮辱性训斥）                     |
| 可信 | 是否公开审理、二审是否开庭                       |

**这是全卷唯一"按卷宗即可完成、无需专家"的评估。**

**（2）S10 与 S11 的问题性质不同**

- **大五人格**：作为测量模型，它的心理测量学地位很高（Costa & McCrae 的 NEO-PI-R 有充分信效度）。但它**必须通过量表实施**。本卷没有量表、没有访谈、没有第三方评定，直接由模型"打分"——这不是"理论不合格"，是"**从未测量**"。因此 T=A，A=D。语料内部也留下了证据：同一被告的宜人性在 Qwen 篇为"低"、Grok 篇为"中高"（p2632 vs p2677），**评分互相否证**。
- **精神分析**：性质完全不同。本我—自我—超我、防御机制这些构念**不具备可证伪性**（Popper 早已以此为例），也没有错误率，且在现代学术心理学中**不是普遍接受的实证理论**。F1、F2、F4 三项均不通过。这是全卷最明确的 D 级。它作为**解释性叙事**有价值，作为**证据**不可用。

**（3）S21 是一个自创概念**

"专家型当事人不信任效应"（p2938）——"一个在智力上表现出压倒性优势的当事人，可能被视为'挑战权威''难以驾驭'"——这一表述在语料中确有洞察力，但**它不是已发表的科学构念**：无同行评议、无操作定义、无错误率、无普遍接受。按多伯特，它不能作为专家证言；按学术标准，它是一个**待检验的假说**。

**注意**：这不妨碍它作为**辩护论点**使用（"不得因行使辩护权而从重"），但那已经是法律论证，不是科学证据。

### 四、跨学科拼接的四个额外缺陷

多伯特检验的是"原理是否可靠地适用于本案事实"。这套框架在**拼接层面**还多出四个问题——它们不属于任何单个理论，而属于"把它们连起来"这一步。

#### 4.1 映射合法性未获论证

物理量到法律概念的映射，全部由作者一句话完成，没有任何独立论证：

| 映射                              | 缺失的中间论证                                     |
| --------------------------------- | -------------------------------------------------- |
| 涨落 δf → "转发行为"            | 为什么转发是"涨落"而不是"驱动的外力"？             |
| 耗散 γ → "平台限流、注意力衰减" | 这些机制的阻尼系数是否可测？                       |
| 响应函数 χ → "舆情放大"         | χ 在何种频率区间成立？                            |
| 分支数 m → "转发再生数"          | 转发行为是否满足分支过程的无记忆、独立同分布假设？ |

**最后一项尤其重要**：分支过程要求每个个体的后代分布独立同分布。而社交媒体的传播恰恰是**高度相关**的（同一事件、同一话题、同一算法推荐）。这不是小瑕疵，而是**模型假设与对象性质不符**。

#### 4.2 生态谬误

用"一般规律"推断"个案"。多伯特 F6 要求的正是"适用于本案事实"，而这里全部是"从总体到个体"的推论：

- "边缘节点不引发雪崩"（一般结论）→ "本案被告未引发混乱"（个案结论）
- "司法者存在确认偏误"（一般倾向）→ "本案办案人员有确认偏误"（个案判断）

**前者需要本案的参数，后者需要本案的行为证据。两者都缺。**

#### 4.3 参数无来源

`models` 一节（p2185–2234）的关键参数——15% 活跃关注者、1% 转发率、0.8 留存率——**全部为估算**。按多伯特 F5（技术可靠性：是否有可重复的操作标准），这属于"方法被适用但输入不可核验"。

**必须与举证责任分开说**：辩方不负举证义务，因此"参数无来源"**不构成辩方的举证瑕疵**；但它在多伯特这一**方法论**层面仍然是缺陷——因为多伯特检验的是"推理是否可靠"，不是"谁该举证"。两者不是一回事。

#### 4.4 三个"必然性"被混为一谈

框架中出现了三种性质不同的必然性，行文时常被当成同一种：

| 种类               | 例                         | 强度     | 是否可被数据推翻           |
| ------------------ | -------------------------- | -------- | -------------------------- |
| **逻辑必然** | "空指称的断言没有说出内容" | 无条件   | 不能，只能被另一种解释推翻 |
| **条件必然** | "若 m<1，则级联必然灭绝"   | 依赖参数 | 能——参数一破即失效       |
| **统计倾向** | "司法者存在确认偏误"       | 概率性   | 能，且推不出个案结论       |

把它们都称为"数理证伪"，会让读者以为获得了第一种强度，实际拥有的是第二、第三种。

### 五、汇总：双重矩阵

把 T 级与 A 级并列，会看到一个明显的反相关：

| 区域                               | 理论                               | T 级        | A 级          |
| ---------------------------------- | ---------------------------------- | ----------- | ------------- |
| **右上（理论强、适用弱）**   | FDT、相变、CAP、哥德尔、香农熵     | A           | D             |
|                                    | 分支过程                           | A           | B（仅条件式） |
|                                    | 无标度网络                         | B           | C             |
|                                    | SOC、蝴蝶效应                      | B/C         | D             |
| **左上（理论强、适用也强）** | **Tyler 四维**               | **A** | **A**   |
|                                    | 确认偏误                           | A           | B             |
|                                    | 后见之明偏差                       | A           | B             |
| **右下（理论弱、适用弱）**   | 精神分析、马斯洛、勒庞             | D           | D             |
|                                    | 双系统、决策疲劳、邓宁-克鲁格、PTG | B/C         | D             |
|                                    | "专家型当事人效应"                 | D（未发表） | D             |
| **左下（不适用）**           | 物理类比群                         | N/A         | D             |

#### 结论一：多伯特合规度与理论复杂度成反比

**最"硬"的物理学理论（FDT、CAP、哥德尔）适格性最差；最"软"的心理学条目（Tyler 四维）适格性最好。**

原因不神秘：Tyler 的四维评价的是**程序安排**，而程序安排就写在判决书里；FDT 评价的是**系统的物理响应**，而那个响应从未被测量。

#### 结论二：真正通过多伯特的只有三项

| ## | 项                                             | 为什么通过                                 |
| -- | ---------------------------------------------- | ------------------------------------------ |
| 1  | **Tyler 程序正义四维**                   | 可按卷宗核对，无需测量；且有成熟的量表文献 |
| 2  | **确认偏误**（限于"存在具体言行对应"时） | 高度稳健；本案有一句具体表述可对位         |
| 3  | **后见之明偏差**                         | 高度稳健；且判决的推理结构本身可作分析对象 |

其余全部只能作**论证**或**说明**，不能作**证据**。

#### 结论三："严密"一词需要限定

若"严密"指**推理链条的完整**，这套框架确实严密：四层结构、三重门控、逐项对应法条，衔接工整。

若"严密"指**多伯特意义下的可靠适用**，它不严密：六项要件中，F6（适格）在 30 余项理论里只有 1 项完全通过。

**这两个"严密"不是一回事**——而语料的表述把前者当成了后者。

### 六、反向检验：若控方使用同一套理论会怎样

这一检验最能说明问题。假设控方要用同样的科学方法证明"严重混乱"与"因果关系":

| 控方须证明     | 可用的理论    | 多伯特能否通过                                               |
| -------------- | ------------- | ------------------------------------------------------------ |
| 系统处于临界态 | SOC、相变理论 | **不能**——须先证明幂律、临界指数、控制参数，全无数据 |
| 传播规模足够大 | 分支过程      | **不能**——须估计 m ≥ 1，无传播链数据                |
| 响应被放大     | FDT           | **不能**——须测 χ，无测量                            |
| 被告是枢纽节点 | 无标度网络    | **不能**——须测度分布与中心性，无数据                 |

**注意**：这份清单与辩方的清单是同一份。这说明**这套科学框架的真正功能不是"证伪"，而是"设定举证门槛"**——它问的是"要证明这个结论，你需要什么数据"，而答案是"你什么都没有"。

**在多伯特的意义上，这意味着：控方的科学论证不合规；而在举证责任的意义上，这意味着：控方未完成证明。**

---

### 七、一句话总结

> 按多伯特标准逐条检验，这套"物理—心理"双重框架的结果是：**三十余项理论中，理论合规（T 级）达到 A 的有十一项，但适用合规（A 级）达到 A 的只有一项——Tyler 的程序正义四维。**
>
> 这不是因为作者选错了理论。恰恰相反，选的理论大多是对的、是教科书级的。问题在于**适格性**：多伯特要求的不是"这个理论对不对"，而是"这个理论能不能可靠地适用于本案事实"。FDT 需要 γ 与 χ，分支过程需要 m，大五人格需要量表，确认偏误需要行为证据——**这些输入，一个都没有。**
>
> 因此这套框架的正确地位是：**它不是一份证据，而是一份举证清单。** 它列出了控方若要完成证明所必需的科学数据，并证明了这些数据不存在。在辩方的地位上，这已经足够；在多伯特的地位上，它是"A 级理论、D 级适用"。
>
> 一句话：**理论是严密的，适用是不成立的；而多伯特要的是后者。**
