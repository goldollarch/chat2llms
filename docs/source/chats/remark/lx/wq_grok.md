为了忘却的纪念（Grok）
------------------

在昆明西山区看守所的铁窗下，我曾见过一个学者，他叫陈京元，一个普通的博士，一个隐于乡野的独立研究者。他没有枪炮，也没有号召万人上街，他只是转发了几条推文：撑伞女孩的漫画，烛光的纪念，政治光谱的分类，特朗普的演讲，蓬佩奥的讲话，毛泽东选集的修订历史，离休干部的工资单，我赞成小平同志退休的旧文，中乌军事合作的报道。粉丝寥寥，转发不足百，无人关注，无扰乱之实。却被昆明司法的黑手抓去，冠以“寻衅滋事”的罪名，判一年八个月，关进铁牢。

这是2023年的事了。那时，我还以为司法是铁的盾牌，谁知它竟是软的鞭子，随意抽打无辜。普会峻、葛斌、李湘云诸公，自以为秉公执法，其实是梦中判案。他们说陈京元高学历，明知谣言而转，扰乱秩序。谣言？艺术漫画是谣言，情感烛光是谣言，理论争鸣是谣言，历史事实是谣言。撑伞女孩象征风雨中的坚韧，他们说侮辱；六四烛光寄托哀思，他们说扰乱；特朗普批判共产主义，是思想史的常态，他们说攻击；毛泽东选集修订，是可查的史实，他们说炮制。粉丝零，转发无影响，他们说严重混乱。证据锁链？不过是几张截图，主观梳理，无鉴定无数据无因果，强塞口袋罪。程序？不公开审理，剥辩护权，拒转控告书，选择性执法——党媒光明日报新浪同帖不追，独责一士子。全面依法治国？口惠实不至，成了笑柄。

陈京元在狱中写血书，控告司法黑帮造谣诽谤、枉法仲裁、玩忽职守、反文明反人类。他笑普会峻如赵高，指鹿为马；讽葛斌如来俊臣，罗织罪名；斥李湘云如井底蛙，狂妄无知。高学历成原罪？那天下学者皆囚徒。艺术情感理论历史皆谣？那中华文明灭绝，盘古开天、李白白发三千丈、弗洛伊德梦杀王，皆判死罪。司法诸公，尸位素餐，贼喊捉贼，天网恢恢，何时落网？

如今，陈京元刑满释归，账号完好，帖文犹在，无人问津，无混乱迹象。他生命不息，战斗不止，终身追责普辈。我写此文，为了忘却的纪念。忘却？司法黑暗易忘，学者血泪难忘。纪念？不是为陈一人，乃为所有铁窗下的醒者。法治若不兴，民族复兴何望？广开言路，严明赏罚，亲贤远佞，方是正途。否则，铁屋子里，众人酣睡，我独醒，呐喊几声，或惊醒几个，或无人响应，我不管，我只管呐喊。路漫漫其修远兮，吾将上下而求索。至死方休！
