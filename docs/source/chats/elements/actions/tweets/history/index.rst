历史资料
========

陈京元博士在【:doc:`狱中自辩暨控告血书 </case/docus/defendent/letter>`】中指出，
昆明公检法系统以"寻衅滋事罪"（《中华人民共和国刑法》第293条）将其判刑入狱，
所依据的"犯罪证据"包括其曾经转发过的纯粹属于历史资料和现实表述内容的文章，
这些文章被警方一概定性为"谣言"。

Refer to: :ref:`Self-Defense and Accusation from Prison <historical-realities>`
