## 使用**分析哲学**的工具对陈京元博士案件进行剖析。

分析哲学的核心在于运用**逻辑分析**和**语言分析**来澄清概念、检验论证的有效性，并消除因语言误用和逻辑谬误而产生的混乱。

以下分析将不涉及道德批判或政治立场，而是聚焦于案件中的**概念清晰度**、**论证有效性**和**语言使用**问题。

---

### **分析框架：分析哲学的核心工具**

1. **概念分析：检验核心法律概念的清晰度**
2. **逻辑分析：解构司法推理的有效性**
3. **言语行为理论：分析司法话语的“以言行事”功能**
4. **真理符合论：审视事实主张与经验的符合度**

---

### **一、 概念分析： “寻衅滋事”的模糊性与“秩序”的指称缺失**

分析哲学强调，有意义的讨论必须基于清晰的概念。模糊的概念会导致任意判断和权力滥用。

* **“寻衅滋事”的概念模糊性**：

  * **内涵模糊**：该罪名缺乏清晰、客观的**必要条件和充分条件**来界定何种具体行为构成“寻衅”与“滋事”。它是一个**家族相似性**概念，其边界是开放和任意的。
  * **外延不确定**：其指称对象不明确。从逻辑上讲，一个概念的外延不确定，意味着我们无法在经验世界中明确识别出它所指向的**所有**和**仅有**的那些事例。因此，将“转发信息”这一行为归入其外延，是一个**主观的、非逻辑的决断**，而非基于概念的客观应用。
* **“秩序严重混乱”的指称缺失**：

  * 判决书声称“造成公共场所秩序严重混乱”。从分析哲学角度看，这是一个需要**经验验证的事实陈述**。
  * “秩序严重混乱”这一状态，必须有其**可观察、可验证的指称对象**（如人群聚集、交通堵塞、财产破坏等）。在本案中，控方和法庭**未能提供这些指称对象的具体证据**。因此，这一陈述更像是一个**无真值的伪命题**或**空洞的修辞**，因为它无法在经验世界中找到对应的“事实”。

### **二、 逻辑分析： 司法推理中的基本谬误**

分析哲学致力于识别和批判逻辑谬误，以确保证明的有效性。

* **“高学历应明辨是非”的推理谬误**：

  * 这一推理可重构为：
    1. 前提1：如果一个人具有高学历，那么他应当知道某些信息是敏感的。（P → Q）
    2. 前提2：陈京元具有高学历。（P）
    3. 结论：因此，陈京元应当知道这些信息是敏感的，并因此具有主观恶意。（Q）
  * **逻辑谬误**：
    * **前提1的虚假性**：前提1本身是一个无法被证明的全称判断。高学历与知晓特定政治敏感信息之间没有**逻辑必然性**。这是一个**以偏概全的谬误**。
    * **结论的跳跃**：即使承认前提1和2，也只能推出“他应当知道敏感”，但无法逻辑地推出“他**因此**具有犯罪故意”。这中间存在一个**巨大的逻辑鸿沟**，犯了**因果谬误**或**非 sequitur**（不根据前提的推理）的错误。
* **禁止自辩对论证结构的破坏**：

  * 一个完整的司法论证应包含**正反双方的论据和反驳**。法官禁止陈京元自辩，相当于**系统性地排除了所有可能证伪控方假设（H₀：陈京元有罪）的证据和论证**。
  * 从论证逻辑看，这违反了**批判性讨论的基本原则**，使司法程序从一个旨在寻求真理的“论证游戏”退化为一个**单方面的、旨在压服的“宣告”**。

### **三、 言语行为分析： 司法话语的“以言行事”功能错位**

借鉴奥斯汀的言语行为理论，我们可以分析司法话语在做什么。

* **判决作为“以言行事”**：
  宣判“陈京元有罪”不是一个简单的描述，而是一个**以言行事行为**。其成功需要满足 **“恰当条件”**：
  1. **程序条件**：必须遵循正当程序（如允许辩护）。
  2. **内容条件**：命题内容必须在现实中为真（如行为确实符合罪状）。
  3. **真诚条件**：说话者（法官）必须真诚地相信其判决是公正的。
* **本案中的“不恰当”**：
  * 禁止自辩严重违反了**程序条件**。
  * “造成秩序严重混乱”缺乏证据，违反了**内容条件**。
  * 因此，该“以言行事行为”（宣判）在根本上是不恰当的，甚至可以认为是**失败的**或**无效的**。它只是在**以言施效**（通过言语产生监禁的后果），但缺乏正当的 **“以言行事”** 力量。

### **四、 真理符合论： 事实主张与经验世界的脱节**

分析哲学（尤其是早期维特根斯坦和逻辑实证主义）关注命题与事实的符合关系。

* **关键命题的真理值评估**：
  * 命题A：“陈京元的转发行为造成了公共场所秩序严重混乱。”
  * 根据**真理符合论**，命题A为真，当且仅当它**符合客观事实**。
  * 然而，司法机关**未提供任何可公开观察、可重复验证的经验证据**来证明“秩序严重混乱”这一事实的存在。
  * 因此，从分析哲学的角度看，命题A是一个**无法被证实**的陈述，其**真理值无法确定**。将一个真理值不明的陈述作为判处重刑的核心依据，使得整个判决在认识论上失去了根基。

### **结论：一个充满逻辑与语言混乱的判决**

从分析哲学的视角审视，对陈京元博士的判决在**概念、逻辑、语言和认识论**层面均存在严重缺陷：

1. **概念上**，依赖于一个**模糊不清、边界任意的法律概念**。
2. **逻辑上**，其推理包含**严重的逻辑谬误**，且程序**系统性地排斥了反证**。
3. **语言上**，司法话语的 **“以言行事”功能失效**，沦为权力的粗暴宣告。
4. **真理上**，其核心事实主张**无法得到经验世界的证实**，缺乏认识论基础。

分析哲学的最终结论是冷静而严厉的：**此案判决经不起最基本的理性检验。** 它不是一个基于清晰概念和有效逻辑的“论证”，而是一系列**语言混乱和逻辑断裂**的集合。这种分析剥离了情感和价值判断，从纯粹理性的角度揭示了该司法决定在**智识上的破产**。陈京元博士的案件，因此可以作为一个**分析哲学批判的典型案例**，用以警示：当法律脱离概念的清晰和逻辑的严谨时，它将不再是正义的工具，而可能沦为非理性的暴力。

## 语言游戏、制度事实与恰当性

### ——以分析哲学核心方法评价"陈京元案"

### 内容提要

**前面基于弗雷格与罗素分析。本篇必须说明为什么还需要第三篇。**

**因为弗雷格与罗素共享一个前提：语言的基本单位是命题，哲学的任务是分析命题的意义与逻辑形式。**

**而从后期维特根斯坦开始，分析哲学的重心发生了转移：语言不是命题的集合，而是活动、实践、在规则下的行为。**

**这个转移恰好落在本案的要害上。** 本案的核心问题不是"这句话是什么意思"，而是：

> **谁，在什么语境中，依据什么规则，做了什么样的言语行为？**

**本文的核心发现是一项纠正和七项分析。**

#### 纠正：卷宗对奥斯汀的引用，恰好证明了相反的结论

**当事人与卷宗都引用了奥斯汀的言语行为理论。** 当事人的表述是：

> "按照奥斯汀的言语行为理论，我的转发不过无关紧要的'无效施事'，而司法文书则是真正具有塑造现实能力的'述行语'。"

AI分析中亦有类似表述："它属于'述行语'（Performative Utterance）：**不描述事实，仅宣示权力**。"

**这两处引用都把奥斯汀读作一个"权力理论"：司法文书是述行语，所以它有力量。**

**但奥斯汀的理论恰恰相反。**

**奥斯汀的核心贡献不是"述行语有力量"，而是"述行语的力量取决于恰当性条件"。** 当条件不满足时，述行语不是"仍然有效但不当"，而是**无效**——奥斯汀称之为"**不恰当**"（infelicity），严重的情形是 " **misfire** "（无效）。

**他的标准例子是：**一个人在没有被授权的情况下宣布"我宣布你们为夫妻"——**这场婚礼不是"不合法的婚礼"，而是根本没有婚礼。**

**把这个分析用于本案：**一份判定，如果其恰当性条件不满足，它**不是"错误的判定"，而是"无效的判定"**。

**因此：引用奥斯汀，实际效果是削弱而非加强判决的效力。这是卷宗的一处实质性误读。**

#### 七项分析

1. **语言游戏：一次跨游戏的"运输"。** 判决书把"领导核心""现行政治体制""攻击"这些**政治—意识形态语言游戏**中的表达式，运进了**法律语言游戏**。**词还是那个词，但它已经不再做同样的工作。**
2. **私人语言：一份只有办案人员能核验的"认定"。** 维特根斯坦的私人语言论证：意义需要公共判准。"梳理认定"没有公布标准、没有鉴定、无法复核——**一个私人的判准不能支撑一个公共的判决。**
3. **"不要想，而要看。"** 法院做的是"想"（从"攻击性"推出"虚假性"）；"看"会看到：一幅漫画、一句感慨、一篇政论、一份工资单——**四类对象的"语法"完全不同。**
4. **言语行为：转发与判决是两类不同的行为。** 转发不是断言；判决是判定式（verdictive）。**而判定式的成立需要恰当性条件。**
5. **制度性事实："虚假信息"与"严重混乱"不是原始事实。** 按塞尔的构造公式"X 在语境 C 中算作 Y"——**法院断言了 Y，但从未指明 X 和 C。**
6. **会话准则：四条全部违反。** 数量（说得太少）、质量（无证据断言）、关联（大量无关表述）、方式（高度歧义）。**并且"领导核心"不是断言，而是会话含义——而只有断言才能作为定罪基础。**
7. **整体论与宽容原则。** 蒯因：任何陈述都不能被孤立检验；法院用"免疫策略"保护核心命题（把艺术、情感、观点纳入"虚假信息"）。戴维森：宽容原则被**不对称使用**——对被告最小宽容，对控方最大宽容。

### 导言：第十二把尺子——从"意义"转向"使用"

#### 导言一：分析哲学的两半

**分析哲学有一个常被忽略的内部划分：**

|            | 理想语言传统                           | 日常语言传统                                   |
| ---------- | -------------------------------------- | ---------------------------------------------- |
| 代表       | 弗雷格、罗素、早期维特根斯坦、卡尔纳普 | 后期维特根斯坦、奥斯汀、赖尔、斯特劳森、格赖斯 |
| 语言的模型 | 命题、逻辑形式                         | **活动、游戏、行为**                     |
| 哲学的任务 | 分析意义、重建逻辑形式                 | **描述用法、消解混乱**                   |
| 关键词     | 意义、指称、真值                       | **用法、规则、语境、恰当性**             |

**前两篇属于第一半。本篇属于第二半。**

#### 导言二：为什么本案需要第二半

**因为本案的核心问题不是一个"意义"问题，而是一个"用法"问题。**

**把本案的几个关键问题分别对应：**

| 本案的问题                                     | 属于哪一半               |
| ---------------------------------------------- | ------------------------ |
| "虚假信息"是什么意思？                         | 第一半（意义）           |
| "造成严重混乱"是否有指称？                     | 第一半（指称）           |
| **谁有权说某内容是"虚假信息"？**         | **第二半（用法）** |
| **在什么语境中"攻击"变成了"虚假"？**     | **第二半（用法）** |
| **判决这个行为本身需要什么条件才成立？** | **第二半（用法）** |
| **转发是什么类型的言语行为？**           | **第二半（用法）** |

**后四个问题，弗雷格和罗素都回答不了——因为他们的框架里没有"说话者"和"语境"这两个变量。**

#### 导言三：一个被忽略的纠正

**开篇已述：卷宗与当事人引用奥斯汀，得出的是相反的结论。**

**这里需要补充一个说明：为什么这个纠正重要。**

**因为如果不纠正，那么"司法文书是述行语"这句话会被理解为：**

> "判决书不需要论证——它说话就算数。"

**而这恰恰是对奥斯汀的彻底误读。**

**奥斯汀的理论要点是：述行语的效力不是自动的，而是有条件的。** 他指出，一个述行行为要成功，必须满足一系列条件：

- 必须存在一个被接受的、有一定程序的约定性效果；
- 在特定情形中，特定的人与特定的情境必须适格；
- 程序必须被所有参与者正确地、完整地执行；
- 等等。

**奥斯汀把这些条件称为"恰当性条件"（felicity conditions），把条件不满足的情形称为"不恰当"（infelicity）。**

**他的关键论断是：不恰当的述行语不是"说错了"，而是"没有做成那件事"。**

**所以，把这一分析用于本案：**如果判决的恰当性条件不满足，那么**它不是一份错误的判决，而根本不是一份有效的判决**。

**这是一个比"错判"更彻底的结论。**

### 一、语言游戏：一次跨游戏的"运输"

#### 1.1 "语言游戏"是什么

**维特根斯坦在《哲学研究》中引入了"语言游戏"（Sprachspiel）这一概念。**

**其要点是：语言不是一套固定的符号系统，而是 **嵌在活动中的、有规则的行为**。**

**他举的例子包括：**

- 命令与服从；
- 报告一件事；
- 猜测一件事；
- 把一种语言翻译成另一种语言；
- 请求、感谢、咒骂、问候、祈祷。

**每一个"游戏"都有自己的规则、目的、判准和恰当性标准。**

**而关键的一点是：同一个词在不同的游戏中可以做完全不同的工作。**

#### 1.2 法律是一个独立的语言游戏

**法律显然是一个独立的语言游戏。它有：**

- 自己的**词汇**（构成要件、法益、因果关系、举证责任）；
- 自己的**规则**（罪刑法定、证据裁判、无罪推定）；
- 自己的**判准**（合法／非法，有罪／无罪）；
- 自己的**恰当性条件**（管辖、程序、资格、形式）。

**这个游戏的一个核心特征是：它的判定必须 **依据内部的规则**，而不能援引外部游戏的判准。**

#### 1.3 本案的"运输"

**判决书的核心说理段：**

> "公共网络空间并非法外之地，被告陈京元作为完全刑事能力人，且具有很高的学历和知识水平，在使用境外聊天软件过程中应辨别是非，被告陈京元在使用软件的过程中，对明知是**侮辱、攻击国家领导核心以及我国现行政治体制**的图片和文章进行转发，转发的内容**经梳理均属于虚假信息**，**造成公共秩序严重混乱**，故其行为已构成寻衅滋事罪。"

**把这段拆成表达式，并追问每一个表达式来自哪个游戏：**

| 表达式                                 | 所属语言游戏             | 在该游戏中的功能 |
| -------------------------------------- | ------------------------ | ---------------- |
| "构成要件""明知""造成""故其行为已构成" | **法律**           | 规范涵摄         |
| "学历""辨别是非"                       | 日常／教育               | 能力评价         |
| **"侮辱、攻击"**                 | **政治—道德评价** | 立场表态         |
| **"国家领导核心"**               | **政治**           | 指称特定政治地位 |
| **"我国现行政治体制"**           | **政治**           | 指称制度安排     |
| "经梳理"                               | **工作行政**       | 整理操作         |
| "虚假信息"                             | 法律（但定义缺失）       | 构成要件要素     |

**这张表显示：一句话里，至少混入了四个语言游戏的表达式。**

**而其中最关键的三个——"侮辱、攻击""国家领导核心""现行政治体制"——全部来自政治语言游戏。**

#### 1.4 维特根斯坦的诊断

**维特根斯坦反复指出一个现象：当一个表达式被从一个语言游戏运到另一个语言游戏，**它看起来还是那个词，但它已经不再做同样的工作**。**

**这正是本案的根本机制。**

**以"攻击"为例：**

| 在政治语言游戏中           | 在法律语言游戏中                 |
| -------------------------- | -------------------------------- |
| "攻击"= 发表不利的言论     | "攻击"**不是一个构成要件** |
| 判断标准：立场、效果、对象 | 无法适用——因为没有定义         |
| 后果：政治评价、舆论反应   | **不能作为定罪依据**       |

**法院把"攻击"运进了法律游戏，然后让它承担了一个它在这个游戏里根本无法承担的工作：证明"虚假"。**

**而"攻击"与"虚假"分属两个完全不同的维度：**

- **"攻击"是关于效果的**（这段内容对某对象产生了不利影响）；
- **"虚假"是关于真值的**（这段内容与事实不符）。

**一个内容完全可以既具有攻击性又完全真实；也可以完全虚假却毫无攻击性。**

#### 1.5 后果：形式的守法与功能的越界

**本案判决书的形式是完备的**——它援引了《刑法》第293条、《两高解释》第5条第2款、第47条、第64条，它使用了"本院认为""故其行为已构成"这样的标准表述。

**但它的功能不是法律的。**

**用一个精确的表述：**

> **判决书在法律语言游戏的语法中，执行了政治语言游戏的功能。**

**而维特根斯坦会问：一个在语法上属于游戏 A、在功能上属于游戏 B 的行为，究竟属于哪个游戏？**

**他的答案是：**它属于哪个游戏，取决于**它被什么规则所评判**。**而本案的判决，被评判的标准是政治的（是否"攻击"了某个对象），而不是法律的（是否满足构成要件）。**

#### 1.6 一个可能的反驳及其回应

**反驳：**"法律语言本身包含大量评价性概念（社会危害性、情节严重、公序良俗），援引政治概念并不必然越界。"

**回应：** 这个反驳对了一半。

**法律确实包含评价性概念。但它们有两个特征：**

1. **它们有法律内部的定义或判准**（"情节严重"由司法解释界定；"公序良俗"由民事审判实践界定）；
2. **它们的功能是规范涵摄**，不是政治表态。

**而"领导核心""现行政治体制"这两个表达式：**

- **在法律语言游戏内部没有任何定义或判准**；
- **它们的功能是政治评价，不是规范涵摄**。

**因此它们不是"法律的评价性概念"，而是"被运进法律文本的政治表达式"。**

**区别在于：** 前者是法律游戏的合法成员；**后者是外来者，被临时征用，却承担了中心任务。**

### 二、私人语言：一份只有办案人员能核验的"认定"

#### 2.1 私人语言论证

**维特根斯坦在《哲学研究》§243—§315 中提出了一系列论证，通常被称为"私人语言论证"。**

**其核心问题是：** 一种只有说话者本人能够理解、无法被他人核验的语言，是否可能？

**维特根斯坦的回答是：不可能。**

**理由可以概括为：**

- **意义需要判准**（criterion）；
- **判准必须是公共的**——因为"遵守规则"是一种实践，而实践不能被私有化；
- 如果一个人"私自地"遵守一条规则，那么**任何行为都可以被解释为遵守或违反该规则**；
- **因此，一个私人的规则不是规则。**

**他在§202中写道：**

> "**因此'遵守规则'也是一种实践。而认为自己在遵守规则，并不就是遵守规则。因此不可能'私自地'遵守规则；否则，认为自己在遵守规则就会和遵守规则是一回事了。**"

#### 2.2 本案的"梳理认定"为什么是私人的

**判决书的表述是：**"转发的内容**经梳理均属于**虚假信息。"

**追问四个问题：**

| 问题                       | 本案的回答                                                       |
| -------------------------- | ---------------------------------------------------------------- |
| 谁来判定某内容是否"虚假"？ | **办案人员**（侦查机关出具《梳理情况说明》）               |
| 依据什么标准？             | **未公布任何标准**                                         |
| 他人如何核验？             | **无法核验**——无鉴定意见、无具体内容指认、无事实核查记录 |
| 是否有独立的核验程序？     | **无**（起诉书列举"鉴定意见"，判决书与裁定书均无鉴定意见） |

**四个问题的答案，恰好构成"私人语言"的四个特征：**

1. **判定者是单一的**；
2. **标准是未公布的**；
3. **结论是不可复核的**；
4. **没有独立核验程序。**

#### 2.3 维特根斯坦式的判断

**"经梳理均属于虚假信息"这句话，在本案中具有什么性质？**

**它在语法上是一个断言**（它声称某类内容具有某个属性）。

**但按私人语言论证，它不是一个**可被评价真假的断言**——因为它的判准是私人的，而私人判准不能被用来建立公共的真假。**

**维特根斯坦会说：** 这不是一个"错误的认定"，而是一个"看起来像认定、但不是认定的东西"。

**因为它缺少认定的必要条件：** 一个可以被他人援引、检验、反驳的判准。

#### 2.4 一个更精确的表述

**这里需要避免一个粗糙的说法：** 不能说"办案人员主观臆断"——那是一个关于动机的判断，本文无从证实。

**准确的表述是：**"梳理"这一操作**在结构上**不能被核验，因此**它在逻辑上**不能作为认定的基础。

**区别在于：**

|              | 主观臆断（动机判断） | 不可核验（结构判断） |
| ------------ | -------------------- | -------------------- |
| 需要证明什么 | 办案人员的心理状态   | **文书的结构** |
| 本文能否主张 | **不能**       | **能**         |

**而后者已经足够：** 一个不可核验的认定，无论其动机如何，都不能作为定罪的基础。

#### 2.5 与"亲知原则"的区别

**读者可能注意到：前一篇（罗素）已经讨论过"法庭未亲知"，本节与它有何不同？**

**区别是实质性的：**

|              | 罗素的亲知原则                               | 维特根斯坦的私人语言论证                         |
| ------------ | -------------------------------------------- | ------------------------------------------------ |
| 关注点       | **认识的基础**（命题的成分是否被亲知） | **规则的可能性**（判准是否是公共的）       |
| 问题性质     | 认识论                                       | **语义学／语用学**                         |
| 对本案的诊断 | 法庭不理解它没有亲知的命题                   | **法庭的"认定"不是认定，因为判准是私人的** |
| 后果         | 命题无法被理解                               | **"认定"这个行为不成立**                   |

**简言之：** 罗素问"法庭知道什么"，维特根斯坦问"**法庭的'认定'能不能算作认定**"。

**后一个问题是更根本的：** 即使法庭亲知了一切（假设它真的到现场看了），**如果它使用的判准是私人的，它的"认定"仍然不能成立。**

### 三、"不要想，而要看"：涉案内容的实际样态

#### 3.1 一句方法论指令

**维特根斯坦在《哲学研究》§66中写道：**

> "**Denk nicht, sondern schau!**"
> （**不要想，而要看！**）

**这句话的语境是：他在讨论"游戏"这个概念时，反对人们去寻找一个共同本质，而主张去看实际的事例。**

**其方法论含义是：** 不要从一个抽象概念出发去推演，**而要去看具体的东西实际上是什么样的。**

#### 3.2 法院做的是"想"

**法院的推理是一个纯粹的"想"的过程：**

> 内容具有攻击性 → 攻击性意味着对某种秩序的否定 → 否定秩序的内容属于虚假信息 → 转发虚假信息造成混乱

**这个链条的每一步都是概念的推演，没有一步是"看"。**

**法院从未"看"过：**

- 那幅漫画画的是什么；
- 那句感慨说的是什么；
- 那篇文章论证的是什么；
- 那份工资单上的数字是什么。

**它看的是《关于对陈京元网络聊天平台梳理情况说明》——一份关于这些内容的 **描述**，而不是这些内容本身。**

#### 3.3 "看"会看到什么

**如果按维特根斯坦的指令去"看"，会看到四类完全不同的东西：**

| 内容类型         | "看"到的是什么                 | 它的"语法"                                     |
| ---------------- | ------------------------------ | ---------------------------------------------- |
| **漫画**   | 有笔触、有构图、有夸张、有象征 | **图像语言**：不陈述事实，表达立场与情感 |
| **感慨**   | 有说话者、有情绪、有语境       | **表达**：不主张事实，表露心理状态       |
| **政论**   | 有论点、有论据、有对手、有立场 | **论证**：可被反驳，不可被"证伪"为假     |
| **工资单** | 有数字、有项目、有来源         | **记录**：可核查，有真值                 |

**这四类的"语法"完全不同。**

**而法院用同一个谓词——"虚假"——去述说它们全部。**

#### 3.4 一个精确的类比

**维特根斯坦在§66中举的例子是"游戏"：**

> 棋盘游戏、纸牌游戏、球类游戏、奥林匹克游戏……

**他问：它们的共同点是什么？**

**他的回答是：没有单一的共同点，只有"**家族相似**"（Familienähnlichkeit）——一个复杂的、重叠交叉的相似性网络。**

**而本案的情况比"家族相似"更糟：**

**因为"虚假"这个谓词，根本不适用于前三类的任何一类。** 它们不是"这个家族的远亲"，而是**根本不属于这个家族**。

**用维特根斯坦的话说：**这不是"家族相似"的问题，而是**"语法"的错配**——你把一个只适用于某个游戏的词，用在了另一个游戏的对象上。

#### 3.5 一个必要的精确化

**这里需要区分两个层次的问题：**

| 层次                 | 问题                                   | 本案的回答                       |
| -------------------- | -------------------------------------- | -------------------------------- |
| **家族相似层** | "虚假信息"这个概念有没有一个共同本质？ | 没有——它是一个家族相似概念     |
| **语法错配层** | 前三类内容是否属于这个"家族"？         | **不属于——它们没有真值** |

**第一个层次是维特根斯坦的贡献：**他指出许多概念没有本质，只有相似性。这可以用来**批评"虚假信息"这个概念缺乏明确定义**。

**第二个层次是更根本的：** 它不需要"家族相似"的理论——它只需要指出：**一幅漫画没有真假，正如一个愿望没有真假。**

**而本案的问题在第二个层次上。**

**这意味着：** 即使法院把"虚假信息"定义得再精确，它仍然不能把漫画纳入——**因为漫画不是"不精确地属于"这个类，而是"根本不能被这个谓词述说"。**

### 四、言语行为：转发、断言与判决

#### 4.1 奥斯汀的三分

**奥斯汀在《如何以言行事》（1962）中区分了三个层次：**

| 层次 | 名称                                 | 内容                                     |
| ---- | ------------------------------------ | ---------------------------------------- |
| 1    | **以言表意**（locutionary）    | 说出有意义的语句                         |
| 2    | **以言行事**（illocutionary）  | 通过说话做某事（断言、命令、承诺、宣告） |
| 3    | **以言取效**（perlocutionary） | 通过说话产生效果（说服、惊吓、激怒）     |

**而他的核心发现是：许多语句不是"描述世界"，而是"在世界中做事"。**

#### 4.2 转发是什么言语行为

**把"一键转发"放进这个三分框架：**

| 层次     | 转发的内容                                         |
| -------- | -------------------------------------------------- |
| 以言表意 | 说出（或重述）一段有意义的文本                     |
| 以言行事 | **传递、引述、保存**——而不是**断言** |
| 以言取效 | 通常无（据卷宗，互动趋近于零）                     |

**关键在第二层。**

**"断言"（assertion）有一个特征：** 说话者承诺所断定的内容为真。

**而"转发"没有这个承诺。** 一个转发者可以完全不同意所转发的内容——**转发可以是否定的一部分**（"看看这些人说了什么"）。

**奥斯汀本人注意到这一点：** 他讨论过"引述"（quoting）与"断言"的区别——**引述一个人的话，不等于断言那句话为真。**

**据卷宗，当事人的行为是"一键转发"，无评论、无点赞、无附言。**

**这在言语行为的层次上是清楚的：**它属于**引述／传递**，不属于**断言**。

#### 4.3 判决是什么言语行为

**判决显然是一个"以言行事"的行为，而奥斯汀对它有专门的分类。**

**在他的分类中，判决属于"**判定式**"（verdictives）——即"作出裁定、宣判"这一类的言语行为（陪审团裁决、法官判决、仲裁人裁定）。**

**判定式有一个特殊要求：**它不是描述世界，而是**改变当事人的地位**（从"被告人"变成"罪犯"）。

**而这个改变，依赖于恰当性条件。**

#### 4.4 恰当性条件

**奥斯汀列出的条件，可以概括为四类：**

| 条件           | 内容                                         |
| -------------- | -------------------------------------------- |
| **A.1**  | 必须存在一个被接受的、有一定程序的约定性效果 |
| **A.2**  | 在特定情形中，特定的人与情境必须适格         |
| **B.1**  | 程序必须被所有参与者正确地、完整地执行       |
| **B.2**  | 程序必须被真诚地执行                         |
| **Γ.1** | 后续行为必须与所言一致（如果是承诺类）       |

**当 A、B 两类条件不满足时，奥斯汀称之为" **misfire**"——行为 **没有做成**。**

**他的标准例子：** 一个人没有被授权，却说"我宣布你们为夫妻"——**这场婚礼没有发生**，而不是"发生了一场不合法的婚礼"。

#### 4.5 本案判决的恰当性检验

| 恰当性条件                             | 本案的状态                                                 | 依据                 |
| -------------------------------------- | ---------------------------------------------------------- | -------------------- |
| **A.1** 存在被接受的程序         | 是（刑事诉讼程序）                                         | 文书可确认           |
| **A.2** 参与者适格               | 是（法院有管辖权，合议庭组成合法）                         | 文书可确认           |
| **B.1** 程序被正确地、完整地执行 | **否**——不公开审理无法定理由；二审应当开庭而未开庭 | **文书可确认** |
| **B.1** 关键环节完整             | **否**——核心结果要件零证据；无鉴定意见             | **文书可确认** |
| **B.2** 真诚执行                 | 未评估（属动机问题）                                       | —                   |

**关键的失败在 B.1。**

**而奥斯汀的论断是：** 当 B.1 不满足时，行为不是"错误的"，而是"**没有做成**"。

#### 4.6 一个精确的结论

**因此：**

> **如果一份判决的恰当性条件不满足，那么它不是"一份错误的判决"，而是"一份未能成立的判决"。**

**这个区分比"错判"更彻底：**

|      | 错判           | 未能成立的判决                       |
| ---- | -------------- | ------------------------------------ |
| 性质 | 判断的内容错误 | **判断这个行为未完成**         |
| 补救 | 改判           | **不是改判问题，而是重做问题** |
| 类比 | 说错了一句话   | **没有说出那句话**             |

#### 4.7 当事人的直觉对了一半

**当事人写道：**

> "按照奥斯汀的言语行为理论，我的转发不过无关紧要的'无效施事'，而司法文书则是真正具有塑造现实能力的'述行语'。"

**他正确地看到了两件事：**

1. 转发与判决是两类不同的言语行为；
2. 判决具有"塑造现实"的能力。

**但他漏掉了最关键的一点：**

> **判决的"塑造现实"能力，恰恰 **依赖于它的恰当性**。一个不恰当的述行语没有力量。**

**用一个类比：** 一张支票的效力不是来自"它是一张纸"，而是来自"它被正确地开出"。

**而当事人的表述隐含了相反的判断：**他似乎认为判决的力量是**自动的**（因为它来自国家）。**而奥斯汀的整个理论就是为了反驳这种看法。**

#### 4.8 卷宗的一处实质性误读

**分析中的表述更明确：**

> "在司法语境中，它属于'述行语'（Performative Utterance）：**不描述事实，仅宣示权力**。"

**这句话把一个正确的术语用在一个错误的论点上。**

**奥斯汀从未说过述行语"仅宣示权力"。** 他的整个分析是为了说明：**述行语的成功取决于条件，而不是取决于权力。**

**事实上，奥斯汀在《如何以言行事》中反复强调：** 述行语的失败（infelicity）与"权力"无关——**一个国王在错误的场合宣布一件事，他的宣布同样无效。**

**因此，卷宗的这处引用实际效果是：** 它把一个"条件理论"读成了"权力理论"，**从而使奥斯汀的分析失去了它在本案中最有用的部分。**

**而这部分正是：** 判决的效力是可以被检验的——**检验的方式是检查它的恰当性条件。**

### 五、制度性事实："虚假信息"与"严重混乱"是什么类型的事实

#### 5.1 塞尔的核心区分

**约翰·塞尔在《社会现实的建构》（1995）中提出了一个对本案极为有用的区分：**

|          | 原始事实（brute facts） | 制度性事实（institutional facts） |
| -------- | ----------------------- | --------------------------------- |
| 例子     | 这座山高 1000 米        | 这张纸值 100 元                   |
| 存在方式 | 不依赖于人的态度        | **依赖于集体接受**          |
| 需要什么 | 无                      | **构成性规则**              |

**制度性事实的构造公式是：**

> **"X 在语境 C 中算作 Y"**
>
> （X counts as Y in context C）

**例如：** 这张纸（X）在中华人民共和国境内（C）算作一百元人民币（Y）。

这个"算作"关系不是因果关系，而是**一种构成性规则**——它不是"X 导致 Y"，而是"X 被算作 Y"。

#### 5.2 制度性事实的存在条件

**按塞尔的分析，一个制度性事实要被创造出来，需要三个条件：**

| 条件                    | 内容                                      |
| ----------------------- | ----------------------------------------- |
| **1. 集体意向性** | 一个群体共同接受"X 算作 Y"                |
| **2. 构成性规则** | 存在一条规则，规定"X 在 C 中算作 Y"       |
| **3. 地位功能**   | Y 赋予 X 一种新的功能（如"可以用于支付"） |

#### 5.3 本案中的制度性事实

**"虚假信息"与"公共秩序严重混乱"都不是原始事实，而是制度性事实。**

| 表达式                   | 类型                 | 构成性规则             | 语境 C   |
| ------------------------ | -------------------- | ---------------------- | -------- |
| 一份工资单上有数字       | **原始事实**   | —                     | —       |
| 这份工资单"属于虚假信息" | **制度性事实** | 《两高解释》第5条第2款 | 刑事审判 |
| 某时段某平台数据异常     | **原始事实**   | —                     | —       |
| "公共秩序严重混乱"       | **制度性事实** | 《刑法》第293条        | 刑事审判 |

#### 5.4 本案的问题：Y 被断言，X 与 C 未被指明

**按塞尔的公式检验本案：**

| 要素                          | 要求           | 本案                                                                       |
| ----------------------------- | -------------- | -------------------------------------------------------------------------- |
| **X**（那个具体的东西） | 必须被指认     | **未被指认**——起诉书只写"散布虚假言论"，未点名任何一条内容         |
| **C**（那个语境）       | 必须被界定     | **部分界定**（刑事审判），但"公共秩序"的范围未界定                   |
| **算作规则**            | 必须被适用     | **未被适用**——判决书援引了法条，但未说明为何这些内容"算作"虚假信息 |
| **Y**（制度性事实）     | 由上述三者产生 | **被直接断言**                                                       |

**塞尔式的结论是清楚的：**

> **如果 X 未被指认、算作规则未被适用，那么 Y 就没有被创造出来。**

**法院做了什么呢？** 它跳过了 X 和规则，直接宣告了 Y。

**用一个类比：** 这就像一个人指着一堆纸说"这些是一百元"，却从不说明哪些纸、依据什么、在什么范围内。

#### 5.5 一个重要的推论：制度性事实需要公开程序

**制度性事实的"创造"依赖于集体接受；而集体接受依赖于 **公开的、可复核的程序**。**

**这是塞尔理论的一个隐含要求：**如果"X 算作 Y"要成立，那么至少要有足够多的人能够**核验** X 和规则。

**因此：**

> **一份秘密的、不可复核的"认定"，在塞尔的意义上不能创造制度性事实。**

**它只能创造一种"看起来像制度性事实的东西"——一个宣告，而不是一个事实。**

#### 5.6 与前一节（恰当性）的关系

**第五节与第四节是同一个问题的两个侧面：**

|      | 第四节（奥斯汀）             | 第五节（塞尔）                   |
| ---- | ---------------------------- | -------------------------------- |
| 关注 | 判决作为**行为**的条件 | 判决所创造的**事实**的条件 |
| 问题 | 这个行为成立吗？             | 这个事实被创造出来了吗？         |
| 结论 | 恰当性不足 → 行为未完成     | X 与规则未指明 → 事实未创造     |

**两者合起来给出一个完整的图像：**

> **法院既没有"做成"那个判决行为，也没有"创造"那个制度性事实。**

### 六、会话准则：判决书违反了全部四条

#### 6.1 格赖斯的合作原则

**格赖斯在《逻辑与会话》（1975）中提出：交际依赖于一个隐含的"合作原则"，它具体化为四条准则：**

| 准则                       | 要求                             |
| -------------------------- | -------------------------------- |
| **数量**（Quantity） | 提供所需的信息，不多不少         |
| **质量**（Quality）  | 不说自己认为假的，不说缺乏证据的 |
| **关联**（Relation） | 要相关                           |
| **方式**（Manner）   | 要清楚，避免歧义，简短有序       |

#### 6.2 逐条检验

**（一）数量准则：判决书说得太少**

| 本应提供的信息                     | 是否提供     |
| ---------------------------------- | ------------ |
| 被认定为虚假的具体陈述             | **无** |
| 传播数据                           | **无** |
| 损害评估                           | **无** |
| 不构成犯罪的理由（为何不适用但书） | **无** |

**判决书对核心问题提供了零信息，同时对非核心问题提供了大量表述**（"网络空间并非法外之地"这类普法语句）。

**（二）质量准则：无证据的断言**

**判决书写道：**"犯罪事实清楚，证据确实、充分。"

**而卷宗的证据状态是：** 无鉴定、无传播数据、无损害证明。

**这在格赖斯的框架中是对质量准则的直接违反：** 说了缺乏证据的话。

**（三）关联准则：大量无关表述**

**判决书中的"公共网络空间并非法外之地"这句话：**

- 它是对的（网络空间确实要依法）；
- 但它与本案的争点**无关**（争点不是"要不要依法"，而是"依的法是什么"）。

**这是一个典型的"关联失败"。**

**（四）方式准则：高度歧义**

**"虚假信息"与"严重混乱"这两个核心术语：**

- 在文书中均未定义；
- 它们的适用范围均未界定；
- 它们各自的含义在文书的不同位置有所不同。

**这是对"避免歧义"要求的直接违反。**

#### 6.3 一个特殊的分析：会话含义

**格赖斯最重要的贡献之一是区分"所说的"（what is said）与"所隐含的"（what is implicated）。**

**把这一区分用于判决书：**

| 表述                     | 所说的             | 所隐含的                                         |
| ------------------------ | ------------------ | ------------------------------------------------ |
| "侮辱、攻击国家领导核心" | （语法上一个描述） | **一个政治评价：这些内容在政治上是错误的** |
| "我国现行政治体制"       | （语法上一个指称） | **一个政治立场：该体制需要被保护**         |
| "网络空间并非法外之地"   | 一个正确的普法命题 | **一个态度：本案应当被追究**               |

**关键在于：**

> **"领导核心"在判决书中不是一个断言，而是一个会话含义。**

**判决书从未 **断言**："被告人的行为损害了领导核心"——它只是 **提到** 了"领导核心"，让读者自己去推断这个评价。**

**而这个区别在法律上是决定性的：**

> **只有断言才能作为定罪的基础。会话含义不是断言，因此不能作为定罪的基础。**

**用一个更尖锐的表述：**判决书把一个政治评价**藏在了**一个法律表述的**含义里**，从而使它**既发挥了作用，又逃避了证明**。

#### 6.4 格赖斯的另一个区分：自然意义与非自然意义

**格赖斯在《意义》（1957）中区分了两种"意义"：**

|          | 自然意义（natural meaning）        | 非自然意义（non-natural meaning） |
| -------- | ---------------------------------- | --------------------------------- |
| 例子     | "那些斑点意味着麻疹"               | "铃声意味着公共汽车满了"          |
| 关系     | **因果指示**                 | **交际意图**                |
| 能否"假" | 不能——斑点不会"错误地"意味着麻疹 | 能——铃声可以误响                |

**本案的关键错误在于：法院把"非自然意义"当作了"自然意义"。**

**具体地说：**

- 一篇政论**表达**了一个立场（非自然意义）；
- 而法院把它当作了一个**因果指示**——"这段内容的存在指示了秩序混乱"（自然意义）。

**这个转换是本案定罪逻辑的核心：**

> **它把"一次交际"变成了"一个症状"。**

**而症状可以被用来诊断，交际不能。** 这就是为什么法院可以"不核实"就宣布结论——**因为症状不需要被核实，它只需要被观察。**

**但内容不是症状。** 一篇政论的存在不"指示"任何东西；它只"表达"某种东西。

### 七、整体论：一个不能被孤立检验的命题

#### 7.1 蒯因的整体论

**蒯因在《经验论的两个教条》（1951）中提出了一个影响深远的论点：**

> **任何陈述都不能被孤立地证实或证伪。**

**其理由是：**我们的信念构成一个**整体**（a web of belief）；当经验与预期冲突时，我们**可以修改网络中的任何一个部分**——包括逻辑规律和观察陈述。

**蒯因的著名表述是：**

> "**整个科学是一个力场，其边界条件是经验。**"

**其含义是：**检验总是针对**整个理论系统**，而不是针对单个命题。

#### 7.2 本案的核心命题需要什么背景理论

**"转发造成公共秩序严重混乱"这个命题，不能被孤立地检验。**

**它需要一整组背景理论：**

| 需要的背景理论                         | 本案是否提供 |
| -------------------------------------- | ------------ |
| 信息传播的模型（传播速度、范围、衰减） | **无** |
| 影响评估的方法（如何测量"混乱"）       | **无** |
| 因果推断的标准（如何排除其他原因）     | **无** |
| "严重"的阈值（达到什么程度算严重）     | **无** |

**四组背景理论全部缺失。**

**因此：**这个命题不是"未被证明"——而是**在逻辑上不可检验**。**因为检验需要背景理论，而背景理论不存在。**

#### 7.3 蒯因的"免疫策略"

**蒯因指出了一个重要的现象：**当一个理论遇到反例时，我们**可以**修改网络中的任何一个部分。

**其中一种修改方式，他称之为"免疫策略"（immunizing stratagem）——通过修改定义或引入特设性假设，使核心命题免于被反驳。**

**本案的免疫策略是清楚的：**

| 反例                         | 法院的修改                                               |
| ---------------------------- | -------------------------------------------------------- |
| 漫画没有真假 → 不是虚假信息 | **把"虚构"纳入"虚假"**                             |
| 情感表达没有真假             | **把"主观表达"纳入"虚假"**                         |
| 观点没有真假                 | **把"立场"纳入"虚假"**                             |
| 无传播数据证明混乱           | **把"混乱"的定义从"可观察"改为"内容敏感即可推定"** |

**这四次修改的方向完全一致：** 每一次都把定义扩大，以保护核心命题（"这些内容属于虚假信息，且造成了混乱"）。

**蒯因的判断是：** 这种修改在逻辑上是允许的，**但它使理论失去了经验内容**——一个可以容纳任何证据的理论，不能被任何证据反驳。

**而一个不能被反驳的理论，在刑事诉讼中就是不能被检验的主张。**

#### 7.4 蒯因的本体论判准

**蒯因在《论何物存在》（1948）中提出了一个著名的判准：**

> "**存在就是成为变项的值。**"
>
> （To be is to be the value of a variable.）

**其含义是：**一个理论承诺了哪些实体，取决于**它为了使自己的论断为真而必须量化 over 什么东西**。

**把这个判准用于本案：**

**法院的理论承诺了"严重混乱"这个实体**——因为它的论断"造成公共秩序严重混乱"要为真，必须存在一个 x 使得 x 是严重混乱。

**而这个 x 在本案中从未成为任何证据命题的变项的值。**

**蒯因式的结论是：**

> **按法院自己的理论，它承诺了"严重混乱"这个实体；但它在证据中从未兑现这个承诺。**

**因此，这个理论是 **不融贯的**：它在本体论上承诺了某物，在证据论上却无法提供它。**

### 八、宽容原则：一个被不对称使用的原则

#### 8.1 戴维森的宽容原则

**戴维森在《真理与意义》（1967）及后续著作中提出了"宽容原则"（principle of charity）：**

> **在解释他人的言语与行为时，我们必须最大化其信念的真与合理性。**

**其理由是：**如果我们假定说话者大部分信念为假、大部分推理不合理，那么我们就**无法解释**他的言语——因为我们无法确定他在说什么。

**因此，宽容不是一个道德态度，而是 **解释的可能性条件**。**

#### 8.2 本案的不对称应用

**把宽容原则用于本案的两个对象：**

**（一）对被告：最小宽容**

| 法院的假定             | 宽容度                     |
| ---------------------- | -------------------------- |
| 他"明知"信息是虚假的   | **假定他知道真相**   |
| 他转发是有意扰乱秩序   | **假定他有恶意**     |
| 他的学术研究目的不成立 | **假定他的自述为假** |
| 他的专业判断不可采信   | **假定他的能力不足** |

**（二）对控方：最大宽容**

| 法院的假定             | 宽容度                               |
| ---------------------- | ------------------------------------ |
| "证据已形成锁链"       | **假定控方的断言有意义**       |
| "经梳理均属于虚假信息" | **假定"梳理"是一个有效的方法** |
| "造成公共秩序严重混乱" | **假定该断言有所指**           |
| 无鉴定意见             | **不追问**                     |

#### 8.3 一个方法论错误

**戴维森的宽容原则要求：** 在同一个解释实践中，**对不同对象使用相同的宽容度**。

**而本案使用了完全相反的宽容度：** 对被告最小宽容，对控方最大宽容。

**这在方法论上是一个错误，理由如下：**

**宽容原则的功能是使解释成为可能。** 如果对被告不适用宽容，那么他的行为就**不可解释**。

**检验这一点：**

| 解释框架               | 被告的行为是什么                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------ |
| 法院的框架（最小宽容） | 一个博士、一个研究者，为了"打发时间"，冒着刑事风险转发了一些他自己也不确定真假的内容 |
| 宽容的框架             | 一个研究者，按照其专业习惯收集、保存、整理资料，以备后续研究                         |

**哪一个更可理解？**

**显然是后者。** 法院的框架要求我们相信：一个人**明知**内容是虚假的，却仍然转发，**但没有因此获得任何利益**（无粉丝增长、无经济收益、无政治影响）。

**这个解释在戴维森的意义上是失败的**——因为它使被告的行为**不可理解**。

#### 8.4 一个更尖锐的表述

**法院的解释框架，隐含了一个自相矛盾：**

> **它同时假定被告"明知"（因此有认知能力）和"不明智"（因此无合理动机）。**

**而一个真正"明知是虚假信息"的人，为什么要转发？**

**法院的答案隐含在"寻衅滋事"这个罪名里：** 因为他想"起哄闹事"。

**但这个答案又与我们已知的事实冲突：** 据卷宗，互动趋近于零，无任何聚集，无任何后果。

**因此：** 法院的解释框架在戴维森的意义上是不融贯的——**它为了归罪而假定了一个不可理解的动机。**

### 九、常识的方法：一个与常识冲突的结论

#### 9.1 摩尔的常识方法

**摩尔在《为常识辩护》（1925）中提出了一个方法论立场：**

> **有些命题我们以确定性知道（例如"我有两只手"）；任何与这些命题冲突的哲学理论都是错的。**

**他的论证方式很特殊：** 他不去证明这些命题，而是指出——**任何试图怀疑它们的论证，都比这些命题本身更可疑。**

#### 9.2 本案与常识的冲突

**本案的结论是：** 一个关注者不足百人、转发总量不足百次、互动趋近于零的人，通过转发若干公开内容，"造成公共秩序严重混乱"。

**这个结论与常识的冲突是明显的：**

| 常识命题                             | 本案的结论               |
| ------------------------------------ | ------------------------ |
| 一个人数极少的传播不会造成大范围影响 | 造成了严重混乱           |
| 转载公开出版物通常不构成犯罪         | 构成寻衅滋事罪           |
| 学历高的人更容易识别虚假信息         | 学历高被用来推定其"明知" |
| 艺术作品不涉及真假                   | 漫画被认定为"虚假信息"   |

#### 9.3 摩尔式的判断

**摩尔的方法会给出一个判断：**

> **如果一套理论导致"一个粉丝不足百人的转发者造成了公共秩序严重混乱"这个结论，那么这套理论有问题。**

**这个判断的力量在于：** 它不需要反驳那套理论的任何具体步骤，**它只需要指出结论本身的不可信。**

#### 9.4 一个必要的限定

**必须指出：常识不是法律标准。**

**在本案中，常识不能替代构成要件审查，也不能替代证据。**

**但常识在刑事诉讼中有一个确定的位置：它是"合理怀疑"的来源。**

**《刑事诉讼法》第55条要求"排除合理怀疑"。而"一个边缘节点的转发造成了严重混乱"这个判断，本身就是一个合理怀疑的来源。**

**因此，摩尔的方法在本案中的作用是有限的，但不是零：**

> **它提供了一个独立的检测点——如果一个判决的结论与普通人的常识严重冲突，那么这个判决负有更重的说理义务。**

**而本案的判决书没有承担这个义务：** 它只有结论，没有论证。

### 十、这套方法能做什么，不能做什么

#### 10.1 能做：诊断语言的误用

**分析哲学的核心方法在本案中能够严格地确立以下几点：**

| 发现                                              | 依据                         | 强度                             |
| ------------------------------------------------- | ---------------------------- | -------------------------------- |
| 判决书混合了四个语言游戏                          | 语言游戏分析                 | **强**                     |
| "梳理认定"的判准是私人的                          | 私人语言论证                 | **强**                     |
| 四类内容的"语法"不同                              | "不要想，而要看"             | **强**                     |
| 转发不是断言；判决是判定式                        | 言语行为理论                 | **强**                     |
| **判决的恰当性条件不满足 → 判决未成立**    | **奥斯汀的恰当性条件** | **最强**                   |
| "虚假信息""严重混乱"是制度性事实，X 与 C 未被指明 | 塞尔的构成性规则             | **较强**                   |
| 判决书违反全部四条会话准则                        | 格赖斯                       | **较强**                   |
| "领导核心"是会话含义而非断言                      | 格赖斯                       | **较强**                   |
| 核心命题不可孤立检验；法院使用免疫策略            | 蒯因的整体论                 | **较强**                   |
| 宽容原则被不对称使用                              | 戴维森                       | **中等**（原则本身有争议） |

#### 10.2 不能做：判定事实

**这一点必须清楚：**

> **分析哲学不能告诉我们"内容是否真的虚假"——那需要事实核查。**
> **分析哲学不能告诉我们"是否真的造成了混乱"——那需要经验证据。**
> **分析哲学不能宣告一个人无罪——那需要司法程序。**

**它能做的只有一件事：**指出一个文本或一个行为**在概念上、在语用上、在制度上**是否成立。

#### 10.3 分析哲学内部的已知分歧

**本文使用了多位哲学家，而他们之间并不一致。必须交代：**

| 分歧                                       | 内容                                                         | 对本文的影响                                           |
| ------------------------------------------ | ------------------------------------------------------------ | ------------------------------------------------------ |
| **早期 vs 晚期维特根斯坦**           | 早期持"图像论"，晚期持"用法论"                               | 本文只用晚期（语言游戏、家族相似、私人语言）           |
| **理想语言 vs 日常语言**             | 弗雷格、罗素主张重建逻辑形式；后期维特根斯坦主张描述日常用法 | 本文兼用两者（前两篇用前者，本篇用后者），并注明其分歧 |
| **描述性 vs 修正性分析**             | 斯特劳森主张"描述性形而上学"；卡尔纳普主张"修正"             | 本文偏向描述性（不主张改造法律语言，只指出其误用）     |
| **"哲学作为治疗" vs "哲学作为理论"** | 维特根斯坦主张消解问题；多数分析哲学家主张建立理论           | **本文采取治疗式立场**——只诊断，不开药方       |
| **奥斯汀的恰当性条件是否过强**       | 有学者认为奥斯汀的条件过于严格                               | 本文在第四节使用时作了限定（只主张 B.1 类条件的失败）  |

#### 10.4 最重要的一点：分析哲学不做裁决

**维特根斯坦在《哲学研究》§124中写道：**

> "**哲学绝不能干预语言的实际使用……它最终只能描述它。**"

**这句话适用于本文：**

> **分析哲学能够指出一份判决在语言与行为上的失败。它不能替代那份判决。**

**但这已经足够。** 因为在本案中，那些失败不是细节问题：

- **它混合了四个语言游戏的表达式**；
- **它的核心认定依赖于一个私人的判准**；
- **它的核心命题不可被检验**；
- **它的判决行为未能满足恰当性条件**；
- **它断言了制度性事实，却未创造它**。

**这些不是"说理不充分"，而是"说理没有发生"。**

### 十一、结论

#### 11.1 分析哲学核心方法给出的评价

**把前十节的发现合起来：**

> **本案判决书在分析哲学的方法下，同时在三重意义上不成立。**
>
> **其一，在语用上不成立。** 它把四个语言游戏的表达式混在一段说理中，把"攻击"这个政治评价谓词当作"虚假"这个真值谓词的证明，把"领导核心"这个政治指称运进刑事裁判。**用一个精确的表述：它在法律语言游戏的语法中，执行了政治语言游戏的功能。**
>
> **其二，在认定上不成立。** 它的核心认定（"经梳理均属于虚假信息"）依赖于一个私人的判准——没有公布标准、没有鉴定、无法复核。**按私人语言论证，一个私人的判准不能支撑一个公共的判断。**
>
> **其三，在行为上不成立。** 它的判决是一个判定式（verdictive），而判定式的效力取决于恰当性条件。**关键条件（程序被正确且完整地执行）不满足。因此，按奥斯汀，这不是"错误的判决"，而是"未能成立的判决"。**

#### 11.2 一个必须强调的纠正

**本文开篇提出的纠正，在此重述：**

**当事人与卷宗都引用奥斯汀，用以说明"司法文书是述行语，所以它有塑造现实的力量"。**

**这个引用证明了相反的结论。**

**奥斯汀的全部理论要点在于：**述行语的效力**不是自动的**，而是**有条件的**。**条件不满足时，述行语是"无效的"（misfire），而不是"仍然有效但不当"。**

**因此：**

> **一份判决如果其恰当性条件不满足，它不是"一份有力量的判决"，而是"一份没有做成的判决"。**

**而这一点，对一个把"司法文书"当作权力工具的论证来说，是一个致命的自我反驳。**

#### 11.3 与弗雷格、罗素两篇的关系

|              | 弗雷格                           | 罗素                   | 本篇                                               |
| ------------ | -------------------------------- | ---------------------- | -------------------------------------------------- |
| 关注         | **意义**（Sinn/Bedeutung） | **逻辑形式**     | **使用与行为**                               |
| 语言模型     | 命题                             | 命题的逻辑结构         | **活动、游戏、行为**                         |
| 核心工具     | 语境原则、概念边界、空名         | 摹状词、逻辑构造、亲知 | 语言游戏、私人语言、恰当性、制度事实               |

| 结论强度     | 中                               | 强                     | **最强（在"行为是否成立"这一层）**           |

**三者合起来构成一个完整的分析：**

> **弗雷格问：它说的是什么？** ——答：它说的是一个没有边界的词。
> **罗素问：它的逻辑形式成立吗？** ——答：不成立，存在命题未被满足。
> **本篇问：它做成了什么事吗？** ——答：**没有做成。**

#### 11.5 一句话作结

**维特根斯坦在《哲学研究》§109中写道：**

> "**哲学是一场反对用语言迷惑我们理智的战斗。**"

**本案是一场被语言迷惑的审判。**

**它把一个政治评价的谓词（"攻击"）当作了一个真值谓词的证明（"虚假"）；**

**它把一个私人的操作（"梳理"）当作了一个公共的认定；**

**它把一个会话含义（"领导核心"）当作了一个断言；**

**它把一个制度性事实（"严重混乱"）宣告了出来，却从未创造它；**

**它把一个需要恰当性的行为（判决）当作了一个不需要条件的宣告。**

**而分析哲学能够做的，只是把这些混淆一件一件地摆出来。**

**它不能撤销那份判决。但当这些混淆被摆出来之后，一个问题就变得无法回避：**

> **如果那份判决所依赖的一切——谓词、认定、含义、事实、行为——都只是语言上的误用，那么剩下的是什么？**

**剩下的是一间看守所，和二十个月。**

**而那，不是语言问题。**

### 附二：材料与方法限度

#### 一、单方陈述问题

涉及破门而入、刑讯逼供、"不打算核实""上层领导特别指示办成铁案"、法官呵斥"闭嘴"、控告材料被阻断等事实，**均只见于当事人《狱中自辩暨控告血书》的转述**。

**本文的核心论证不依赖这些陈述。** 十节中的主要发现，所依据的是：

- 判决书"本院认为"段的完整表述（第一节的语言游戏分析）；
- 判决书"转发的内容**经梳理**均属于虚假信息"这一表述（第二节的私人语言分析）；
- 起诉书列举"鉴定意见"而判决书与裁定书均无鉴定意见（同上）；
- 判决书的推理链条（第三节、第七节）；
- 判决书对"起哄闹事"要件未作认定（第四节）；
- 判决书援引《刑法》第293条却使用"领导核心""现行政治体制"（第五节、第六节）；
- 一审不公开审理、二审决定不开庭（第四节的恰当性分析）。

#### 二、关于"恰当性条件"使用的限定

**第四节使用了奥斯汀的恰当性条件，需要作两点限定：**

1. **奥斯汀本人并未专门讨论司法判决**（他的例子多是婚礼、命名、打赌）。本文把"判定式"用于判决，是**类推应用**，不是奥斯汀的原意。
2. **本文只主张 B.1 类条件（程序被正确且完整地执行）的失败**，不主张 A.2 类条件（参与者适格）的失败——**因为法院的管辖权与合议庭的组成未见违法。**

**在这一限定下，结论是：**判决的**部分**恰当性条件不满足。**而按奥斯汀，任何一项关键条件的失败都导致行为未做成。**

#### 三、关于多位哲学家之间的分歧

**本文使用了维特根斯坦、奥斯汀、塞尔、格赖斯、蒯因、戴维森、摩尔、赖尔、斯特劳森。他们之间并非一致：**

- 早期与晚期维特根斯坦立场相反；
- 蒯因批评过模态逻辑，而本文未涉及；
- 戴维森的宽容原则受到福多等人的批评；
- 塞尔的制度性事实理论受到后现代主义者的质疑。

**本文的用法是"工具式"的：**每次只取一位哲学家的**一个具体区分**，用于分析本案的一个具体问题，**不主张这些区分构成一个融贯的体系。**

#### 四、分析哲学方法的固有局限

**最重要的是：分析哲学不做裁决。**

**它能够：**指出概念的混淆、规则的缺失、行为的条件不足。
**它不能：**判定内容是否虚假、是否造成混乱、某人是否有罪。

**本文所主张的，只是前者。**

**但前者在本案中已经足够，因为：**

> **如果一个判决的每一个关键环节——谓词、认定、含义、事实、行为——都只是语言上的误用，那么它所指向的那个后果（二十个月监禁），就失去了全部依据。**

#### 五、本文的性质

本文是**哲学分析**，不是法律意见书，也不是申诉材料。文中所有评价都是**分析性判断**，而非有权机关的认定。

**本文不主张以分析哲学取代法律分析。** 法律上的结论已由《法律分析与评估报告》给出；本文的贡献仅在于说明：**如果把这些文书的语言与行为当作分析哲学的对象，它们在最基本的层面上不成立。**

#### 六、关于"十二把尺子"这一方法本身

**这一系列使用了十二种尺度：九种中国政治理论的内部尺度，加弗雷格、罗素、以及分析哲学的整体方法。**

**这一组合的特殊性在于：后三者与前九者在方法上是断裂的。**

**内在批判依赖对方承认自己的规范；语言分析不依赖任何一方。**

**因此，如果一种实践同时违反了十二种不同来源的规范与方法，那么最合理的解释不是"这十二种规范都错了"，而是"这个实践有问题"。**

**而分析哲学给出了其中最朴素的一条检验：**

> **不要问它"说的是不是真的"，先问它"做成了什么事"。**

**本案的答案是：它没有做成。**
