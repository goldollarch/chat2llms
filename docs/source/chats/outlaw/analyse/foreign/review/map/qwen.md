### 〇、地图与评级轴

**罗素框架**（《西方哲学史》1945 第一章）：确定知识属**科学**；超出最试探性表述之外的教条属**神学**；两者之间是**无人之域**——同时遭受科学、神学与形而上学三方攻击，这就是哲学。关键在常被略去的后半句：无人之域的居民必须**只讲理由、不讲 certainty**。

**本案的映射约定**：

- **科学侧**＝已确立的定理、定律、可测量数据；
- **无人之域**＝可给理由、可被反驳、不要求最终确定的论证（概念分析、规范论证、可错的经验概括）；
- **神学侧**（罗素意义上的"教条"）＝不可反驳、以权威或体认为根据的表述——包括天理/良知/道心式断言，也包括**不可证伪的解释框架的教条化**；
- **判决书**＝地图上的**越境者**：用"证据锁链""经梳理均属"的句式冒充科学侧确定性，用"领导核心不可冒犯""我觉得是谣言"的根据冒充神学侧不可错性，而它合法栖身所需遵守的无人之域规则（说理、举证、可复核）恰恰一条都未执行。
- **第六支柱的地图位置需单列**：它不在无人之域设防，也不从外部进攻神学侧，而是**进入教义内部，取用其中残存的理性构件**（实事求是、实践标准、制度根本性、法制统一、有错必纠、自我革命），用以审计该教义的执行人。故其效力条件不是"论据为真"，而是"**承诺对执行者确有约束力**"——一个政治前提，不是一个可证事实。

**可用性评级**（全表通用）：

| 级            | 含义                                                                           |
| ------------- | ------------------------------------------------------------------------------ |
| **A**   | 经一次"法言法语化"翻译后可**直接写入**申诉状/再审申请                    |
| **A−** | 可直接使用，但**收件人不是刑事审判庭**（限于政治系统渠道或作为话语包装） |
| **B**   | 须实质改造（换前提、补证据或降格）后方可用                                     |
| **C**   | 只作说理背景，不出现原术语与学者名                                             |
| **D**   | 仅限学术与档案层，**一律不入诉讼文书**                                   |

**四条越界警示**（全表反复出现的失败模式，先立于此）：

1. **废垒之戒**：不在已被科学侧放弃的阵地设防（证实原则、情感主义——见 §3）。
2. **教条漂移**：不可证伪性＝向神学侧漂移；解释力越强、对抗性程序中越无防御（欧陆外圈的结构性代价）。
3. **身份论证陷阱**：判决的"高学历=明知"与辩护的"守道之士/顶级心智/本真此在"**共享同一前提**（以当事人社会位阶作论证环节）。一切身份型辩护在此案中都自我拆台——两侧握手的那个前提必须整个放弃，立足点只能是"任何公民"。
4. **高危话语隔离（本表新增，由第六支柱带来）**：入件风险不只来自"过于学术"，也来自"过于革命"。汇编中借文革文体的极左段落（发动群众、打倒司法黑帮、资产阶级法权、斗争先声），其被拒收与连带致害概率**高于自由主义与欧陆批判话语**，因为它们与官方自身的历史定性（1981 年决议）正面冲突——材料 p1782 已引该决议自我设限。凡以阶级专政、群众斗争语态写成的段落，一律整段隔离，**不得与其余材料同件递出**。

### 二、把总表读成一条防线：四种话术，四道边检

判决书任何一次自我辩护只会取四种形式，各自撞上一条边界——**且第四条撞在不同的地点**：

1. **"这是有证据支撑的事实断言"**（"造成严重混乱"）→ 撞 **Daubert 边防**（中国对应：证据种类、完整性校验、鉴定程序、§55 排除合理怀疑）→ 科学支柱的实测证据包与概念区分拦截：无数据则连进入审查的门槛都未达到。**拦截地：法庭。要求交出：数据。**
2. **"这是不容置疑的价值真理"**（"领导核心不可冒犯""法外之地论"）→ 撞 **无人之域的规范责任**（说理义务、权衡义务、明确性）→ 富勒八项＋阿列克西＋卢曼转化版拦截：价值断言不得冒充构成要件；未适用条文自身的区分标准即"适用法律确有错误"。**拦截地：法庭。要求交出：理由。**
3. **两条都不走，径以权力宣告**（"未提交新证据，驳回"）→ 这正是罗素所说无人之域**遭受攻击**的形态本身——撞程序刚性：§238 违反公开审判**应当**发回、§234 应开庭而不开庭、举证责任法定不得倒置。**拦截地：法庭。要求交出：程序。**
4. **"这是政治大局、维护核心、稳定所需"**（第四种也是最后一种退路：不再谈事实、不再谈规范、不再谈程序，而谈政治站位）→ 前三道边检在此处都会松动，因为它们在法庭内部与政治话语**没有共同语言**。拦住它的只有 **承诺边检**：以该权威**自己确立的公开承诺**作尺——制度不因领导人看法与注意力而改变（反注意力式追诉）、实事求是与实践标准（反"我觉得是谣言"）、法制统一（反选择性追诉）、有错必纠与自我革命（反拒绝纠错）、"让人民群众在每一个司法案件中感受到公平正义"（反以稳定之名制造不义）。其结构是：**不用外部价值反驳其政治理由，而用其政治理由的官方原文反驳其政治理由。** 拦截地：**不在法庭，在政治系统**（政法委、纪检监察、人大、检察；并作为检察监督与依职权再审的递呈依据）。要求交出：**一致性**。

由此可得全案的元诊断：**错判不是选错了答案，而是拒答了问题**——它跳过的恰恰是无人之域的全部义务（定义、举证、说理、权衡、公开）。六类解构工具的互补性在于各自要求交出一样东西：科学要**数据**，分析哲学要**理由**，欧陆要**制度说明**，程序论要**程序**，诸子要**名实相副**，内部检验要**言行一致**——而六样它一样都没交。

> 四道边检的合成效果：前三道把判决逼回法庭内它唯一合法的位置（必须给理由的论证场），第四道把同一问题送到法庭之外的另一个机关（必须兑现承诺的政治系统）。**这就是为什么本表既要有 A 级法条主张，也必须保留一条 A− 级政治通道——两者收件人不同，缺一则整案无出口。**

### 结语：谱系的一句话总纲

按罗素地图重排后，这部 10194 页汇编的全部方法野心可以收成一句：

> **它发动了整张知识地图上的一切法院来审判一桩判决，最终发现只有法庭内的那个机关有管辖权——而它受理的从来不是"哪套理论为真"，只有两样东西：证据与程序。**
> 科学解构的价值在于把自己**转化**为证据（鉴定），哲学解构的价值在于把自己**翻译**为程序请求（发回、开庭、说理），诸子解构的价值在于证明连最工具主义的传统都不认这份判决，而第六支解构的价值在于：它是唯一一支**不引入任何外部标准**、只把判决方的承诺原样递回其手中的——因此也是唯一能给整份材料换上一件在收件人面前最不易被拒收外衣的。
> 五者共同的伦理，仍是无人之域的那条古老戒律：**只讲理由，不讲 certainty；要求别人如此，自己先如此。**
