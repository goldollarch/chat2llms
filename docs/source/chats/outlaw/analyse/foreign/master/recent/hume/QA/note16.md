# 休谟如何看待正义与社会契约

在大卫·休谟（David Hume）的政治与道德哲学体系中，对 **正义（Justice）** 与 **社会契约（Social Contract）** 的理解建立在他的经验主义和实用主义根基之上：

### 1. 正义并非先验原则，而是“人为的美德”（Artificial Virtue）与社会约定

休谟认为，正义并非某种永恒存在、先验给定的自然法则，也不是人类生来就具备的原始本能。相反，正义是一种 **“人为的美德”（Artificial Virtue）**。

* **社会约定（Convention）**：正义源于人类在长期社会互动中形成的经验与约定。为了解决资源稀缺性以及人类有限的利他倾向（Selfishness and Confined Generosity），人类逐渐总结并确立了关于财产权、契约履行与承诺恪守的社会约定。
* **经验基础**：这些约定并非来自抽象理性的逻辑推导，而是在社会实践中被证明能够维护秩序与合作的经验结晶。

### 2. 正义的根基在于“社会功用”（Social Utility）与“同情”（Sympathy）

正义制度之所以具备道德上的正当性与约束力，完全取决于其能否带来促进公共幸福的**经验功效**：

* **公共利益与实用性**：休谟主张，正义的唯一根基在于促进社会整体的福祉、和平与公共利益。如果某项刑罚或法律规则不能带来整体社会效益的提升，反而仅仅制造恐惧与痛苦，那么它就彻底丧失了正义的经验基础。
* **同情（Sympathy）的道德纽带**：休谟认为道德判断建立在人类普遍的“同情”情感之上。人们之所以赞许正义行为、背离不正义，是因为人类能够对他人的苦乐以及社会整体的安危产生共鸣。如果司法系统割裂了对具体个人福祉的同情，转而盲目服从抽象的权力意志，正义便会发生扭曲。

### 3. 解构传统“社会契约论”：以“习惯与实用”替代“原始契约”

休谟对霍布斯、洛克等人的传统 **社会契约论（Social Contract Theory）** 持深刻的怀疑态度，并进行了有力的解构：

* **拒绝虚构的历史契约**：休谟指出，在历史上并不存在一个全社会成员共同签署“原始契约”的真实起点。绝大多数政权和统治的建立，本质上源于战争、征服、篡夺或权力的既成事实。
* **政治服从的真实基础**：人们之所以服从政府和法律，并不是因为恪守某种虚构的历史誓言，而是出于**实用性（Utility）**和**心理习惯（Custom）**。人们意识到有组织的政府能够维持秩序和保护产权，从而在心理上养成了对权威的顺从习惯。

### 4. 经验主义对现代司法与政权的批判警示

休谟关于正义与约定的论述，对公权力的合法性提出了明确的经验检验标准：

* **反对“形而上”的权力独断**：当政权或司法机关脱离经验事实与公共利益，凭空制造合法的“必然性幻觉”或强加绝对信念时，实际上破坏了社会约定的基础。
* **正义的防线**：任何统治或司法判定，若失去了对人道同情的关注以及经验可察的社会功用，便会退化为依靠威慑与恐惧维持的强权，违背了休谟所阐释的正义之本质。
