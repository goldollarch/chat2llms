# 从弗雷格的思想看，将艺术漫画定性为“谣言”犯了什么错误

从弗雷格（Gottlob Frege）的分析哲学视角来看，将艺术漫画定性为“谣言”不仅是法律适用上的错误，更是一场**对语言逻辑基础的系统性践踏**。这一做法在逻辑和语义层面犯了以下核心错误：

### 一、 混淆“意义”（Sense）与“指称”（Reference）

弗雷格区分了符号的“意义”（Sinn，即呈现方式或认知价值）与“指称”（Bedeutung，即实际指向的对象或真值）。

* **指称的失效**：弗雷格认为陈述句的指称是其**真值**（真或假）。然而，艺术漫画（如涉案的“撑伞女孩”或讽刺画）本质上是象征、隐喻和审美表达，**不具备可证伪的“真值”属性**。将艺术表达强行定性为具有真假属性的“虚假信息”，在逻辑上属于试图给不具指称（真值）的对象强加真值。
* **意义的单一化压制**：漫画的“意义”是多元的（可能包含批判、艺术鉴赏、情感宣泄或哀悼），但司法逻辑将其意义暴力还原为单一的“侮辱”或“攻击”，这被称为 **“意义还原主义”的逻辑谬误**。

### 二、 犯了“范畴错误”（Category Error）

弗雷格严格区分 **“概念”**（函项）与 **“对象”**（实体）。

* **对象属性的错置**：艺术漫画作为一个具体的“对象”，其属性属于审美和思想表达范畴。司法机关将其定性为“谣言”，是强行将一个不属于“可证伪事实”范畴的对象填充进“虚假信息”这一概念函项中。
* **概念的非法膨胀**：这被评价为一种 **“逻辑上的欺诈”**，即将“谣言”这一本应针对客观事实陈述的概念，无限扩大外延以吞噬艺术创作，导致逻辑函项失去了确定的定义域。

### 三、 违背“语境原则”（Context Principle）

弗雷格强调：“只有在句子的语境中，一个词才有意义”。

* **去语境化的语义暴力**：司法逻辑将漫画从其**丰富的艺术与社会语境**（如象征性、讽刺性、历史背景）中剥离出来，进行孤立解读。
* **逻辑不连贯**：这种做法无视了漫画在逻辑系统中的原本作用，将其异化为一种“犯罪工具”，破坏了法律体系作为一个逻辑一致的“语句系统”的整体性。

### 四、 陷入“心理主义”（Psychologism）的谬误

弗雷格坚决反对将逻辑和真理归结为主观心理过程。

* **以主观感性替代客观逻辑**：将漫画定性为谣言，往往不是基于客观的逻辑验证，而是基于执法者的**主观感受或政治担忧**（如“我觉得它是攻击就是攻击”）。
* **否定思想的客观性**：弗雷格认为“思想”是客观可讨论的内容。将漫画表达的客观思想污名为“谣言”，本质上是司法机关用主观推定取代了客观验证，否定了思想独立于心理状态的客观地位。

**总结结论：**
从弗雷格的思想看，这种定性导致了 **“指称结构的虚空”**。它揭示了当司法拒绝承认“一幅漫画可以是艺术、抗议或隐喻，但绝非谣言”时，法治便沦为了披着法律外衣的非理性暴力，最终导致了 **“理性的葬礼”**。
