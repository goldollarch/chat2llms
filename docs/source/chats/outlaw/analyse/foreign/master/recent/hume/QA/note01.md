# 什么是休谟的经验主义

**大卫·休谟（David Hume）** 是18世纪苏格兰启蒙运动时期的著名哲学家，也是英国经验主义的集大成者与温和怀疑论的代表。休谟的 **经验主义（Empiricism）** 主张人类的一切知识均源于感官经验，其核心理论与推论主要体现在以下几个维度：

### 1. 认知来源：印象与观念（拷贝原则）

休谟将人类心灵的一切认知内容（知觉）分为两大类：

* **印象（Impressions）**：指当下直接、生动、强烈获得的感官感知与内心情感体验。
* **观念（Ideas）**：指印象在记忆和想象中留下的相对模糊、褪色的副本。

休谟由此提出了著名的**拷贝原则（Copy Principle）**：一切简单观念都必然源于先前对应的简单印象。如果一个抽象术语或概念无法追溯到任何直接的感官印象，那么它在经验上就是无意义的虚构或幻想（语言幻象）。

### 2. 因果关系批判与心理习惯

在经验论的基础上，休谟对传统的“因果必然性”进行了深刻解构：

* 人类在感官经验中只能观察到事件在时间与空间上的接续、接近以及多次重复出现的 **“恒常联结”（Constant Conjunction）**，但从未在经验中观察到事件之间客观存在的“必然联系”。
* 所谓的因果推断并非理性的必然逻辑，而是心灵在多次经验重复后形成的**心理习惯（Custom）与心理联想**。

### 3. “自我”实体的解构（心理束理论）

休谟将经验主义应用于对“自我”概念的审视，提出了**心理束理论（Bundle Theory of Self）**：

* 当人类进行内省时，感官所能捕捉到的仅仅是一束永恒流动、接连出现的具体知觉与情绪，而无法观察到任何独立、固定、恒常的“自我实体”。
* 因此，“自我”只不过是一堆以极快速度流动变幻的知觉集合。

### 4. 事实与价值的划界（休谟铡刀 / 是-应当问题）

休谟在伦理学中提出了著名的 **“是-应当”问题（Is–Ought Problem）**：

* 人们无法纯粹从描述性的“是”（Is，客观事实陈述）中，通过逻辑演绎直接推导出规范性的“应当”（Ought，道德义务或命令）。
* 道德与价值判断的根基在于人类的主观 **道德情感（Moral Sentiment）** 与同情，而非纯粹的客观理性。休谟为此提出了名言：“理性是且应当仅是情感的奴隶”。

### 5. 划清理解界限的“温和怀疑论”

休谟的经验主义最终导向了一种**温和的怀疑论（Moderate Skepticism）**：

* 怀疑论的目的不是否定日常生活的知识，而是为了**划清人类理解与理性的界限**。
* 它提醒人们保持**理性的谦卑**，承认许多日常依赖的信念根植于人类的自然本能与心理习惯，而非不可动摇的先验理性。
