Legal
=========

法律哲学（Legal Philosophy，又称法理学、法哲学，Jurisprudence）是哲学与法学交叉的核心领域，它探讨 **法律的本质、法律与道德的关系、法律的正当性、法律解释、司法推理、权利与义务、法治、法律权威等根本性问题**。
法律哲学不仅为法律体系提供理论基础，也深刻影响了立法、司法、法律改革以及我们对“什么是良法”“什么是公正”的理解。

主要包括：

1. **自然法理论** （如阿奎那）：强调法律必须符合道德，不正义的法律不是真正的法律。
2. **法律实证主义** （如哈特、奥斯丁）：认为法律是社会规则，其效力不依赖于道德。
3. **德沃金的整全法理论**：认为法律包含道德原则，法官应追求正义与一致性。
4. **法治与程序正义理论** （如富勒、拉兹）：强调法律必须通过正当程序平等适用。
5. **法律现实主义** （如霍姆斯）：指出法律本质受社会与法官判断影响。

这些工作不仅塑造了现代法律理论与制度，也持续影响着我们对法律本质、法律实践与法律改革的理解。
