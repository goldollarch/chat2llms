### 二、舍勒现象学哲学的核心思想

（1）价值的层级与情感直觉
舍勒认为，价值是客观的、独立于个体意志的存在。
但人类通过理性无法直接认识价值，只有 **通过情感直觉（Gefühlsintuition）** 才能领悟其层级。

他提出了五个主要的价值层次：

1. **感官价值（愉快—痛苦）**
2. **生命价值（健康—病弱）**
3. **精神价值（真理、美、正义）**
4. **宗教价值（神圣—亵渎）**
5. **人格价值（爱与尊严）**

舍勒强调：社会的正义与文明，建立在高层次价值对低层次价值的统摄之上。
当政治系统将感官的、功利的、权力性的价值凌驾于精神与人格价值之上，
社会就陷入“倒错的爱”（*perverser Ordo amoris*）状态——
即爱与尊重的秩序被颠倒。
