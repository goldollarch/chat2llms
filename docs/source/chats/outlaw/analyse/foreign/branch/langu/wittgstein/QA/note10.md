# 私人语言论证如何解构司法推定

在路德维希·维特根斯坦（Ludwig Wittgenstein）的晚期哲学中，**“私人语言论证”（Private Language Argument）** 是一个用以摧毁主观主义与本质主义的重磅理论。维特根斯坦指出，一种完全基于个人内心感觉、缺乏公共可检验标准（Public Criteria）的“私人语言”在逻辑上是不可能成立的。语言的规则与意义必然依赖于社会共同体在公共“生活形式”中可检验、可质证的公共实践（Communal Practice），而不能建立在个体的私自解释或内心感觉之上。

将这一理论引入对司法判决（如陈京元案）的审查，能够从语言学与法逻辑的根基上，彻底解构“高学历应明知”等 **司法推定（Judicial Presumption）** 的专断性与虚妄性：

---

### 一、 解构维度一：将主观证明退化为不可检验的“司法私人语言”

在刑事司法中，“明知”是对行为人真实心理状态的事实认定，必须依赖客观、公共的证据（如事先警告、明确供述、特定避查行为等）加以证实。

* **司法推定的病理**：裁判者在缺乏公共证据证明被告人心理真实状态的情况下，建立“高学历” \\(\rightarrow\\) “应辨别是非” \\(\rightarrow\\) 推定“明知是虚假信息”的推理链条。这实质上是以裁判者个人“觉得是谣言”、“认为博士就必然明知”的主观感觉，替代了公共举证责任。
* **私人语言的破产**：私人语言论证指出，无法被他人公共质证与验证的内部感受不能构成规则。这种脱离了公共经验证据、仅凭裁判者内心感觉完成的逻辑跳跃，正是典型的 **“司法私人语言”**。它缺乏主体间可验证性（Intersubjective Verifiability），使本应具备公共约束力的法律要件降格为裁判者的单方主观独白。

---

### 二、 解构维度二：揭示规则遵循（Rule-following）中的逻辑自相矛盾

维特根斯坦强调，遵守规则是一项公共实践，不能等同于个体的“私人解读”或主观推断。

* **推定的内在矛盾**：私人语言论证揭示了司法机关在适用规则时的自我证伪。法官一方面在私人推定中认可被告人“具有很高学历与知识水平”、“能够明辨是非”，以此作为“明知故犯”的理由；另一方面又在判决中将其认为理性的表达判定为“非”并判刑，甚至在庭审中剥夺其运用专业知识进行自辩的资格，这在实质上宣判被告人“没有明辨是非的能力”。
* **自我归谬**：如果被告人真的具备高辨别能力，何以分辨不出裁判者眼中极其显而易见的“谣言”？如果被告人缺乏辨别能力，又如何推定其“明知”？ 这种依赖私人直觉的逻辑强焊，无法形成任何可被共同体遵循的公共规则，暴露出司法推定并非在“遵循规则”，而是在滥用权力制造“私人规则”。

---

### 三、 解构维度三：剥离权力修辞，恢复概念的公共经验指称

私人语言论证要求语词在公共生活形式中拥有清晰的经验指称（Observable Referents），反对语词脱离使用场景而空转。

* **经验事实的抽空**：在司法推定的掩盖下，“明知”与“造成公共秩序严重混乱”被直接并列硬焊。判决书未提供任何点击量、传播链条或线下骚乱数据，彻底脱离了公共经验世界（如陈博士账号粉丝不足百人、实际传播力近乎为零的事实）。
* **修辞的还原**：私人语言论证通过坚持“公共可检验性”，将这些被权力强行等同的修辞剥离，暴露出“严重混乱”与“主观明知”在此类文书中仅是缺乏经验实体对应的“伪命题”与“指称缺失”。

---

### 总结

从维特根斯坦的视角看，私人语言论证对司法推定的解构表明：**法律裁判绝不能成为裁判者私人感觉的独白**。任何缺乏公共经验证据支持、仅凭裁判者主观想象与身份标签完成的“主观推定”，在语言哲学上都是无法成立的“私人语言”。只有重新回归公共证据裁判、严密验证主客观因果链，法律语言才能恢复其公共性、确定性与正义价值。
