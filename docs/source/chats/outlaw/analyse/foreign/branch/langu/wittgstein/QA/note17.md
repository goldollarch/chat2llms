# 用“遵守规则悖论”或“私人语言论证”解构司法裁判中的主观推定

从路德维希·维特根斯坦（Ludwig Wittgenstein）晚期哲学视角切入，**“规则遵循的悖论”** 与 **“私人语言论证”** 为解构司法裁判中“高学历应明知”等主观推定（Presumption）提供了严密的语言学与法逻辑工具。在陈京元案中，公检法机关以被告人“具有很高学历和知识水平”倒推其“应能明辨是非”，进而判定其主观上“明知是虚假信息/攻击内容而转发”。这一主观归罪链条在维特根斯坦的两大理论下被彻底解构为 **逻辑上的自我归谬与规范上的自我消解**。

---

### 一、 “规则遵循的悖论”如何解构“高学历应明知”的主观推定

维特根斯坦在《哲学研究》（§201）中提出了**规则遵循的悖论**：如果“遵循规则”依赖于个人内心私下的“解释”（Interpretation），那么任何行为方案都可以经由巧言解释被说成是“符合规则”或“违反规则”的，规则本身便会失去规范约束力。打破这一悖论的关键在于明确：**遵循规则是一种建立在公共生活形式与习惯基础上的“公共社会实践”，而非私下的心理解释**。

这一理论对司法主观推定的解构体现在以下层面：

1. **将公共法律规则降格为“私下的逻辑解释”**：
   刑事司法规则明确规定：**主观故意/明知属于心理事实，必须由具体的客观证据加以证明，严禁基于身份进行主观推定**。然而，裁判者在缺乏聊天记录、供述、辟谣通知等事实证据的情况下，私自发明了一条解释链条——将法条中的“明知”拉伸为“高学历” \\(\rightarrow\\) “应能明辨是非” \\(\rightarrow\\) “必然明知”。这种将规范性注意义务（“应知”）偷换为刑事主观要件（“明知”）的做法，正是**以裁判者私下的任意解释取代了公共法律规则**。
2. **导致法律规则规范性的彻底消解（“规则的终结”）**：
   当裁判者可以凭主观意志将任意身份特征（如学历、职业）解释为“主观明知”的充要条件时，法定的“明知”要件就被完全虚置。任何不悦的表达都可以被事后“解释”为被告人明知故犯，这就陷入了规则遵循悖论中的规范破产——**规则不再能够约束司法权力，权力反而可以在事后任意“创造规则”与“套用口袋”**。

---

### 二、 “私人语言论证”如何解构司法中的“主观独白”

维特根斯坦的**私人语言论证**指出，一种完全基于个体内心感觉、缺乏公共可检验标准（Public Criteria）的“私人语言”在逻辑上是不可能成立的。语言的规则与意义必然依赖于主体间可验证的公共实践。

这一论证在解构司法专断时展现出极强的杀伤力：

1. **揭露主观推定缺乏“公共可检验标准”（Intersubjective Criteria）**：
   在刑事诉讼中，“明知”必须依赖公共、客观的指称（如是否曾被明确告知删帖、是否使用暗语规避审查等）。然而，办案人员“觉得是谣言”或法官“认为博士必然明知”的主观直觉，完全属于不可被公共质证与验证的内部感觉。**这种缺乏公共证据证明的主观推断，本质上就是一种“司法的私人语言”**。它使严肃的法庭裁决沦为裁判者无法被外部检验的单方独白与权力宣告。
2. **揭示“身份归罪”在语用和逻辑上的自我归谬（内在矛盾）**：
   私人语言论证要求公共规则在实践中保持一致性，不能根据主观需要随意切换标准。司法机关在主观推定中构建了一个双重标准的逻辑死结：

   * **需要归罪时**：认可被告人的“高学历与高知识水平”，认定其具有极高的理性与“明辨是非能力”，据此推定其“明知故犯”。
   * **庭审自辩时**：当被告人试图运用其专业知识进行逻辑与实证抗辩时，法官却粗暴打断（如“闭嘴，问你什么回答什么”），剥夺其运用判断力的资格，实质上宣判被告人“没有明辨是非的能力”。

   这种**既认定其“极具辨别力”又裁定其“毫无辨别力”的自我矛盾（反证法归谬）**，暴露出裁判者并非在客观寻找事实，而是陷入了缺乏公共语法约束的私人修辞与权力霸权怪圈。

---

### 总结

从维特根斯坦晚期哲学来看，对“高学历应明知”等司法推定的解构表明：**法律裁判绝不能退化为裁判者私人直觉与身份标签的“私人语言”**。任何缺乏公共经验证据支持、仅凭“身份–能力–应知”链条完成的主观推断，在语言哲学与刑事法理上都是无法成立的“伪命题”与“规则滥用”。法律要恢复其正义价值，就必须废除私人性的主观推定，重回**以公共证据、经验质证和主体间可检验性为基石的规则遵循轨道**。
