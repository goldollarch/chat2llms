# 涉案Twitter账号数据证明了社会秩序未受混乱

根据这些来源，陈京元通过其涉案Twitter账号（**@_cenjoy**）的多项量化数据，系统性地反驳了“造成公共秩序严重混乱”的指控。这些数据证明其言论行为在客观上几乎没有产生任何社会影响。

以下是证明社会秩序未受混乱的关键数据和实证：

1. **极低的关注人数（粉丝量）**：
   该账号并非具有影响力的大型内容创作者，其**粉丝数不足100人**，且其中大部分被识别为“僵尸粉”。
2. **极低的活跃度与转发总量**：
   陈京元二十多年来在全部社交网站上转发过的贴文总量**不超过100次**。工具查询显示，涉案帖子的**互动量（Engagement）几乎近似于零**，例如部分被作为“罪证”的贴文，其实际转发数和评论数均为零。
3. **缺乏传播效应的“自然实验”**：
   陈京元在刑满释放后观察发现，所有被指控为引发“严重混乱”的“犯罪铁证”至今仍完好无缺地存在于网络上，但其状态是**无人关注、无转发、无讨论**。来源指出，这一实证结果有力地证伪了“危害后果”的存在，因为真正的“谣言”若具备破坏力，理应已被官方删除或引发了广泛的社会动荡。
4. **科学层面的因果断裂**：
   陈京元利用其“非线性复杂系统”专业背景论证，他在网络拓扑结构中仅仅是一个 **“边缘节点”**。基于无标度网络的鲁棒性原理，这种边缘节点的微弱扰动在物理上**不可能触发系统性的“雪崩效应”**（即社会秩序混乱）。

这些来源强调，司法机关在未能提供群体性事件、公共场所骚乱、网络瘫痪或政府应急响应等任何**可观测、可验证的经验证据**的情况下，直接通过“扣帽子”的方式认定“严重混乱”，在法理上被认为是站不住脚的。

**比喻：**
陈京元的转发行为就像是往波涛汹涌的大海里**投入了一粒微小的石子**；司法机关却宣称这粒石子引发了全球性海啸，而现实中海面上甚至连一圈能够被察觉的涟漪都没有留下。
