### 一、荣格分析心理学核心思想简述

荣格的分析心理学不同于弗洛伊德的“性驱力学”，它关注的是**人类心灵的整体结构与象征秩序**。在荣格看来，个体心理与集体文化、神话结构密不可分，每一个社会事件都可以被理解为 **“集体无意识的显影”**。其核心概念如下：

1. **集体无意识（Collective Unconscious）**
   指超越个体经验的普遍心理结构，是人类共同的精神遗产，包含原型（archetypes）等象征性意象。社会冲突往往是集体无意识中压抑内容的投射。
2. **原型（Archetype）**
   是人类经验的原初形象，如“父权”“英雄”“智者”“殉道者”“审判者”等，这些象征支配着社会角色和集体想象。
3. **人格面具（Persona）与阴影（Shadow）**
   Persona是个体或群体对外展示的“社会自我”；
   Shadow是被压抑、否认或投射到他人身上的黑暗面。
   当社会过度强调道德与秩序时，阴影会在压抑之处复活。
4. **个体化（Individuation）**
   是人格整合过程，即个体在直面阴影、整合对立后，实现“自性（Self）”的心理成长。
   荣格认为，社会也有“集体个体化”阶段——文明必须面对自身的阴影，否则将陷入神经症。
