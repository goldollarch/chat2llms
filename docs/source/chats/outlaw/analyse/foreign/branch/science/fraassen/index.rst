Bas van Fraassen
==================

基于​范·弗拉森（Bas van Fraassen）的 **​​建构经验论** ​​——这一当代 **反实在论** 的核心代表理论。

---------

范·弗拉森是当代科学哲学界极具影响力的人物，他以提出 **“建构经验论”** 而闻名，这一理论是对主流的 **“科学实在论”** 最有力、最精致的挑战之一。他的核心思想可以概括为：**科学的目标不是追求“真理”，而是追求“经验适当性”；我们接受一个理论，不是因为相信它为真，而是因为它能在经验上“拯救现象”。我们应对科学理论持“建构的”而非“实在的”态度。**

弗拉森的思想精密而富有颠覆性，其核心要义可以梳理为以下四大支柱：


一、核心立场：建构经验论

这是弗拉森正面提出的纲领，旨在取代科学实在论。

*   **科学实在论的核心主张**：科学理论旨在提供关于世界的 **真实描述**，尤其是关于 **不可观察实体** （如电子、夸克、DNA）的真实描述。一个成功理论的好部分，我们 **有理由相信它近似为真**。

*   **建构经验论的核心主张**：**“科学的目标是为我们提供经验上适当的理论；接受一个理论只涉及相信它在经验上是适当的。”**

    *   **经验适当性**：一个理论是“经验上适当的”，当且仅当它关于 **可观察事物** 的所有论断是 **真实的**。换言之，这个理论能够“拯救现象”——它能准确地描述和预测我们所能观察到的一切。

    *   **关键区分**：他将世界严格区分为 **“可观察的”** 和 **“不可观察的”** 两部分。科学理论的职责仅限于 **可观察领域**。对于理论所假定的不可观察的实体和过程，我们无需承诺其真实存在。

*   **著名比喻**：科学理论如同一个 **地图或模型**。我们使用一张地图，不是因为它完美对应了地下的每一块岩石（真理），而是因为它能 **有效地指引我们到达目的地** （经验适当性）。我们“接受”这个理论，就像我们“接受”并使用这张地图，而不必相信地图上的每条等高线都对应着地下的真实岩层。

二、对科学实在论的批判：不充分决定性论题

弗拉森用来攻击科学实在论的主要武器是“不充分决定性”论题。

*   **核心命题**：**“对于任何一组有限的观察数据，总存在无限多个在逻辑上可能的不同理论，它们都能同样好地‘符合’或‘拯救’这些数据。”**

*   **含义**：我们之所以选择某一个理论（如相对论），而不是另一个与之逻辑上不相容但经验上等价的理论，并非因为证据 **迫使我们** 相信它为真。证据在逻辑上无法唯一地决定理论的选择。

*   **对实在论的反驳**：科学实在论者认为，我们最佳理论的成功（如做出新颖预测）是证明其（近似）真理性的“无奇迹论证”。弗拉森反驳道，**经验适当性本身就足以解释理论的成功**。一个理论在经验上成功，是因为它恰好在可观察层面是准确的，这并不奇迹般地意味着它对不可观察领域的描述也是真实的。存在其他经验上等价的理论，说明成功并非真理的独有标志。

三、可观察性的划界标准：经验主义的坚守

建构经验论的核心在于“可观察”与“不可观察”的划界。弗拉森为此提供了一个精致的辩护。

*   **问题**：如何界定“可观察的”？用望远镜看算观察吗？用显微镜呢？

*   **弗拉森的立场**：他采取了一种 **朴素的、相对于人类感官能力的标准**。

    *   **“可观察的”** 是指那些 **在适当条件下，不用借助仪器，仅凭人类感官就能直接感知** 的实体或过程。例如，桌上的苹果、树上的猫。

    *   **“不可观察的”** 是指那些 **原则上** 无法被人类感官直接感知的实体，无论使用多么精密的仪器。例如，电子、磁场。

*   **理由**：他认为，这个划界虽然模糊，但在哲学上是必要的。它标志着我们 **证据基础** 的界限。我们关于世界的所有证据，最终都源于观察。因此，将信念限制在可观察范围内是经验主义最严谨的立场。

四、贝叶斯式的理论接受：作为信念与承诺的“接受”

弗拉森细致区分了“相信”和“接受”。

*   **相信**：是一种 **认知态度**，关乎真假。我们相信一个命题，就是认为它为真。

*   **接受**：是一种 **更具实践性的承诺**。我们“接受”一个理论，意味着我们 **在研究中承诺使用它**，以其作为思考和实验的框架，但并不一定相信其所有内容（尤其是关于不可观察部分的内容）为真。

*   **立场**：根据建构经验论，我们 **不应“相信”** 理论关于不可观察世界的描述为真；但我们完全可以 **“接受”** 一个经验上适当的理论，并将其作为探索世界的有效工具。这是一种 **实用主义的、而非形而上学的态度**。

思想特质与影响

*   **经验主义的捍卫**：弗拉森在20世纪后期复兴并精致化了经验主义传统，使其能够应对现代物理学的挑战。

*   **反形而上学倾向**：他的哲学带有强烈的“实证主义”色彩，试图将哲学从无法验证的形而上学思辨中解放出来。

*   **深远影响**：引发了科学哲学界关于实在论与反实在论长达数十年的激烈辩论，推动了语境主义、实用主义等新思潮的发展。

*   **争议**：批评者认为，他的“可观察性”划界是 **任意和反科学的** （因为科学进步恰恰依赖于仪器扩展我们的认知）；并且，建构经验论可能过于保守，无法激励科学家去探索不可观察的深层实在。

总而言之，范·弗拉森的核心思想在于，他是一位 **“经验主义的建筑师”和“实在论的冷静审查官”**。他教导我们，对科学的最高赞誉不是称其发现了“终极真理”，而是承认它构建了 **极其有效、精准和经验上可靠的世界模型**。他的全部工作是对科学权威性的一次 **低调而有力的重塑** ：科学的权威并非源于其对不可见世界的本体论承诺，而是源于其在可见世界中所展现出的 **无与伦比的解释力和预测力**。
