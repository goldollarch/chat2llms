景教
=========

基于景（或耶稣、基督）教的视角评价陈京元博士案件。

-----

“景教”是基督教的一个历史分支，即 **聂斯托利派**，在唐代传入中国时的称谓。

基督教的核心思想可以概括为：**一位独一的上帝基于其神圣的爱与恩典，通过耶稣基督的道成肉身、受难与复活，为人类开辟了一条救赎之路，使信靠祂的人得以脱离罪恶与死亡，与上帝和好，并获得永恒的生命。**

这是一个以“**救赎**”为核心的宏大叙事，其核心要义建立在以下五大支柱之上：


一、核心本体论：独一上帝与三位一体

这是基督教神学的基石，定义了“神是谁”。

*   **独一上帝**：基督教坚信只有 **一位** 上帝。祂是宇宙的创造者、主宰者，是 **全知、全能、全善、全在** 的。

*   **三位一体**：这独一的上帝以“三位格”存在： **圣父、圣子（耶稣基督）、圣灵**。这三者不是三个神，而是同一位上帝的三个不同位格，本质相同、权能同等、荣耀同尊。这是一个奥秘，旨在说明上帝既是超越的（圣父），又是临在的（道成肉身的圣子），也是运行在信徒心中的（圣灵）。

二、核心人性论：上帝的形象与罪的堕落

这是基督教对“人是谁”及人类困境的诊断。

*   **上帝的形象**：人是按 **上帝的形象** 所造，因此具有极高的尊严和价值，被赋予管理世界的责任，并渴望与上帝建立关系。

*   **罪的堕落**：但人类的始祖亚当和夏娃违背上帝的命令，导致“**罪**”进入了世界。这里的“罪”不仅指道德上的过错，更指一种 **与上帝关系破裂的状态**，一种以自我为中心、背离上帝的生命倾向。罪导致人与上帝隔绝，带来灵性的死亡、关系的破碎和肉身的死亡。

三、核心救赎论：耶稣基督的道成肉身与救赎

这是基督教思想的中心，回答了“上帝如何拯救人”。

*   **道成肉身**：圣子 **耶稣基督**，是完全的上帝，为了拯救人类，取了人的样式，降世为人。祂是“神人之间的中保”。

*   **十字架救赎**：耶稣在十字架上的死，是 **代罪牺牲**。祂作为无罪的羔羊，承担了世人罪的刑罚，用宝血洗净了信祂之人的罪，完成了 **赎价**。

*   **复活与得胜**：耶稣死后第三天从死里复活，证明祂胜过了罪恶和死亡的权势。复活是基督教希望的基石，预示着信徒将来也同样会复活，获得不朽的生命。

四、核心回应论：因信称义与重生得救

这指明了“人该如何接受这份救恩”。

*   **因信称义**：人无法通过自身的善行或道德修养来赚取救恩。救恩是上帝 **白白的恩典**。人只需要 **信靠** （信仰）耶稣基督，就能在上帝面前被算为“义人”（与上帝和好）。这就是“**因信称义**”。

*   **重生与成圣**：当一个人真心信主时，他就得到了“**重生**”，圣灵内住在他心里，他开始一个新的、有上帝生命的人生。此后，他要在圣灵的帮助下，不断成长，活出基督的样式，这个过程称为“**成圣**”。

五、核心终末论：永生与神的国

这揭示了基督教最终的盼望和结局。

*   **永生**：信徒的最终归宿不是消亡，而是进入上帝为其预备的 **永生**。这永生从信主的那一刻就开始，并在死后进入完全的状态。

*   **基督再临与审判**：基督教相信，耶稣基督将来会 **再次降临**，审判活人死人。信靠祂的人将复活得生，进入新天新地；不信的人将面临永远的刑罚。

*   **神的国**：耶稣传道的核心是“**天国（或神的国）近了**”。这个国既是将来临的完美国度，也是现在就可以通过信徒的生命来彰显的上帝统治权。

关于“景教”的特别说明

历史上传入中国的“景教”（聂斯托利派），其核心思想与上述基本一致，但因强调耶稣基督的“神人二性”区分，在表述上可能更突出耶稣人性的完整，曾被当时的罗马教会判为异端。但其核心依然信奉三位一体、耶稣救赎等基本教义。

总而言之，基督教的核心思想是一个 **围绕上帝主动的救赎之爱而展开的宏大叙事**。它从上帝完美的创造开始，经过人的堕落，在耶稣基督的救赎中达到高潮，并最终在上帝的永恒国度中圆满。其核心是 **关系性的修复** ——修复人与上帝、人与人、人与世界的关系，而这修复的根基和动力，完全来自于上帝在耶稣基督里所彰显的 **恩典与爱**。
