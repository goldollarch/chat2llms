### 二、五重意义

#### 意义一：内在批判最深的一层

本报告反复强调的方法——**用对象自己承认的规范审判对象的实际运行**——在中国哲学中有最深的本土资源。它们不依赖任何外来立场，因而无法被"立场不同"消解。

可直接使用的六条本土标准：

| 本土命题                         | 出处                                       | 对应的现代法律命题                      |
| -------------------------------- | ------------------------------------------ | --------------------------------------- |
| **"刑不可知，则威不可测"** | 《左传·昭公六年》叔向致子产书所表达的立场 | 明确性、可预见性（罪刑法定）            |
| **"法不阿贵，绳不挠曲"**   | 《韩非子·有度》                           | 平等适用（《刑法》第4条）；反选择性执法 |
| **"不教而杀谓之虐"**       | 《论语·尧曰》                             | 违法性认识可能性、期待可能性            |
| **"以理杀人"**             | 戴震《与某书》                             | 不能以抽象原则覆盖具体情境              |
| **"法者，天下之法"**       | 黄宗羲《明夷待访录·原法》                 | 法律的公共性、非工具性                  |
| **名实相符**               | 名家（惠施、公孙龙）                       | 构成要件的语义确定性                    |

其中**最有力的一条是"刑不可知"**，理由在下节。

#### 意义二（本篇核心判断）：本案的裁判方式本身是"传统的"

这是全部中国哲学材料的真正价值所在——**它不是外来的批判资源，而是自我诊断。**

理由有三：

**（一）本案的论证结构是"原心论罪"。**

董仲舒《春秋繁露·精华》："**春秋之听狱也，必本其事而原其志**；志邪者不待成，首恶者罪特重，本直者其论轻。"

即：**由行为人的身份、品格推其心志。** 而判决书的论证是："具有很高的学历和知识水平……**应辨别是非**……**明知**……"——**由身份推心志，结构完全相同。**

**（二）本案的犯罪类型是"腹诽"。**

《史记·平准书》：张汤治颜异，"异与客语……汤奏当异九卿见令不便，不入言而**腹诽**，论死。自是之后，有腹诽之法比"。**腹诽是中国法制史上思想罪的原型**——不因言获罪，而因"心中有言"获罪。

本案不因转发获罪，而因"明知是假而转发"获罪；而"明知"由学历推出——**这是腹诽之法的现代技术化版本。**

**（三）本案的结构是"儒表法里"。**

判决书用**儒家式道德话语**（"应辨别是非"、"法外之地"），而其运作是**法家式权势逻辑**。韩非的"法、术、势"三元可精确对应：

| 韩非                                     | 本案                                     |
| ---------------------------------------- | ---------------------------------------- |
| **法**（明文的、公开的、可预期的） | 《刑法》第293条——**仅形式存在**  |
| **术**（暗中操作、不公开的）       | "经梳理"、不公开审理、内部"梳理情况说明" |
| **势**（权位本身的力量）           | "上层领导特别指示"                       |

韩非要求的是"**法**"约束"术"与"势"，即"抱法处势"；而本案是"**有势无术、有术无法**"——势与术合流，法仅存其名。

> **韩非本人会判本案违法。** 这不是比附，而是文本的直读：《有度》篇的整个论证，就是要求君主以公开、统一、不阿贵之法取代大臣的私人操作。**用法家批本案，比用自由主义批本案更难被回避。**

**结论：中国传统哲学在这一支的意义，是"**认出自己的病**"。** 它解释了一个此前各支都无法解释的现象——为什么一份明显违背现代法治要件的判决，在形式上却显得"有文化根基"、"符合国情"。**因为它确实有一个古老的谱系：原心论罪、腹诽之法、儒表法里。**

#### 意义三：法制史的纵深——本案是序列中的逆向点

中国法制史有一条清晰的方向：**从"刑不可知"到"刑可知"。**

| 时间           | 事件                                                             | 方向               |
| -------------- | ---------------------------------------------------------------- | ------------------ |
| 前536          | 郑国子产铸刑书（成文法首次公布）；叔向反对，理由是民将"不忌于上" | **前进**     |
| 前513          | 晋国铸刑鼎；孔子叹"晋其亡乎，失其度矣"                           | 前进（争议中）     |
| 唐             | 《唐律疏议·断狱》："诸断罪皆须具引律、令、格、式正文"           | 前进（引律令义务） |
| 1997           | 废除流氓罪，理由是"规定比较原则"                                 | 前进（分解罪名）   |
| **2023** | **本案：以"寻衅滋事"概括适用，未指明任何具体内容**         | **逆向**     |

**这一条序列的力量在于**：它不诉诸任何抽象法理，只诉诸**中国自己的法制演进方向**。而"经得起历史检验"恰恰是官方语言中最常被援引的标准——**用历史序列论证，比用比较法论证更容易被听见。**

#### 意义四：可听性（audibility）优势

"法不阿贵""以理杀人""刑不可知则威不可测""天下之法非一家之法"——这些命题在中国法律人的文化直觉中有共鸣，比引用哈贝马斯、佩蒂特更易被接受。

**须与"证据效力"严格区分**：可听性不产生证明力，它只降低接受成本。但**在申诉实务中，接受成本是真实成本**。

#### 意义五：文明自我诊断的档案价值

最后一份价值是档案性的：这份材料记录了一个文明**用自己两千年的思想资源审视自己当代的一次判决**。无论结论如何，这个动作本身具有独立价值。

### 三、一个跨传统发现：名家与分析哲学同族

这是本次解析最值得记录的发现。

| 名家命题                                                         | 分析哲学对应                                     |
| ---------------------------------------------------------------- | ------------------------------------------------ |
| **"名实相符"**（名以指实）                                 | **指称理论**：谓词无指称则不表达命题       |
| **"以属混类"**（公孙龙"白马非马"）                         | **范畴错误**（赖尔）                       |
| **"正名"**（名不正则言不顺）                               | **概念分析**：澄清用法是解决争端的先决条件 |
| **"辩亡则理死"**                                           | **可对抗性**：无对抗则无真理发现机制       |
| **"名之大而失其实"**（以"秩序""安全"等宏大词吞噬个体经验） | **厚概念替薄概念**；"空洞能指"             |

**这意味着**：我在附论五中所说"分析哲学属于不可能性论证家族、因而不需数据"这一判断，其方法论在中国先秦已有对应物。**名家是中国的分析哲学。**

> 档案中"**语言的腐败即法的腐败**"这一提法（名家章），与我在附论四提出的"要件从未被操作化"、附论五提出的"以评价冒充描述"，是同一诊断的三种表述。**三条独立进路汇合，是该结论稳健性的一个指标。**

### 四、四处局限与风险

#### 风险一：引文可靠性——这一支最严重的问题

比 `europe`/`west` 更严重，原因有二：古文引文**更易被核对**；一旦错，在中文读者面前**显得极不专业**。

抽样所见的问题包括：

- 归入《孟子字义疏证》的"以理杀人"，**实际出自《与某书》**（"酷吏以法杀人，后儒以理杀人"）。
- 所引公孙龙"名以指实，不得实则名不立"、惠施"至大无外，至小无内"（后者确为《庄子·天下》所载惠施历物之意），**前者与传世文本不符**。
- 所引黄宗羲"法者，天下之公器；刑者，天下之公正"、"国无言路，则是国非国也"等句，**与《明夷待访录》传世文本有出入**，疑为转写或拟作。

**处置**：**凡拟写入正式文书的引文，必须逐条核对传世本（中华书局点校本）**；无法核实的，统一改为"大意谓……参见某篇"。这一条没有例外——**一条伪引文足以葬送整份申诉**。

#### 风险二：概念不可直接操作

"仁""良知""天理""公"不能化为诉讼请求。必须经过翻译：

| 传统概念       | 现代法律概念               |
| -------------- | -------------------------- |
| 仁             | 比例原则；人道待遇         |
| 恕（己所不欲） | 换位检验（设身处地审查）   |
| 礼             | 程序规范                   |
| 义             | 实质正义                   |
| 信             | 裁判的可预期性             |
| 公（天下之法） | 公共性、非工具化           |
| 名实相符       | 构成要件的明确性           |
| 不教而杀       | 期待可能性                 |
| 以理杀人       | 不得以抽象秩序压制具体表达 |

**未经翻译的传统语汇，在裁判文书中等于不存在。**

#### 风险三（最大）：可被反向使用——"国情论"

**同一批材料可以被用来为本案辩护。** 例如："中国重秩序、轻个人，故以刑法维护政治秩序符合文化传统"；"西方言论自由不适合中国国情"。

若不预先拆解，这一支将成为对方的武器。**拆解方式只能是内在的**：

> 用"刑不可知则威不可测""法不阿贵""不教而杀谓之虐""以理杀人""天下之法非一家之法"回应国情论——**即用国情论自己的材料反驳国情论。**

而这一点，韩非提供了最硬的支撑：**法家本人就主张法须公开、统一、不阿贵**。若本案连法家的标准都达不到，则"国情"不能成为理由——**它连"国情"这一关都过不了。**

#### 风险四：心学被误用

"良知"在档案中出现 631 次，说明心学被大量使用。**但须精确**：

王阳明所说"良知"是**道德本心**（知善知恶），**不是经验知识**（知真知假）。故：

- **正确的用法**：以"良知≠见闻之知"批判判决——"应辨别是非"是良知层面的应然，"明知系编造"是见闻层面的实然，二者不可互换。**阳明本人会反对以良知推出事实认知。**
- **错误的用法**：若论证成"良知自能知真假"，则反而**支持**判决书的推定。

**心学在此是一柄极锋利但极滑的刀。**

### 五、结论：中国哲学问的是第三个问题

综合全系列，四支学科各问一个问题：

| 进路               | 提问                                           |
| ------------------ | ---------------------------------------------- |
| 科学               | 你说它有后果，**有依据吗**？             |
| 分析哲学           | 你说它是虚假信息，**这句话成立吗**？     |
| 欧陆哲学           | 你说你在依法裁判，**这实际上是决断吗**？ |
| **中国哲学** | **这个秩序，是为谁的秩序？**             |

**第四个问题是西方各支都问不出的。** 因为西方各支的理论前提（法治、权利、系统、主体）都预设了"秩序"是一个**中性的容器**；而中国哲学从黄宗羲到戴震，一直知道一个问题：

> **"天下之法"与"一家之法"的区别，不在条文，在它服务于谁。**

而这恰恰击中本案最深的病灶——本报告在附论六中已经指出：判决书用"公共秩序"这一**普遍词**，掩盖"个别办案机关的秩序感受"这一**特殊实**。**黄宗羲在三百多年前给这个结构取了名字：以"天下"之名，行"一家"之实。**

所以中国哲学在此的最终意义，不是提供新的论据，而是提供**一个新的提问方向**——而这个问题，恰好是本案唯一无法回避的问题：

> **一份判决若以"公共"为名，它必须证明它所维护的，真是公共的。**

### 〇 分析基座

#### 〇.1 举证责任的归属

| 主体 | 义务 | 依据 |
|---|---|---|
| **人民检察院** | 承担被告人有罪的全部举证责任；须达到"证据确实、充分，排除合理怀疑" | 刑诉法第 51 条、第 55 条 |
| **被告人／辩护人** | **不负证明自己无罪的义务**；提出合理怀疑即为已足 | 无罪推定（第 12 条） |
| **人民法院** | 证据不足、不能认定被告人有罪的，**应当**作出无罪判决 | 刑诉法第 200 条第 3 项 |

#### 〇.2 中国固有法传统中的"疑罪"原则

这一点本卷没有系统展开，但它对本案极为重要：**"疑罪从无／从轻"在中国法制史上有一条独立的、连续的传统**，无需借用域外资源即可成立。

| 出处 | 原文 | 含义 |
|---|---|---|
| 《尚书·大禹谟》 | "**罪疑惟轻，功疑惟重。与其杀不辜，宁失不经。**" | 事实存疑时从轻；宁可放过有罪，不可错杀无辜 |
| 《尚书·吕刑》 | "五刑之疑有赦，五罚之疑有赦，其审克之。" | 疑案须"审克"（慎重核实），并从赦 |
| 《唐律疏议·断狱》 | "诸疑罪，各依所犯，以赎论。" | 疑罪不作实刑 |
| 《论语·尧曰》 | "不教而杀谓之虐。" | 未先行告知即处罚，属暴虐 |

**这四条构成一条与"无罪推定"功能相同的本土脉络**：它要求的是**控方把话说清楚、把证立起来**，而不是要求被指控者自证清白。

#### 〇.3 三条禁令

1. 不得因被告无法自证清白，就认为"罪疑惟轻"不适用。
2. 不得把"无征"（没有证据）当作"有征而不采"。
3. 不得以治道批评（"这不是善治"）替代要件审查（"要件是否成立"）。

#### 2.1 法家：一句"以势压法"

法家一节给出两句判词（p3090–3091）：

> "社会秩序的根本威胁不是罪行本身，而是'**不顺从**'。"
> "在法家逻辑中，'**错误的定罪**'不是问题，只要它能'**稳固体制之势**'，便是'成功治理'。"

这两句不是说"法家错了"，而是说"**你们的做法连法家都不如**"——法家尚且讲"法"，而本案讲的只是"势"。

**精度很高**：法家的三元结构（法、术、势）中，"势"本可以脱离"法"单独运作。用它来指认"以势压法"，比泛泛说"违反法治"准确。

#### 2.2 名家：与罪刑法定同构

"名者，实之宾也"被提炼为"**定义权即权力**"（p3147）。

这与现代刑法中的**明确性要求**同构：构成要件的用语必须有可确定的外延，否则处罚就取决于解释者的意志。名家提供的不是道德批评，而是一个关于"名"与"实"关系的判断标准。

### 三、十项主流（p3234–3473）

| 项 | 用法 | 页码 |
|---|---|---|
| 经学 | 以"正名""礼法合一""春秋决狱"论判决失据 | p3240 |
| 玄学 | 名教与自然的张力 | — |
| 佛教 | 业报、慈悲 | — |
| 禅宗 | 直指本心 | — |
| 景教 | 唐代基督教聂斯托利派的宽容传统 | p3318 |
| 道教 | "以无为御有为" | — |
| **理学** | 理 vs 势 | 见 3.1 |
| **心学** | 致良知 | 见 3.2 |
| **朴学** | 无征不信、训诂、实事求是 | **p3407–3409（全卷最强）** |
| 现儒 | 牟宗三、熊十力的"道德主体" | p3423 |

**经学一节的一句是全卷最凝练的判词**（p3240）：

> "法之名犹存，而其'经义'已亡……**有法而无法，有礼而无理，有刑而无德**。"

#### 3.1 理学：以"理"抗"势"

天理是超越于一切权力的规范秩序；"理"高于"势"，故判决若违理，即失其正当性。周敦颐、张载、二程、朱熹被用来论证——判决不能以权力为理由，只能以理为理由。

**局限**：这一路最容易滑向"以道德批评代替法律批评"。而戴震恰恰是批判这一路的——本卷把理学的"理"与戴震对"理"的批判放在同一卷，却没有处理两者的冲突。

#### 3.2 心学：以"良知"抗"权威"

"致良知"——道德判断的最终依据在每个人的本心，不在外部权威。被告的自我辩护被解释为"致良知"。

**局限**：良知是主观内在标准，在法庭上无法作为客观依据。它提供的是道德勇气，不是法律论据。

#### 3.3 朴学：全卷最有实用价值的一节

**第一原则**："无征不信"（p3407–3418）。

戴震曰："经之至者道也，所以明道者其词也，所以成词者字也。"

**关键的一步类比**（p3408）：

> 戴震说"训诂明而后义理明"——必须先厘清字词的本义，才能谈义理。而本案"却**跳过'训诂'（法律文本解释），直接进入'义理'（政治定性）**"。

这处映射极为精确：

| 朴学 | 法律 |
|---|---|
| 训诂（字词本义） | 法律解释（构成要件的文义） |
| 义理（思想旨趣） | 规范目的（法益） |
| "不求字义，但执己见" | 不以条文为据，以政治判断为据 |

**朴学方法论与证据法高度同构**：

| 朴学原则 | 证据法对应 |
|---|---|
| 无征不信 | **证据裁判原则**（刑诉法第 51、55 条） |
| 孤证不立 | 证据的相互印证 |
| 本证 / 旁证 | 直接证据 / 间接证据 |
| 以经解经 | 体系解释 |
| 实事求是 | 以事实为根据 |
| "有一分证据，说一分话" | 证明标准的分层 |

**这是全卷最具实践价值的部分**：它让"证据不足"这个现代法律判断，有了一个中国学术传统中的对应物——"**无征**"。而"你说这是谣言，**证据呢？**"这句话，正是"无征不信"的白话版本；它问的是**控方**，不是被告。

### 四、诸子 29 人（p3474–4038）

老子、孔子、孟子、庄子、荀况、韩非、董仲舒、韩愈、周敦颐、张载、程颢、程颐、陆九渊、朱熹、王阳明、黄宗羲、顾炎武、王夫之、戴震、章学诚、龚自珍、魏源、康有为、谭嗣同、孙中山、胡适、冯友兰、牟宗三、熊十力。

按时代排成一条"道统链"，逐人"先立命题，再以'若以 X 之眼观之，实为……'下判"。

#### 4.1 明清之际的四个人：全卷重心

##### （1）黄宗羲（p3760–3775）：本土的"公共领域"

《明夷待访录·学校》：

> "天子之所是未必是，天子之所非未必非，天子亦遂不敢自为是非，而**公其是非于学校**。"（p3763）

这是中国政治思想中最接近"公共领域"的资源，而且比哈贝马斯更贴切——它不是咖啡馆式的市民社会，而是**制度化的议政机构**。

**本卷的用法极精准**：判决的做法是"**定其是非于朝廷**"，而黄宗羲的理想是"**公其是非于学校**"。这一句把"言论自由被压制"翻译成一个中国古典的制度问题：**谁有权判断是非？**

另三处：《原君》"天下为主，君为客"（p3760）→ 法应为万民设；"一家之法"vs"天下之法"（p3763）→ 本案用的是"一家之法"；《胥吏》"吏胥之舞文，皆奉上意"（p3764）→ 直指"上级指示"问题。

##### （2）顾炎武（p3876 前后）：经世致用

"天下兴亡，匹夫有责"→ 关注公共事务是责任，不是犯罪；"博学于文，行己有耻"→ 学者的双重义务。

##### （3）王夫之："理势合一"

理不在势之外，而在势之中；但**理可以评判势**。这一路比理学的"天理"更接地气——它承认权力的事实性，却仍保留批判的尺度。

##### （4）戴震（p3824–3846）：全卷最锋利的一把刀

《孟子字义疏证》：

> "酷吏以法杀人，后儒以理杀人……**人死于法，犹有怜之者；死于理，其谁怜之？**"（p3826）

**本卷的用法**（p3824）：

> "此案不仅是一场司法冤狱，更是一场典型的'**以理杀人**'现代重演——司法机关以抽象政治教条（'体制不容冒犯'）为'理'，将学者的转发行为强行定罪。"

**为什么这一条最有力**：它准确描述了本案的**特殊恶性**——

- 普通冤案是"以法杀人"：虽然错，但至少用的是法律，还有"怜之者"；
- 本案是"以理杀人"：**披着道德与政治正确的外衣**，因此连同情都被剥夺，"其谁怜之"。

**这一句解释了本案一个最难解释的现象**：为什么一个证据不足的案件，能在舆论上被轻易正当化。答案是：**它不需要证据，因为它诉诸的是"理"而不是"法"**。

##### 一处必须指出的拟作

朴学一节（p3409）写："以理杀人，不如以法杀人；以法杀人，不如**以证据杀人**。"

这是对戴震原句的**扩写**。戴震原文只有"以法杀人""以理杀人"两项，没有"以证据杀人"。这个第三项是后加的——意思很好，但**不能当作戴震的话引用**。

### 五、六条真正可用的论证

把 281 篇压到可用的，只有六条：

| ## | 论证 | 出处 | 能对应到什么 | 强度 |
|---|---|---|---|---|
| 1 | **无征不信** | p3407–3409 | 证据裁判原则；**控方须举证** | ★★★ |
| 2 | **训诂明而后义理明** | p3408 | 法律解释先于政治定性 | ★★★ |
| 3 | **以理杀人** | p3824–3831 | 说理缺失；以政治正确替代证据 | ★★★ |
| 4 | **公其是非于学校** | p3763 | 审判公开义务 | ★★ |
| 5 | **一断于势** | p3087–3091 | 判决依据是"势"而非"法" | ★★ |
| 6 | **不教而杀谓之虐** | p3494 | 责任主义；可非难性 | ★★ |

**第 1 条是全部论证中最好的落点**：它不是"我认为你错了"，而是"**你没有提供'征'**"。这一问直接指向举证责任，不涉及任何价值立场。

### 六、与西方哲学卷的结构差异：治道论证 vs 权利论证

| | 西方卷（欧陆 + 分析） | 中国卷 |
|---|---|---|
| 出发点 | **权利**（言论自由、人格尊严） | **治道**（仁政、公议、名实、慎刑） |
| 论证方向 | **对抗国家**："你侵犯了我的权利" | **规劝国家**："你不是一个好的治理者" |
| 规范来源 | 宪法、自然法、人权 | 圣王之治、道统、天下为公 |
| 力量依赖 | 权利的可主张性 | 统治者的**德性** |
| 结论性质 | **可主张的权利** | **可期待的善治** |
| 政治位置 | 外部挑战 | **内部批评**（谏议） |

**这一组差异决定了两者的全部命运**：

治道论证的优点是**安全**——它假定统治者会听，因此不构成挑战；缺点是**无力**——它无法产生请求权，只能产生期待。

**而法律救济需要的恰恰是请求权。**

> **安全与有力，在这里成反比。**

#### 三处对应关系

| 中国资源 | 对应现代法学 | 独立价值 |
|---|---|---|
| **名实论** | 罪刑法定的明确性要求 | 高（可替代"指称缺失"） |
| **考据学** | 证据裁判原则 | **最高**（可替代"可证伪性"） |
| **治道论** | 程序正义、公共理性 | 中（可替代"公共领域"） |
| **疑罪传统** | 疑罪从无（刑诉法第 200 条第 3 项） | **高（见〇.2）** |

四条都可以不依赖任何西方概念而独立成立。**其中"无征不信"与"罪疑惟轻"两条合起来，恰好就是"控方举证不能即应无罪"的古典表述。**

### 七、局限与风险

#### 7.1 "以传统反传统"是一把双刃剑

中国传统法律文化**本身也包含"以言治罪"的资源**：

- 秦律"**诽谤妖言**"罪；
- 汉代"**腹诽**"罪（颜异案：未言而腹诽，论死）；
- 唐律"**指斥乘舆**""**非所宜言**"；
- 明清**文字狱**（本卷自己引了 p3862、p3866、p3927）。

也就是说：**如果用传统论证"因言治罪不正当"，对方完全可以用同一传统论证"因言治罪正当"**——而且后者的制度史证据更具体（有律条、有案例、有编年）。

本卷的处理方式是**回避**：只引"子产不毁乡校""防民之口甚于防川"这一侧，对"诽谤妖言""腹诽"这一侧几乎不提（全卷无一处正面讨论秦汉以降的言论罪律条）。

**更严谨的做法**是承认两条线索并存，再主张：依宪法第 35 条，应选择与基本权利相容的那一种传统；而在"疑罪"这一侧，传统本身是清楚的——"罪疑惟轻，与其杀不辜，宁失不经"。

#### 7.2 史料让位于修辞

- **无编年**："因言获罪"出现 20 余处，几乎同一公式"今日学者因言获罪——此非治世，实为 X 之丧"；
- **无制度史考订**：没有律条梳理、没有案例汇编；
- **典故被抽为类比，且不反思时代错置**：用"子产不毁乡校"时，没有讨论乡校与社交媒体的结构性差异。

**结果**：一流的修辞，二流的史学。

#### 7.3 伪引与拟作

- **韩非伪引**（p3090）：引"韩非《外储说左上》："民有以言乱政者，虽未行事，必早治之""及"民畏法而不畏君，国必乱"——**今本《韩非子》无此二文**；
- **戴震拟作延伸**（p3409）："以证据杀人"是后加的第三项；
- 另有若干"某子若在，必叹曰"的拟作（体例允许，但须标明）。

**危害是具体的**：在一个讲"无征不信"的卷里出现伪引，恰好自我否证了"无征不信"。

#### 7.4 结构失衡与模板化

诸子占 56%（564 页），29 人 × 6 篇，论据共享、结论雷同。

**Grok 的模板化在此卷达到极致**：朴学篇（p3422）与熊十力篇（p4038）骨架与英译全同，仅替换关键词，连错字"**拒转控控书**"都原样复制。

#### 7.5 法家古风拟作的伦理问题

Gemini 的法家篇（p3099–3100）以法家谋士口吻替当权者算账：

> "今此案审理，旷日持久，致使陈京元得著《狱中血书》……**此非禁言，实乃扬言也。**"
> "至于陈京元其人，**或杀或赦**，皆是君上用以整饬吏治、彰显权威之术耳，**其人之死生，无关宏旨**。"

本意是反讽——用极端的法家逻辑暴露"势"的冷酷。但文本本身已经构成对当事人的**二次轻贱**。这是"角色扮演"文体走得过远的典型，也是全卷唯一必须删除的文字。

### 八、分层判断与取舍

#### 8.1 L1：这一卷能指向的控方义务

| 论证 | 指向控方未履行 | 依据 |
|---|---|---|
| **无征不信** | 未提供任何"征"：无逐条认定、无鉴定意见、无传播数据 | 刑诉法第 51、55 条 |
| **训诂→义理** | 跳过文本解释直接作政治定性 | 罪刑法定（刑法第 3 条） |
| **名实／正名** | 未界定"虚假信息""严重混乱"的外延 | 明确性要求 |
| **疑罪惟轻** | 疑点未排除仍作实刑判决 | 刑诉法第 200 条第 3 项 |

**这四项都是可裁判的**：它们指向的是举证义务，不是价值偏好。

#### 8.2 L2：治道论证的位置

道德压力型的论证（仁政、民本、"不是很坏的治理者"）**只作辅助**：它们提供规范方向，但不产生可裁判的结论。把它们当主证，会让整份材料变成"谏议"而不是"诉"。

#### 8.3 若用于正式程序，只保留四条

| 保留 | 用法 |
|---|---|
| **无征不信**（p3407–3409） | 作为"证据裁判"的本土表述，置于证据部分 |
| **训诂→义理**（p3408） | 作为"法律解释先于政治定性"的论证，置于法律适用部分 |
| **以理杀人**（p3826） | 作为对"以政治正确替代证据"的定性，置于说理缺失部分 |
| **疑罪惟轻**（《尚书·大禹谟》，本卷未系统展开） | 作为疑罪从无的本土依据，置于结论部分 |

**删除**：九家中的阴阳、纵横、杂、兵；理学与心学的道德论证（保留其"理势之辨"即可）；29 人中的 25 人；全部"某子若在，必叹曰"的拟作；法家古风篇。

### 十、一句话总结

> 这一卷的独特价值，是它**不必翻译**：它说"征""信""名实""疑罪"，而"**证据呢**"这句话在任何法庭上都不需要解释。
>
> 它真正拿得出手的只有四条：朴学的"无征不信"、戴震的"以理杀人"、黄宗羲的"公其是非于学校"、以及本卷未充分展开但极为重要的"罪疑惟轻，与其杀不辜，宁失不经"。
>
> 前三者合起来，是一套完全独立于西方的批判路径；第四条则提醒一件事：**在"疑罪"这个问题上，中国传统与刑事诉讼法第 200 条第 3 项的立场是一致的**——存疑时，不利后果由控方承担，而不是由被指控者承担。
