戴震
======

基于戴震核心哲学思想

---------------------------------

戴震（1724—1777），清代乾嘉学术的代表人物，其哲学思想以 “气本论” 为核心，激烈批判程朱理学，主张 “理在气中”“理存于欲” ，具有鲜明的唯物倾向和人文关怀。以下是其核心思想的简要概括：

一、宇宙论：气本论

• 气为宇宙本体：戴震认为宇宙万物皆由 “气” 构成，气是运动的物质实体（“阴阳五行，道之实体”）。

• 理在气中：反对程朱理学将 “理” 视为独立于气的绝对本体。他强调 “理者，察之而几微必区以别之名也” ，即理只是气化运行中呈现的条理、规律，不能脱离具体事物而存在。

二、认识论：由“血气心知”达至“理义”

• 感官与心智并重：人通过 “血气”（感官）接触外物，再由 “心知”（理性思维）进行分析辨别，从而认识事物内在的 “理”。

• 批判“复性说”：反对理学认为真理先天存在于心中的观点，主张知识来源于对客观世界的考察（“事物之理，必就事物剖析至微而后得”）。

三、人性论与伦理学：理欲统一

• 人性即“血气心知”：人性基于自然的生理与心理机能，包括欲望、情感和认知能力。

• 理存乎欲：戴震提出 “理者，存乎欲者也” ，认为道德规范（理）不能脱离人的基本欲望而存在。正当的欲望是生命活力的体现，“饥寒愁怨、饮食男女” 皆属自然需求。

• 批判“存天理，灭人欲”：他痛斥理学将天理与人欲对立是 “以理杀人” ，认为压抑人性会导致虚伪与社会不公。真正的道德应 “遂欲达情” ，在满足合理需求中实现善。

四、方法论：训诂明则义理明

• 通过考据求真理：戴震主张回归儒家经典原意，以严谨的考据（训诂、音韵、典章制度研究）为基础，才能探求真正的义理。

• 反对空谈性理：批评宋明理学脱离实证、主观臆断的学风，体现了乾嘉朴学的科学精神。

五、思想史意义

1. 唯物主义的深化：继承张载、王夫之的气学传统，构建了清代最系统的气本论哲学体系。
2. 启蒙色彩：对理学禁欲主义的批判具有早期启蒙性质，强调人的自然权利与情感价值。
3. 学术转型：其 “由字通词，由词通道” 的方法论，推动了清代学术向实证研究转型，但也引发后世关于“考据与义理孰重”的争论。

核心贡献

戴震哲学的根本立场是 “回归人本身”——他将宇宙、知识、伦理的根基从超验的“天理”拉回现实的 “气化流行” 与 “人伦日用” ，试图在自然人性中重建道德与社会秩序。其思想虽未脱离儒家框架，却为传统哲学注入了鲜明的唯物论、经验论色彩，成为中国近代思想启蒙的重要先声。
