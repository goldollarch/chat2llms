SOC and Avalanche
==================

陈京元在其 :doc:`【狱中血书】</case/docus/defendent/letter>` 中，
运用“**自组织临界性**”理论及“**雪崩动力学**”，论证其个人微弱的网络转发行为不可能引发“**社会秩序严重混乱**”，
同时指出司法黑帮的构陷行为才可能触发系统性的“雪崩效应”，**危害国家安全**。


- **自组织临界性** （Self-Organized Criticality，SOC）是指系统在没有外部调控的情况下，自发地演化到一个临界状态，在这个状态下，系统对微小扰动的响应可能是大规模的事件（如雪崩）。这一理论由Per Bak等人提出，广泛应用于物理学、地质学、生物学等领域。
- **雪崩动力学** （Avalanche Dynamics）描述了在SOC系统中，微小的扰动如何引发大规模的事件。雪崩效应指的是在临界状态下，系统对微小扰动的响应可能是大规模的事件，类似于雪崩的发生。
