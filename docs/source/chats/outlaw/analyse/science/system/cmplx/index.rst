Complex System
================

陈京元在其 :doc:`【狱中血书】</case/docus/defendent/letter>` 中，对检方指控其行为”造成公共秩序混乱”提出系统性反驳。
他指出社交网络是典型的复杂系统，其固有特征（如小世界效应、无标度特性）决定了其本质上是“无序”的。
根据CAP定理（分布式系统无法同时满足一致性、可用性与分区容错性），网络秩序的“混乱”是常态，个人的转发行为无法改变这一系统性特征。
他据此否定了自己的转发贴这种所谓的“犯罪行为”，和“社会秩序混乱”这一“损害事实”之间具有“因果关系”。
