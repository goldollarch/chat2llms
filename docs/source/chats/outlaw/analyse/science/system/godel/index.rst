Gödel Theorem
==============

陈京元在其 :doc:`【狱中血书】</case/docus/defendent/letter>` 中，引用“**哥德尔不完全性定理**”，
强调人类理性的根本局限性，他认为人类目前建立的各种理论及观点都是有缺陷的，所以不可全然肯定或否定，而应该“以海纳百川般的胸怀和态度吸纳各家学说，才能构建更完整深刻的知识体系。”

正是基于这样的认知心理，他否定了本案执法人员对他的“明知”其转发贴文为“谣言”的认定。他明言“我对人类认识领域的所有知识都保持着怀疑或批判的态度……相关执法人员认定我‘明知’的各种知识和能力，完全不符合我的认知结构。” 
他认为他转发的哪些关于理论认识领域的各种贴文并不是“谣言”，而是“有极大收藏价值并值得进一步研究讨论的精品文章”。

陈博士基于学者的“认知谦逊”和“怀疑主义”解构了控方对其“明知谣言”的指控。
